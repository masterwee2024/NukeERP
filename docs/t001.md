## What Is Being Built
The pyERP project skeleton: Django backend with Poetry/uv dependency management, React 19 frontend with Vite + TypeScript + TailwindCSS, and a monorepo folder structure that cleanly separates backend, frontend, docs, and tests.

## How It Will Be Built

### Backend (Django)
- Initialize Django project with `django-admin startproject pyerp .`
- Create Django apps: `core`, `financial`, `assets`, `treasury`, `scm`, `crm`, `mrp`, `hrm`, `admin`
- Configure `pyproject.toml` with Poetry/uv, Python 3.12+
- Install core dependencies: django, djangorestframework, django-ninja, psycopg2-binary, redis, celery, django-environ
- Configure `.env` and `settings.py` for database, Redis, ALLOWED_HOSTS, CORS

### Frontend (React)
- `npm create vite@latest frontend -- --template react-ts`
- Install TailwindCSS 4, TanStack Query, TanStack Table, Zustand, React Router, React Hook Form, Zod
- Configure `vite.config.ts` with proxy to Django backend (port 8000)
- Configure TypeScript strict mode
