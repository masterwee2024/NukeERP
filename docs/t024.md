# T024 — Period Management

- **Phase**: 2
- **Depends On**: T010, T020
- **Estimated Effort**: 2 days

## What Is Being Built
Close/reopen fiscal periods. Prevent posting to closed periods. Year-end close process: transfer P&L to retained earnings, lock previous year, open new year.

## How It Will Be Built

### Backend (Django)
- **Service** (`apps/financial/services/period_service.py`):
  - `close_period(period_id)` — validate no unposted entries, set status=closed
  - `reopen_period(period_id)` — set status=open (admin only)
  - `year_end_close(financial_year_id)` — transfer P&L balances to retained earnings, create new financial year with periods, lock old year
- **API** (`apps/financial/api/period_api.py`):
  - `GET /api/v1/financial/periods/` — list with status
  - `POST /api/v1/financial/periods/{id}/close/` — close period
  - `POST /api/v1/financial/periods/{id}/reopen/` — reopen period
  - `POST /api/v1/financial/financial-years/{id}/year-end-close/` — year-end close
