# T105 — Change Order Management

- **Phase**: 2
- **Depends On**: T100
- **Estimated Effort**: 2 days

## What Is Being Built
Change order tracking for projects. Record scope changes, cost impact, client approval. Update project budget and contract amount. Change order history. Approved vs pending changes.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `ChangeOrder`: id, project FK, change_order_number, title, description, reason, cost_impact (positive = additional cost, negative = reduction), schedule_impact_days, status (draft/submitted/approved/rejected/implemented), requested_by, approved_by, approval_date, company FK, created_at
  - `ChangeOrderLine`: change_order FK, category (material/labour/subcontractor/other), description, amount
- **Service** (`apps/financial/services/change_order_service.py`):
  - `create_change_order(data)` — create with line items
  - `approve_change_order(co_id)` — approve, update project budget/contract
  - `reject_change_order(co_id, reason)` — reject with reason
  - `get_change_order_summary(project_id)` — total approved changes, pending, impact
  - `get_project_revised_budget(project_id)` — original budget + approved changes
- **API** (`apps/financial/api/change_order_api.py`):
  - Change order CRUD, approve, reject, summary

### Frontend (React)
- **Change Order List Page**: all changes with status and cost impact
- **Change Order Form Page**: create/edit with line items
- **Change Order Approval**: approve/reject with comment
- **Project Impact Summary**: budget before/after changes
