# T072 — Shop Floor Execution

- **Phase**: 6
- **Depends On**: T064, T068
- **Estimated Effort**: 3 days

## What Is Being Built
Shop floor dashboard (work center queue). Operation start/stop clocking. Scrap/rework recording. Machine downtime logging. Production output recording.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/mrp/models.py`):
  - `ShopFloorEntry`: work_order FK, operation FK, work_center FK, operator FK, start_time, end_time, quantity_produced, quantity_scrapped, downtime_minutes, downtime_reason, notes
- **Service**: clock in/out, calculate actual times, update WO operation actuals
- **API**: clock in, clock out, shop floor entries

### Frontend (React)
- `ShopFloorDashboard` — work center queue with pending operations
- `ShopFloorClockPage` — clock in/out interface (touch-optimized for tablet use on shop floor)
