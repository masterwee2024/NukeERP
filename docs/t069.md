# T068 — Routings & Operations

- **Phase**: 6
- **Depends On**: T062, T064
- **Estimated Effort**: 3 days

## What Is Being Built
`Routing` linked to BOM. Operation sequence: work center, setup time, run time per unit, queue time. Multiple routings per item. Standard vs alternate routing.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/mrp/models.py`):
  - `Routing`: item FK, name, description, is_default, is_active, company FK
  - `RoutingOperation`: routing FK, operation_number, work_center FK, setup_time_minutes, run_time_per_unit_minutes, queue_time_minutes, description, notes
- **Service**: CRUD, time calculation (total = setup + run × qty + queue), cost calculation per routing
- **API**: Routing CRUD + time/cost calculation

## Deliverables Checklist
- [ ] `Routing` and `RoutingOperation` models
- [ ] Operation sequence with times
- [ ] Total time calculation
- [ ] Total cost calculation (labour + overhead per work center)
- [ ] Multiple routings per item (standard + alternates)
- [ ] React routing pages

## Success Criteria
- [ ] Total time = setup + (run_time × qty) + queue
- [ ] Total cost = sum of (operation hours × work center cost rate)
- [ ] Default routing marked per item
- [ ] All tests pass
