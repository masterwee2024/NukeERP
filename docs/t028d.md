# T028d — Variance Analysis

- **Phase**: 2
- **Depends On**: T028c
- **Estimated Effort**: 3 days

## What Is Being Built
Manufacturing variance analysis comparing actual costs to standard costs. Six variance types: Material Price, Material Usage, Labour Rate, Labour Efficiency, Overhead Spending, Overhead Volume. Variance reports with drill-down. Variance GL entries.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `VarianceEntry`: id, work_order FK, item FK, period FK, variance_type (material_price/material_usage/labour_rate/labour_efficiency/overhead_spending/overhead_volume), standard_amount, actual_amount, variance_amount, variance_percent, status (open/closed), journal_entry FK, company FK, created_at
- **Service** (`apps/financial/services/variance_service.py`):
  - `calculate_variances(work_order_id)` — calculate all six variances
  - `post_variance_gl(variance_id)` — GL entry for variance
  - `get_variance_report(company, period, variance_type)` — variance report
  - `get_variance_trend(company, item_id, months)` — variance over time
- **Variance Formulas**:
  ```
  Material Price Variance = (Std Price - Actual Price) × Actual Qty
  Material Usage Variance = (Std Qty - Actual Qty) × Std Price
  Labour Rate Variance = (Std Rate - Actual Rate) × Actual Hours
  Labour Efficiency Variance = (Std Hours - Actual Hours) × Std Rate
  Overhead Spending Variance = Budget OH - Actual OH
  Overhead Volume Variance = (Budget Hours - Actual Hours) × OH Rate
  ```

### GL Entries (Unfavourable Variance)
```
Material Price Variance (unfavourable — actual > standard):
DR Material Price Variance (P&L)    2,000.00
CR Accounts Payable                 2,000.00
```

### Frontend (React)
- **Variance Report Page**: table with all variance types, amounts, percentages
- **Variance Trend Chart**: line chart showing variances over time
- **Drill-down**: click variance to see underlying transactions
