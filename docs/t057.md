# T056 — Lead Management

- **Phase**: 5
- **Depends On**: T009
- **Estimated Effort**: 3 days

## What Is Being Built
`Lead` model: name, company, contact info, source, status (new/contacted/qualified/lost). Lead assignment to salesperson. Notes & activity log. Convert to Customer + Opportunity.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/crm/models.py`):
  - `Lead`: name, company_name, email, phone, source (website/referral/cold_call/social/other), status (new/contacted/qualified/lost), assigned_to FK, company FK, notes, converted_customer FK, converted_opportunity FK, created_at
  - `LeadActivity`: lead FK, activity_type (call/email/meeting/note), subject, description, date, user FK
- **Service**: CRUD, assign, convert to customer + opportunity, activity logging
- **API**: CRUD + assign + convert + activity endpoints

### Frontend (React)
- `LeadListPage` — table with status filter, assignment filter
- `LeadFormPage` — create/edit
- `LeadDetailPage` — profile, activity timeline, convert button

## Deliverables Checklist
- [ ] `Lead` and `LeadActivity` models
