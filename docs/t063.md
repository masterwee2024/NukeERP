# T062 — Customer Invoicing

- **Phase**: 5
- **Depends On**: T014, T026, T058
- **Estimated Effort**: 4 days

## What Is Being Built
Invoice generation from Delivery Order (single or consolidated). Invoice numbering from T014. Tax calculation. GL posting (AR debit, Revenue credit, Tax credit). E-invoice integration point.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/crm/models.py`):
  - `CustomerInvoice`: (links to `CustomerInvoice` from T029 or references DO)
  - `InvoiceFromDO`: service to create invoice from one or more DOs
- **Service**: create from DO, consolidate multiple DOs, tax calculation, GL posting (DR AR, CR Revenue, CR Tax Payable)
- **API**: create from DO, list, detail, post

## Deliverables Checklist
- [ ] Create invoice from single DO
- [ ] Consolidate multiple DOs into one invoice
- [ ] Invoice numbering from T014
- [ ] Tax calculation per line
- [ ] GL posting (DR AR, CR Revenue, CR Tax)
- [ ] React invoicing pages
- [ ] All actions use `useConfirm()` dialog

## Success Criteria
- [ ] Invoice from DO carries correct items, quantities, prices
- [ ] Consolidated invoice merges lines correctly
- [ ] GL entries are balanced
- [ ] Invoice number auto-assigned
- [ ] All tests pass
