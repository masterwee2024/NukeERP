# T084 — Payroll: PCB (MTD) Calculation

- **Phase**: 7
- **Depends On**: T077
- **Estimated Effort**: 3 days

## What Is Being Built
Monthly Tax Deduction (PCB) calculation per LHDN MTD schedule. Resident vs non-resident rates. Additional remuneration formula. PCB calculation per employee. CP39 (monthly PCB remittance) data.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `PCBCalculation`: employee FK, payroll_period FK, monthly_tax_deduction, annual_tax_estimation, taxable_income, tax_payable, pcb_amount
- **Service** (`apps/hrm/services/pcb_service.py`):
  - `calculate_pcb(employee, period)` — use LHDN MTD table/formula
  - `calculate_additional_remuneration(amount, period)` — additional PCB formula
  - `generate_cp39(company, period)` — CP39 data for PCB remittance
- **API**: PCB calculation, CP39 data

### PCB Calculation Steps
1. Calculate aggregate monthly income
2. Determine cumulative taxable income
3. Apply LHDN MTD tax rates to cumulative income
4. Subtract monthly PCB instalment
5. PCB for month = cumulative PCB - PCB previously deducted
