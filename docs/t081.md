# T080 — Payroll: Salary Structure

- **Phase**: 7
- **Depends On**: T072
- **Estimated Effort**: 2 days

## What Is Being Built
`SalaryStructure` per employee: basic pay, fixed allowances (housing, transport, meal), variable allowances (overtime, commission). Recurring vs one-time. Pro-rata calculation for mid-month joiners. Salary revision history.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `SalaryStructure`: employee FK, basic_salary, housing_allowance, transport_allowance, meal_allowance, other_fixed_allowances, effective_date, is_current, company FK
  - `SalaryRevision`: employee FK, revision_date, previous_salary, new_salary, reason, approved_by FK
  - `VariableAllowance`: employee FK, payroll_period FK, allowance_type (overtime/commission/bonus/other), amount, description
- **Service**: CRUD, pro-rata calculation, salary revision, current salary lookup
- **API**: Salary structure CRUD + revision + pro-rata calculation
