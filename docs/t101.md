# T101 — Project Cost Tracking

- **Phase**: 2
- **Depends On**: T100
- **Estimated Effort**: 4 days

## What Is Being Built
Project cost tracking — all costs tagged to projects. Labour hours × rate, materials consumed, subcontractor invoices, equipment usage. Project cost ledger. Cost by category, cost by period. Actual vs budget by project.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `ProjectCost`: id, project FK, cost_category (material/labour/subcontractor/equipment/overhead), description, quantity, unit_cost, total_cost, cost_date, reference_type (invoice/journal/timesheet), reference_id, gl_account FK, period FK, company FK, created_at
- **Service** (`apps/financial/services/project_cost_service.py`):
  - `record_cost(project_id, data)` — add cost to project, create GL entry
  - `get_project_costs(project_id, filters)` — list costs with filters
  - `get_cost_by_category(project_id, period)` — costs grouped by category
  - `get_cost_by_period(project_id, months)` — costs over time
  - `get_actual_vs_budget(project_id)` — budget comparison by category
  - `get_project_profitability(project_id)` — revenue vs cost = profit
- **API** (`apps/financial/api/project_cost_api.py`):
  - Cost CRUD, cost reports, profitability, budget comparison

### Frontend (React)
- **Project Cost Page**: list of all costs for project with filters
- **Cost Entry Form**: add cost (manual or from invoice/timesheet)
- **Cost by Category**: pie chart showing cost breakdown
- **Actual vs Budget**: bar chart comparison
- **Project Profitability**: revenue, cost, profit, margin

### Cost Recording Sources
```
Materials: from GRN (link to stock movement)
Labour: from timesheet (hours × hourly rate)
Subcontractors: from supplier invoice (link to invoice)
Equipment: from equipment log (hours × rate)
Overhead: from cost allocation formula
```
