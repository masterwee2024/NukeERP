# T075c — Marginal Costing (vs Absorption Costing)

- **Phase**: 6
- **Depends On**: T075b
- **Estimated Effort**: 2 days

## What Is Being Built
Marginal costing alongside absorption costing. Contribution margin calculation (Sales - Variable Costs). Break-even analysis. CVP (Cost-Volume-Profit) analysis. Comparison report showing profit difference between absorption and marginal costing.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/mrp/models.py`):
  - `MarginalCostProfile`: id, item FK, variable_material_cost, variable_labour_cost, variable_overhead_cost, selling_price, contribution_margin, contribution_margin_percent, period FK, company FK, created_at
- **Service** (`apps/mrp/services/marginal_costing_service.py`):
  - `build_marginal_profile(item_id, period)` — calculate variable costs and contribution
  - `get_contribution_margin(item_id)` — selling price - variable costs
  - `get_break_even_units(item_id)` — fixed costs / contribution margin per unit
  - `get_break_even_revenue(item_id)` — fixed costs / contribution margin %
  - `get_cvp_analysis(item_id, target_profit)` — units needed for target profit
  - `compare_absorption_vs_marginal(company, period)` — profit comparison
- **Key Formulas**:
  ```
  Contribution Margin = Selling Price - Variable Costs
  Contribution Margin % = Contribution Margin / Selling Price × 100

  Break-Even Units = Total Fixed Costs / Contribution Margin per Unit
  Break-Even Revenue = Total Fixed Costs / Contribution Margin %

  Target Profit Units = (Fixed Costs + Target Profit) / Contribution Margin per Unit

  Absorption Profit - Marginal Profit = Fixed Overhead in Closing Stock - Fixed Overhead in Opening Stock
  ```

### Frontend (React)
- **Contribution Margin Report**: per item with margin %
- **Break-Even Analysis**: units and revenue break-even
- **CVP Chart**: volume-profit relationship
- **Absorption vs Marginal Comparison**: profit difference analysis
