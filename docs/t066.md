# T065 — Bill of Materials (BOM)

- **Phase**: 6
- **Depends On**: T041, T042
- **Estimated Effort**: 4 days

## What Is Being Built
`BOM` model: parent item, component item, quantity, UOM, scrap %, operation sequence. Multi-level BOM tree view. Single-level & indented BOM report. Where-used report.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/mrp/models.py`):
  - `BOM`: item FK (parent), description, is_active, is_default, version, effective_date, company FK
  - `BOMLine`: bom FK, line_number, component_item FK, quantity, uom FK, scrap_percent, operation_number, notes
- **Service**: CRUD, tree building (multi-level), where-used query, cost roll-up
- **API**: BOM CRUD + tree + where-used + cost endpoints

### Frontend (React)
- `BOMListPage` — table with item filter
- `BOMFormPage` — create/edit with line items, component lookup
- `BOMTreePage` — multi-level tree view with expandable nodes
- `WhereUsedPage` — shows which BOMs use a specific component
