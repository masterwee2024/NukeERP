# T074 — Product Costing

- **Phase**: 6
- **Depends On**: T062, T065, T068
- **Estimated Effort**: 3 days

## What Is Being Built
Standard cost roll-up (BOM material cost + routing labour/overhead). Actual cost tracking via WO (material actual + labour actual). Variance analysis: material price/usage variance, labour efficiency/rate variance. Cost update (revalue inventory).

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/mrp/models.py`):
  - `ProductCost`: item FK, cost_type (standard/actual), material_cost, labour_cost, overhead_cost, total_cost, effective_date, company FK
  - `CostVariance`: item FK, period, variance_type (material_price/material_usage/labour_rate/labour_efficiency/overhead_spending/overhead_volume), standard_amount, actual_amount, variance_amount
- **Service**: roll up standard cost, calculate actual cost from WO, compute variances
- **API**: cost inquiry, roll-up, variance report

### Frontend (React)
- `ProductCostPage` — cost breakdown per item (material + labour + overhead)
- `VarianceReportPage` — variance analysis by type and period

## Deliverables Checklist
