# T092 — Advanced Reporting & Dashboards

- **Phase**: 8
- **Depends On**: T022, T023, T024, T025
- **Estimated Effort**: 5 days

## What Is Being Built
Report builder: select fields, filters, grouping, chart type. Save reports. Dashboard: drag-and-drop widgets (KPI cards, charts, tables). Scheduled report email (Celery). Export: PDF, Excel, CSV. Financial dashboard, sales dashboard, inventory dashboard, HR dashboard.

## How It Will Be Built

### Backend (Django)
- **Models**:
  - `SavedReport`: name, report_type, config (JSON — fields, filters, grouping, chart_type), created_by FK, is_public, company FK
  - `Dashboard`: name, layout (JSON — widget positions/sizes), created_by FK, is_default, company FK
  - `DashboardWidget`: dashboard FK, widget_type (kpi/chart/table), title, config (JSON), position_x, position_y, width, height
  - `ScheduledReport`: report FK, frequency (daily/weekly/monthly), recipients (JSON), last_run, next_run, is_active
- **Service**: dynamic query builder from config, chart data generation, dashboard aggregation
- **API**: report CRUD + execute + export, dashboard CRUD + data, scheduled reports

### Frontend (React)
- `ReportBuilderPage` — field selector, filter builder, grouping, chart preview, save
- `DashboardPage` — drag-and-drop grid (react-grid-layout), KPI cards, charts, tables
- `ReportViewerPage` — view saved report with export options
