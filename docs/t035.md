# T035 — Inter-Company Transaction Engine

- **Phase**: 3
- **Depends On**: T013, T021, T030, T032
- **Estimated Effort**: 5 days

## What Is Being Built
Automated inter-company transaction posting. When Company A sells to Company B, the system auto-creates matching entries in both companies. Inter-company account elimination at group level. Consolidation report for group companies.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `InterCompanyConfig`: group_company FK → Company, source_company FK → Company, target_company FK → Company, inter_company_receivable FK → Account, inter_company_payable FK → Account, is_active
  - `InterCompanyTransaction`: source_company FK, target_company FK, source_document_type, source_document_id, target_document_type, target_document_id, status (pending/completed/failed), error_message, created_at, completed_at
  - `ConsolidationEntry`: group_company FK, period FK, account FK, company FK, original_amount, elimination_amount, consolidated_amount
- **Service** (`apps/financial/services/intercompany_service.py`):
  - `create_inter_company_entry(source_invoice)` — detect if customer/supplier is in same group, auto-create matching entry
  - `post_inter_company_journal(source_company, target_company, amount, description)` — DR receivable in source, CR payable in target
  - `get_inter_company_balances(group_company, period)` — all inter-company balances
  - `eliminate_inter_company_balances(group_company, period)` — create elimination entries
  - `generate_consolidation_report(group_company, period)` — combined P&L and BS
- **API** (`apps/financial/api/intercompany_api.py`):
  - `GET /api/v1/financial/inter-company/config/` — list inter-company configs
  - `POST /api/v1/financial/inter-company/config/` — create config
  - `GET /api/v1/financial/inter-company/transactions/` — list transactions
  - `GET /api/v1/financial/inter-company/balances/` — balances by group
  - `POST /api/v1/financial/inter-company/eliminate/` — run elimination
  - `GET /api/v1/financial/inter-company/consolidation/` — consolidation report
- **Signal**: on SupplierInvoice/CustomerInvoice post, check if vendor/customer is in same group → trigger inter-company posting

### Inter-Company Posting Flow
```
Company A sells RM10,000 to Company B:

Company A (source):
  DR Inter-Company Receivable (Company B)   10,000
  CR Revenue                                  10,000

Company B (target — auto-created):
  DR Expense                                  10,000
  CR Inter-Company Payable (Company A)       10,000

Group Consolidation:
  DR Inter-Company Payable (Company B)       10,000  (elimination)
  CR Inter-Company Receivable (Company A)    10,000  (elimination)
  → Net effect: only external revenue/expense remains
```
