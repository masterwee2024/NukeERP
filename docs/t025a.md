# T025a — Generic Report Page + Report UI Improvements

- **Phase**: 2
- **Depends On**: T025 (report engine)
- **Estimated Effort**: 1 day

## What Is Being Built

Unified report page that serves ALL reports via a generic component, plus 8 UI improvements:

1. **Generic Report Page** — Single `ReportPage.tsx` reads `reportCode` from URL, replacing all per-report page components
2. **ReportTable improvements** — Sticky headers, expand/collapse groups, column resize handles, theme token colors
3. **Filter badges** — Active filters shown as removable chips above the table
4. **Summary cards** — Total Debit, Total Credit, Balance metric cards above the table
5. **ViewSwitcher + Chart** — Table/Chart toggle with Recharts stacked bar chart
6. **Report toolbar** — Consolidated action bar (view switcher, export, refresh)
7. **Export polish** — Replace `alert()` with inline status messages
8. **Server-side pagination** — LIMIT/OFFSET in SQL + page controls in table
