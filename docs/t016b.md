# T016b — Org Chart

- **Phase**: 1
- **Depends On**: T076, T016
- **Estimated Effort**: 3 days

## What Is Being Built
Visual organization chart with drag-and-drop restructuring. Uses d3-hierarchy for tree layout. Shows reporting hierarchy from CEO to individual contributors. Approval chains auto-determined from org chart hierarchy. Position control (budgeted vs filled).

## How It Will Be Built

### Frontend (React)
- **OrgChart** (`frontend/src/components/orgchart/OrgChart.tsx`):
  - d3-hierarchy tree layout with SVG rendering
  - Nodes show: employee name, designation, department, photo
  - Expand/collapse branches
  - Zoom and pan controls
  - Full-screen mode

- **OrgChartEditor** (`frontend/src/components/orgchart/OrgChartEditor.tsx`):
  - Drag-and-drop to restructure (move employee under new manager)
  - Drop zone highlighting
  - Undo/redo for structure changes
  - Save button to persist changes
  - Confirmation dialog before save

- **OrgChartNode** (`frontend/src/components/orgchart/OrgChartNode.tsx`):
  - Employee photo/avatar
  - Name, designation, department
  - Badge showing report count
  - Color coding by department

- **OrgChartControls** (`frontend/src/components/orgchart/OrgChartControls.tsx`):
  - Search employee
  - Filter by department
  - Zoom in/out/reset
  - Expand all / Collapse all
  - Export as PNG

- **ApprovalChainHelper** (`frontend/src/components/orgchart/ApprovalChainHelper.tsx`):
  - When configuring workflow approvers, show org chart picker
  - Select employee → auto-suggest approval chain based on reporting hierarchy
  - "Approve up to" level selector (e.g., "up to Department Manager")

### Backend (Django)
- **API** (`apps/hrm/api/orgchart_api.py`):
  - `GET /api/v1/hrm/orgchart/` — full org tree for current company
  - `PUT /api/v1/hrm/orgchart/restructure/` — save restructured hierarchy
  - `GET /api/v1/hrm/orgchart/approval-chain/{employee_id}/` — get approval chain from employee up to CEO
  - `GET /api/v1/hrm/orgchart/approval-chain/{employee_id}/{stop_level}/` — get chain up to specific level

- **Service** (`apps/hrm/services/orgchart_service.py`):
  - `get_org_tree(company)` — build hierarchical tree from Department/Employee relationships
  - `restructure(moves)` — apply batch move operations (employee_id, new_manager_id)
  - `get_approval_chain(employee, stop_level)` — walk up reporting hierarchy

### Integration with Workflow Designer
- When configuring Approve node in T016a, "Select from Org Chart" button opens org chart picker
- User clicks employee in org chart → selects "approve up to" level → auto-fills approvers list
- Approval chain respects company access (only shows employees with UserCompany access)
