# T049d — Stock Receipts (Non-Purchase)

- **Phase**: 4
- **Depends On**: T049
- **Estimated Effort**: 2 days

## What Is Being Built
Stock receipt for items not coming from purchase orders — returns from customers, manufacturing output, opening stock, donations, samples, inter-company transfers. Different receipt types with different GL implications.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `StockReceipt`: id, receipt_number, receipt_date, receipt_type (return_from_customer/production_output/opening_stock/donation/sample/inter_company_transfer), reference_type (optional — links to RMA, WorkOrder, etc.), reference_id (optional), warehouse FK, received_by FK, gl_account FK, notes, status (draft/received/cancelled), company FK, created_at
  - `StockReceiptLine`: receipt FK, item FK, quantity, uom FK, unit_cost, total_cost, lot_number, bin_location FK
- **Service** (`apps/scm/services/stock_receipt_service.py`):
  - `create_receipt(data)` — create receipt record
  - `receive_stock(receipt_id)` — increase stock, create stock movement, GL entry
  - `get_receipt_history(filters)` — past receipts
- **GL Entries by Type**:
  ```
  Return from Customer:
  DR Inventory                      XXX
  CR Sales Returns (contra-revenue) XXX

  Production Output:
  DR Finished Goods Inventory       XXX
  CR Work-in-Progress               XXX

  Opening Stock:
  DR Inventory                      XXX
  CR Opening Balance Equity         XXX

  Donation:
  DR Inventory                      XXX
  CR Donation Income                XXX
  ```

### Frontend (React)
- **Stock Receipt Form**: select type, items, quantities, GL account
- **Receipt List Page**: all receipts with type filter
- **Type-specific fields**: show different fields based on receipt type
