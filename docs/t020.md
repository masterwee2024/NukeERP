# T020 — Django Admin Customization

- **Phase**: 1
- **Depends On**: T011
- **Estimated Effort**: 2 days

## What Is Being Built
Custom Django admin site with company filtering, role-restricted views, inline models for key entities, and custom admin actions (bulk approve, export).

## How It Will Be Built

### Backend (Django)
- **Custom Admin Site**: `apps/core/admin.py`
  - `PyERPAdminSite` class extending `AdminSite`
  - Login template customized with pyERP branding
  - Dashboard with key metrics
- **Model Admins**:
  - `CompanyAdmin`: list_display, search_fields, inlines for FinancialYear
  - `UserAdmin`: custom, list_display with roles, filter by company
  - `RoleAdmin`: inline Permission checkboxes
  - `MenuAdmin`: tree view, inline MenuRole assignments
- **Company Filter Middleware**: all admin queries filtered by `request.user.company_id` (except superadmin)
- **Custom Actions**:
  - Bulk activate/deactivate users
  - Export to CSV/Excel
  - Bulk role assignment
