# T027 — Balance Sheet

- **Phase**: 2
- **Depends On**: T022
- **Estimated Effort**: 3 days

## What Is Being Built
Configurable Balance Sheet template. Comparative periods. Asset = Liability + Equity validation. Export to PDF/Excel.

## How It Will Be Built

### Backend (Django)
- **Service**: `get_balance_sheet(company, period_to, template_id)` — aggregate asset, liability, equity accounts
- **API**: `GET /api/v1/financial/reports/balance-sheet/` — with period and template params

### Frontend (React)
- `BalanceSheetPage` — period selector, comparative periods, template selector, export

## Deliverables Checklist
- [ ] Balance sheet calculation service
- [ ] Asset = Liability + Equity validation
- [ ] Comparative periods support
- [ ] PDF and Excel export
- [ ] React balance sheet page
