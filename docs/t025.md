# T025 — Trial Balance Report

- **Phase**: 2
- **Depends On**: T018, T020
- **Estimated Effort**: 2 days

## What Is Being Built
Trial balance report aggregating GL entries by account. Period range filter. Drill-down to account detail. Export to PDF/Excel. Debit/credit totals must equal.

## How It Will Be Built

### Backend (Django)
- **Service** (`apps/financial/services/report_service.py`):
  - `get_trial_balance(company, period_from, period_to)` — aggregate GL by account, calculate opening + movement + closing balances
- **API** (`apps/financial/api/report_api.py`):
  - `GET /api/v1/financial/reports/trial-balance/` — with query params for period range
  - `GET /api/v1/financial/reports/trial-balance/export/` — PDF or Excel

### Frontend (React)
- `TrialBalancePage` — period range selector, account table with drill-down, export buttons
