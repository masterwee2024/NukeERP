# T206 — Property Management: Collections

- **Phase**: 2
- **Depends On**: T203
- **Estimated Effort**: 2 days

## What Is Being Built
Outstanding rent tracking, dunning letter generation, legal action tracking, bad debt write-off. Collections workflow for overdue rent.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/property/models.py`):
  - `CollectionAction`: id, tenant FK, invoice FK, action_type (reminder/dunning/legal/write_off), action_date, amount, notes, next_action_date, status (pending/completed/cancelled), company FK
  - `LegalAction`: id, tenant FK, collection_action FK, filing_date, court_case_no, lawyer_name, amount_claimed, amount_recovered, status (filed/hearing/judgment/enforced/closed), company FK
- **Service**: generate dunning letters, track legal actions, write-off bad debts
- **API**: collection actions, dunning generation, legal action tracking

### Frontend (React)
- **Collections Dashboard**: overdue tenants, amounts, aging
- **Dunning Letter Generator**: batch generate letters
- **Legal Action Tracker**: track cases through court system
