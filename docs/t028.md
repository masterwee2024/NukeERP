# T028 — Cash Flow Statement

- **Phase**: 2
- **Depends On**: T022
- **Estimated Effort**: 3 days

## What Is Being Built
Cash Flow Statement with direct and indirect method. Auto-generated from cash/bank GL entries. Categorizes movements into operations, investing, and financing.

## How It Will Be Built

### Backend (Django)
- **Service**: `get_cash_flow_statement(company, period_from, period_to)` — categorize cash movements
- **API**: `GET /api/v1/financial/reports/cash-flow/`

### Frontend (React)
- `CashFlowPage` — period selector, method toggle (direct/indirect), export

## Deliverables Checklist
- [ ] Cash flow calculation service
- [ ] Direct and indirect method
- [ ] Operations/investing/financing categorization
- [ ] PDF and Excel export
- [ ] React cash flow page

## Success Criteria
- [ ] Net cash flow matches bank balance change
- [ ] Categories are correctly assigned
- [ ] Direct and indirect methods produce same net result
- [ ] All tests pass
