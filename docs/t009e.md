# T009e — Opening Balance Migration

- **Phase**: 0
- **Depends On**: T009d
- **Estimated Effort**: 4 days

## What Is Being Built
Migration wizard for opening balances — GL trial balance, AP open invoices, AR open invoices, inventory opening stock, fixed asset opening balances. Step-by-step guided process with validation. Creates opening journal entries and opening transactions as of go-live date.

## How It Will Be Built

### Backend (Django)
- **Service** (`apps/core/services/opening_balance_service.py`):
  - `import_gl_opening balances(data, go_live_date)` — create opening journal entry (DR/CR balancing)
  - `import_ap_opening_balances(data, go_live_date)` — create open AP invoices
  - `import_ar_opening_balances(data, go_live_date)` — create open AR invoices
  - `import_inventory_opening(data, go_live_date)` — create opening stock movements
  - `import_asset_opening(data, go_live_date)` — create fixed asset records with opening NBV
  - `validate_gl_balance(data)` — check debits = credits
  - `validate_references(data)` — check account codes, supplier codes, customer codes exist
  - `get_migration_summary(company)` — summary of all imported opening data
  - `rollback_opening_balances(company)` — remove all opening data

- **Migration Wizard Steps**:
  ```
  Step 1: Go-Live Date
  ├── Select the date from which the system will be live
  └── All opening balances are as of this date

  Step 2: GL Opening Balance
  ├── Download trial balance template (account_code, debit, credit)
  ├── Enter balances from old system's trial balance
  ├── Upload CSV
  ├── Validate: debits = credits, all accounts exist
  ├── Create opening journal entry (DR accounts with debit balance, CR accounts with credit balance)
  └── Import

  Step 3: AP Opening Balance
  ├── Download AP template (supplier_code, invoice_no, invoice_date, due_date, amount, currency)
  ├── Enter unpaid supplier invoices from old system
  ├── Upload CSV
  ├── Validate: supplier exists, amounts > 0, due dates valid
  ├── Create supplier invoices with status "open"
  └── Import

  Step 4: AR Opening Balance
  ├── Download AR template (customer_code, invoice_no, invoice_date, due_date, amount, currency)
  ├── Enter unpaid customer invoices from old system
  ├── Upload CSV
  ├── Validate: customer exists, amounts > 0, due dates valid
  ├── Create customer invoices with status "open"
  └── Import

  Step 5: Inventory Opening
  ├── Download stock template (item_code, warehouse_code, quantity, unit_cost)
  ├── Enter stock quantities and costs from old system
  ├── Upload CSV
  ├── Validate: item exists, warehouse exists, qty ≥ 0, cost > 0
  ├── Create opening stock movement (type: opening_stock)
  └── Import

  Step 6: Fixed Asset Opening
  ├── Download asset template (asset_code, name, category, purchase_date, cost, accumulated_depreciation, useful_life)
  ├── Enter asset data from old system
  ├── Upload CSV
  ├── Validate: category exists, dates valid, cost > 0, accum_depr ≤ cost
  ├── Create fixed asset records with opening NBV
  └── Import

  Step 7: Review & Confirm
  ├── Summary of all imported data
  ├── GL balance verification (debits = credits)
  ├── Validation report (errors, warnings)
  ├── Confirm go-live
  └── Lock migration period
  ```
