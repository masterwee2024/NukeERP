# T070 — MRP Run Engine

- **Phase**: 6
- **Depends On**: T045, T066
- **Estimated Effort**: 5 days

## What Is Being Built
Netting calculation: gross requirements - (on-hand + scheduled receipts - allocated) = net requirements. Lead time offset. Planned order generation (planned PO or planned WO). Action messages (expedite/defer/cancel). MRP pegging (trace demand source).

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/mrp/models.py`):
  - `MRPResult`: item FK, period, gross_requirements, scheduled_receipts, projected_available, net_requirements, planned_order_receipt, planned_order_release, action_message
  - `MRPPegging`: mrp_result FK, demand_type (sales_order/mo/forecast), demand_reference, quantity, due_date
- **Service** (`apps/mrp/services/mrp_service.py`):
  - `run_mrp(company, planning_horizon)` — full MRP run
  - `get_mrp_results(company)` — results grid
  - `get_pegging(item, period)` — trace demand source
- **API**: run MRP, view results, view pegging
