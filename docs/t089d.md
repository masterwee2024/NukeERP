# T089d — Document Template Engine

- **Phase**: 2
- **Depends On**: T009
- **Estimated Effort**: 4 days

## What Is Being Built
Document template engine — Jinja2-based template rendering for business documents (invoices, quotations, POs, payslips, etc.). Template storage in database, variable resolution from DB data, conditional logic, loops for line items, QR code and barcode generation, PDF rendering via WeasyPrint.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/core/models.py`):
  - `DocumentTemplate`: id, name, document_type (invoice/quotation/po/do/credit_note/receipt/payslip/statement/contract/other), content (HTML/JSON — template content), format (A4/Letter/A5), orientation (portrait/landscape), language (en/ms), is_default, is_active, company FK, version, created_by FK, created_at, updated_at
  - `TemplateVariable`: id, template FK, variable_name, source_model, source_field, data_type (string/number/date/currency/image/qrcode/barcode), description, is_required, default_value
  - `TemplateVersion`: id, template FK, version, content, changed_by FK, change_notes, created_at

- **Service** (`apps/core/services/template_engine.py`):
  - `render_template(template_id, context_data)` — render template with Jinja2
  - `resolve_variables(template_id, document_id)` — fetch data from DB
  - `generate_pdf(template_id, document_id)` — render and convert to PDF
  - `generate_preview(template_id, sample_data)` — preview with sample data
  - `validate_template(template)` — check for syntax errors

- **Template Variables** (Jinja2 syntax):
  ```handlebars
  {{variable}}                          — simple variable
  {{variable | format:"RM #,##0.00"}}  — currency formatting
  {{variable | format:"DD/MM/YYYY"}}   — date formatting
  {{#if condition}}...{{/if}}           — conditional
  {{#each items}}...{{/each}}          — loop
  {{@index_plus_one}}                  — loop counter
  {{qr_code data}}                     — QR code generation
  {{barcode data}}                     — barcode generation
  {{company_logo}}                     — company logo image
  ```

- **PDF Generation** (`apps/core/services/pdf_generator.py`):
  - `render_html(template_content, context)` — Jinja2 render
  - `html_to_pdf(html)` — WeasyPrint conversion
  - `add_page_numbers(pdf)` — add page numbers
  - `add_watermark(pdf, text)` — optional watermark

- **API** (`apps/core/api/template_api.py`):
  - Template CRUD
  - `POST /api/v1/templates/{id}/preview/` — preview with sample data
  - `POST /api/v1/templates/{id}/render/{doc_type}/{doc_id}/` — render for specific document
  - `GET /api/v1/templates/{id}/render/{doc_type}/{doc_id}/pdf/` — download PDF
  - `GET /api/v1/templates/{id}/variables/` — list available variables

### Template Example (Invoice)
```html
<html>
<head>
  <style>
    body { font-family: Arial; font-size: 10pt; }
    .header { text-align: center; margin-bottom: 20px; }
    .logo { max-width: 200px; }
    table { width: 100%; border-collapse: collapse; margin: 20px 0; }
    th, td { border: 1px solid #ddd; padding: 8px; text-align: left; }
    th { background-color: #f2f2f2; }
    .total { font-weight: bold; text-align: right; }
    .footer { margin-top: 30px; font-size: 8pt; color: #666; }
  </style>
</head>
<body>
  <div class="header">
    <img src="{{company_logo}}" class="logo">
    <h1>{{company.name}}</h1>
    <p>{{company.address}}</p>
  </div>

  <h2>INVOICE</h2>
  <p>Invoice No: {{invoice.number}}</p>
  <p>Date: {{invoice.date | format:"DD/MM/YYYY"}}</p>

  <table>
    <tr>
      <th>#</th><th>Item</th><th>Description</th><th>Qty</th><th>Price</th><th>Amount</th>
    </tr>
    {{#each lines}}
    <tr>
      <td>{{@index_plus_one}}</td>
      <td>{{item_code}}</td>
      <td>{{description}}</td>
      <td>{{quantity}}</td>
      <td>{{unit_price | format:"RM #,##0.00"}}</td>
      <td>{{amount | format:"RM #,##0.00"}}</td>
    </tr>
    {{/each}}
  </table>

  <div class="total">
    <p>Subtotal: {{subtotal | format:"RM #,##0.00"}}</p>
    <p>SST ({{sst_rate}}%): {{sst_amount | format:"RM #,##0.00"}}</p>
    <p>Grand Total: {{grand_total | format:"RM #,##0.00"}}</p>
  </div>

  {{#if show_sst}}
  <p>SST Registration No: {{company.sst_no}}</p>
  {{/if}}

  <div class="footer">
    {{qr_code invoice.number}}
  </div>
</body>
</html>
```
