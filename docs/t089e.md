# T089e — Document Template Editor

- **Phase**: 2
- **Depends On**: T089d
- **Estimated Effort**: 5 days

## What Is Being Built
WYSIWYG document template editor using TipTap (ProseMirror-based). Users design document layouts visually: text, tables, images, variables, conditionals, QR codes, barcodes. Live preview with sample data. No HTML knowledge required.

## How It Will Be Built

### Frontend (React)
- **TemplateEditor** (`frontend/src/components/templates/TemplateEditor.tsx`):
  - TipTap editor with custom extensions
  - Toolbar: text formatting, insert table, insert image, insert variable, insert conditional, insert QR/barcode
  - Left panel: variable picker (from data source)
  - Right panel: properties (font, size, color, alignment)
  - Bottom panel: preview toggle

- **TipTap Extensions** (`frontend/src/components/templates/extensions/`):
  - `VariableExtension` — inline node for {{variable}}, displays as pill/badge
  - `ConditionalExtension` — block node for {{#if}}...{{/if}}, shows condition label
  - `LoopExtension` — block node for {{#each}}...{{/each}}, shows loop label
  - `QRCodeExtension` — inline node for {{qr_code}}, shows placeholder
  - `BarcodeExtension` — inline node for {{barcode}}, shows placeholder
  - `CompanyLogoExtension` — image node for {{company_logo}}

- **VariablePicker** (`frontend/src/components/templates/VariablePicker.tsx`):
  - List of available variables from template config
  - Categorized: Company, Document, Customer/Supplier, Lines, Totals, System
  - Click to insert at cursor position
  - Drag to position

- **TableBuilder** (`frontend/src/components/templates/TableBuilder.tsx`):
  - Insert table with configurable rows/columns
  - Header row styling
  - {{#each}} loop for dynamic rows
  - Column width adjustment

- **TemplatePreview** (`frontend/src/components/templates/TemplatePreview.tsx`):
  - Render template with sample data
  - Show as PDF preview
  - Toggle between edit and preview modes
  - Print preview

- **TemplateListPage** (`frontend/src/components/templates/TemplateListPage.tsx`):
  - List all templates by document type
  - Filter by type, language, company
  - Quick actions: edit, preview, clone, set default

- **TemplateFormPage** (`frontend/src/components/templates/TemplateFormPage.tsx`):
  - Template metadata (name, type, format, language)
  - Editor canvas
  - Save/preview buttons

### Library
- `@tiptap/react` — WYSIWYG editor
- `@tiptap/starter-kit` — basic formatting
- `@tiptap/extension-table` — table support
- `@tiptap/extension-image` — image insertion
- `@tiptap/extension-text-align` — alignment
