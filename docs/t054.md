# T053 — Goods Receiving (GRN)

- **Phase**: 4
- **Depends On**: T045, T049
- **Estimated Effort**: 4 days

## What Is Being Built
`GoodsReceiptNote` against PO. Partial receipt, over-receipt tolerance. QC hold on receipt. Lot/serial number capture. Auto-create stock movement.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `GoodsReceiptNote`: grn_number, purchase_order FK, receipt_date, receiver FK, warehouse FK, status (draft/inspected/accepted/rejected), company FK
  - `GoodsReceiptNoteLine`: grn FK, po_line FK, item FK, quantity_received, quantity_accepted, quantity_rejected, uom FK, lot_number, serial_numbers (JSONField), bin_location FK, notes
  - `QCInspection`: grn FK, grn_line FK, inspector FK, result (pass/fail/hold), notes, inspection_date
- **Service**: CRUD against PO, validate quantities (tolerance), create stock movements, QC workflow
- **API**: GRN CRUD + inspect + accept + reject
