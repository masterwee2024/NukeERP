# T059 — Customer Master

- **Phase**: 5
- **Depends On**: T010, T026
- **Estimated Effort**: 3 days

## What Is Being Built
`Customer` model: code, name, SST registration number, tax code defaults, credit limit, payment terms, multiple contacts & addresses, GL receivable account, price category. 360° view dashboard (orders, invoices, payments, tickets).

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/crm/models.py`):
  - `Customer`: code (unique globally), name, registration_no, sst_no, email, phone, credit_limit (global default), payment_terms (global default), price_category, notes
  - `CustomerContact`: customer FK, name, title, email, phone, is_primary
  - `CustomerAddress`: customer FK, address_type (billing/shipping/both), address, city, state, postcode, country, is_default
  - `CustomerCompany`: customer FK, company FK, credit_limit (override, null = use global), payment_terms (override, null = use global), gl_receivable_account FK, is_active (per company), unique(customer, company)
- **Service**: CRUD, 360° view aggregation
- **API**: CRUD + 360° view endpoint

### Frontend (React)
- `CustomerListPage` — table with search, credit limit filter
- `CustomerFormPage` — create/edit with contacts and addresses
- `CustomerDetailPage` — 360° dashboard: recent orders, invoices, payments, tickets
