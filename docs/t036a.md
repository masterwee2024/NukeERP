# T036a — Asset Revaluation

- **Phase**: 3
- **Depends On**: T036
- **Estimated Effort**: 2 days

## What Is Being Built
Asset revaluation to increase or decrease asset carrying value to fair value. Revaluation surplus/deficit tracked in equity. Revalued amount used for future depreciation. Compliant with MFRS 116 (Property, Plant and Equipment).

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/assets/models.py`):
  - `AssetRevaluation`: id, fixed_asset FK, revaluation_date, revalued_amount, previous_carrying_amount, revaluation_surplus (if positive), revaluation_deficit (if negative), revaluation_method (direct/indirect), approved_by FK, company FK, created_at
- **Service** (`apps/assets/services/revaluation_service.py`):
  - `revalue_asset(asset_id, revalued_amount, date)` — update asset cost and carrying value, create revaluation entry
  - `calculate_surplus_deficit(asset, revalued_amount)` — compare revalued amount to carrying value
  - `post_revaluation_gl(revaluation_id)` — GL entry: DR/CR asset, CR/DR revaluation surplus (equity)
  - `adjust_depreciation(asset)` — recalculate future depreciation based on new carrying value
- **API** (`apps/assets/api/revaluation_api.py`):
  - `POST /api/v1/assets/{id}/revalue/` — revalue asset
  - `GET /api/v1/assets/{id}/revaluation-history/` — past revaluations

### GL Entries
```
Asset with carrying value RM80,000 revalued to RM100,000:
DR Fixed Asset                      20,000.00
CR Revaluation Surplus (Equity)    20,000.00

Asset with carrying value RM80,000 revalued to RM60,000:
DR Revaluation Deficit (Equity)    20,000.00
CR Fixed Asset                      20,000.00
```
