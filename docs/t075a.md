# T075a — Overhead Absorption

- **Phase**: 6
- **Depends On**: T068, T028e
- **Estimated Effort**: 3 days

## What Is Being Built
Manufacturing overhead absorption — applying overhead costs to products based on predetermined rates. Multiple absorption methods ( labour hours, machine hours, % of material cost, % of direct cost). Over-absorption / under-absorption analysis. Overhead rate calculation and maintenance.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/mrp/models.py`):
  - `OverheadCategory`: id, name, code, absorption_method (labour_hours/machine_hours/material_percent/direct_cost_percent/fixed_rate), company FK, is_active
  - `OverheadRate`: id, overhead_category FK, work_center FK (optional), rate_per_hour, rate_percent, effective_date, status (draft/active/obsolete), company FK, created_at
  - `OverheadAbsorption`: id, work_order FK, overhead_category FK, absorption_base (hours/amount), base_quantity, rate, absorbed_amount, actual_amount, variance, period FK, company FK, created_at
- **Service** (`apps/mrp/services/overhead_service.py`):
  - `calculate_absorption_rate(category_id, period)` — budget OH / budget base = rate
  - `absorb_overhead(work_order_id)` — apply overhead based on rate and base
  - `get_actual_overhead(category_id, period)` — actual overhead costs
  - `get_absorbed_overhead(category_id, period)` — total absorbed
  - `get_over_under_absorption(category_id, period)` — variance analysis
  - `post_absorption_gl(absorption_id)` — GL entry for absorbed overhead
- **GL Entries**:
  ```
  Absorbed overhead (labour hours × rate):
  DR Work-in-Progress                10,000.00
  CR Overhead Control                10,000.00

  Under-absorption (actual > absorbed):
  DR Under-Absorbed Overhead (P&L)    2,000.00
  CR Overhead Control                 2,000.00

  Over-absorption (absorbed > actual):
  DR Overhead Control                 1,500.00
  CR Over-Absorbed Overhead (P&L)     1,500.00
  ```

### Frontend (React)
- **Overhead Rate Setup**: configure rates per category
- **Absorption Run**: run absorption for period
- **Over/Under Report**: analysis of absorption variance
- **Overhead by Work Centre**: breakdown by work center
