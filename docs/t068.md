# T067 — Work Centers

- **Phase**: 6
- **Depends On**: T010
- **Estimated Effort**: 2 days

## What Is Being Built
`WorkCenter` model: code, name, capacity (hours/day), efficiency %, cost per hour (labour + overhead). Work center calendar/shifts. Capacity load chart.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/mrp/models.py`):
  - `WorkCenter`: code, name, description, capacity_hours_per_day, efficiency_percent, labour_cost_per_hour, overhead_cost_per_hour, setup_cost_per_hour, is_active, company FK
  - `WorkCenterCalendar`: work_center FK, date, available_hours, actual_hours, utilization_percent
- **Service**: CRUD, capacity calculation, load calculation (sum of operation hours per period)
- **API**: CRUD + capacity + load endpoints

### Frontend (React)
- `WorkCenterListPage` — table with capacity and utilization
- `WorkCenterFormPage` — create/edit
- `CapacityLoadPage` — load chart per work center by period

## Deliverables Checklist
- [ ] `WorkCenter` and `WorkCenterCalendar` models
- [ ] Capacity calculation (hours × efficiency)
- [ ] Load calculation per work center
- [ ] Capacity load chart
- [ ] React list, form, and load pages
- [ ] All CRUD actions use `useConfirm()` dialog

## Success Criteria

- [ ] Load chart shows utilization per work center

- [ ] All tests pass
