# T016a — Visual Workflow Designer

- **Phase**: 1
- **Depends On**: T016
- **Estimated Effort**: 5 days

## What Is Being Built
Drag-and-drop visual workflow designer using react-flow. Nodes: Start, End, Approve, Condition, Notify, Action. Edges connect nodes with conditional labels. Properties panel for node configuration. Save/load workflow definitions. Company-scoped workflow templates.

## How It Will Be Built

### Frontend (React)
- **WorkflowDesigner** (`frontend/src/components/workflow/WorkflowDesigner.tsx`):
  - react-flow canvas with drag-and-drop nodes
  - Node palette (left panel): draggable node types
  - Properties panel (right side): configure selected node
  - Toolbar: save, load, test, undo/redo, zoom controls
  - Company selector: design workflow for specific company or global template

- **Node Types** (`frontend/src/components/workflow/nodes/`):
  - `StartNode.tsx` — green circle, auto-entry point, no config needed
  - `EndNode.tsx` — red circle, terminal (completed/rejected), status selector
  - `ApproveNode.tsx` — blue diamond, config: approvers (role/user multi-select), approval_type (sequential/parallel), min_approvals, timeout_hours, escalation_node
  - `ConditionNode.tsx` — yellow hexagon, config: field selector (from document type), operator dropdown, value input, true_node/false_node (auto-connected by edges)
  - `NotifyNode.tsx` — purple triangle, config: recipients (role/user), template, channels (push/email/sms/in_app)
  - `ActionNode.tsx` — gray square, config: field, value, description (auto-update document field)

- **Node Palette** (`frontend/src/components/workflow/NodePalette.tsx`):
  - Categorized draggable nodes: Flow (Start/End), Approval (Approve), Logic (Condition), Notification (Notify), Automation (Action)
  - Drag to canvas to add node

- **Properties Panel** (`frontend/src/components/workflow/PropertiesPanel.tsx`):
  - Dynamic form based on selected node type
  - Approve: multi-select approvers (filtered by company access), approval_type radio, min_approvals number, timeout_hours
  - Condition: field dropdown (from PageConfig fields of document type), operator dropdown, value input
  - Notify: recipient multi-select, template dropdown, channel checkboxes
  - All selections validated against company access (UserCompany)

- **Edge Labels** (`frontend/src/components/workflow/EdgeLabelInput.tsx`):
  - Editable edge labels ("Approved", "Rejected", "Amount >= 50000")
  - Condition edges auto-labeled from condition config

- **Workflow List Page** (`frontend/src/components/workflow/WorkflowListPage.tsx`):
  - List all workflows by module/document type
  - Clone workflow to company
  - Version history

### Library
- `reactflow` — flowchart canvas, nodes, edges, drag-drop
- No other heavy dependencies

### Company Scoping
- Global template workflows can be cloned to any company
- Company-specific workflows can override templates
- Approver selection filtered by UserCompany access
- Warning shown if selected approver doesn't have company access
