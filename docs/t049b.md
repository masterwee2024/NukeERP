# T049b — Cost Adjustments

- **Phase**: 4
- **Depends On**: T049
- **Estimated Effort**: 2 days

## What Is Being Built
Manual cost adjustment for inventory items. Correct unit cost when cost is incorrect (e.g., wrong purchase price recorded, revaluation). Cost adjustment creates GL entry and updates stock ledger. Audit trail for all cost changes.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `CostAdjustment`: id, adjustment_number, item FK, warehouse FK, old_unit_cost, new_unit_cost, quantity_affected, cost_difference, total_adjustment, reason, gl_account FK, status (draft/posted), approved_by FK, company FK, created_at
- **Service** (`apps/scm/services/cost_adjustment_service.py`):
  - `create_adjustment(data)` — create cost adjustment record
  - `post_adjustment(adjustment_id)` — update stock ledger, create GL entry
  - `get_adjustment_history(item_id, warehouse_id)` — history of cost changes
- **GL Entries**:
  ```
  Cost adjustment: RM10 increase per unit, 100 units affected
  DR Inventory                    1,000.00
  CR Cost Adjustment (P&L)        1,000.00
  ```

### Frontend (React)
- **Cost Adjustment Form**: enter item, warehouse, new cost, reason
- **Adjustment History**: list of past adjustments with details
