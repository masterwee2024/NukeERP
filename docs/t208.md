# T208 — Property Management: Dashboard

- **Phase**: 2
- **Depends On**: T207
- **Estimated Effort**: 2 days

## What Is Being Built
Property management dashboard — portfolio overview, occupancy trend, collection performance, arrears summary, maintenance status, upcoming lease expiries.

## How It Will Be Built

### Backend (Django)
- **Service** (`apps/property/services/dashboard_service.py`):
  - `get_dashboard_data(company)` — aggregated KPIs
  - KPIs: total properties, total units, occupancy rate, total rental income, collection rate, total arrears, open maintenance requests, upcoming lease expiries
- **API**: dashboard data endpoint

### Frontend (React)
- **Property Dashboard**: KPI cards, charts, lists
  - Occupancy trend chart (line)
  - Collection rate gauge
  - Arrears by aging (bar chart)
  - Maintenance requests status (pie chart)
  - Upcoming lease expiries (list)
  - Top 5 properties by income (bar chart)
