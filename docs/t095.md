# T094 — Multi-Language (BM + English)

- **Phase**: 8
- **Depends On**: T009
- **Estimated Effort**: 4 days

## What Is Being Built
Django i18n for all model labels, error messages, email templates. react-intl or i18next for frontend UI strings. BM + English translations for all user-facing text. Language switcher in header. BM document templates (invoices, payslips, reports).

## How It Will Be Built

### Backend (Django)
- **i18n**: `gettext_lazy` for all user-facing strings
- **Locale files**: `locale/ms/` for Bahasa Malaysia translations
- **Document templates**: BM versions of WeasyPrint HTML templates

### Frontend (React)
- **Library**: `react-intl` or `i18next`
- **Locale files**: `src/locales/en.json` and `src/locales/ms.json`
- **Language Switcher**: dropdown in header, persists to localStorage
- **Translation coverage**: all UI strings wrapped in `t()` function
