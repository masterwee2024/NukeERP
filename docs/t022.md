# T022 — Journal Entry CRUD

- **Phase**: 2
- **Depends On**: T014, T018
- **Estimated Effort**: 4 days

## What Is Being Built
Journal entry creation with multiple debit/credit lines. Auto-balancing validation (sum debits = sum credits). Edit unposted entries. Delete with reversal. Reference document linking (invoice, payment, etc.).

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `JournalEntry`: entry_number (from T014), date, description, reference, status (draft/posted/reversed), company FK, financial_year FK, fiscal_period FK, total_debit, total_credit, reversal_of FK (self), created_by FK
  - `JournalEntryLine`: journal_entry FK, account FK, debit, credit, description, line_number, tax_code FK (optional)
- **Service** (`apps/financial/services/journal_service.py`):
  - `create_journal_entry(data)` — validate balance (DR=CR), validate period open, assign number
  - `update_journal_entry(id, data)` — only if status=draft
  - `delete_journal_entry(id)` — only if status=draft
  - `reverse_journal_entry(id)` — create reversing entry (swap DR/CR), link original
- **API** (`apps/financial/api/journal_api.py`):
  - `GET /api/v1/financial/journal-entries/` — list with filters
  - `POST /api/v1/financial/journal-entries/` — create
  - `GET /api/v1/financial/journal-entries/{id}/` — detail with lines
  - `PUT /api/v1/financial/journal-entries/{id}/` — update (draft only)
  - `DELETE /api/v1/financial/journal-entries/{id}/` — delete (draft only)
  - `POST /api/v1/financial/journal-entries/{id}/reverse/` — reverse
