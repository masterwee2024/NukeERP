# T096 — Security Audit

- **Phase**: 8
- **Depends On**: T088
- **Estimated Effort**: 3 days

## What Is Being Built
OWASP Top 10 review. Dependency vulnerability scan (pip-audit + npm audit). SQL injection, XSS, CSRF protection verification. Rate limiting on auth endpoints. Penetration testing. Data encryption at rest (sensitive fields).

## How It Will Be Built

### Security Checklist
1. **OWASP Top 10 review**: A01-A10 systematic check
2. **Dependency scan**: `pip-audit` for Python, `npm audit` for Node.js
3. **SQL injection**: Django ORM protects against most; raw queries reviewed
4. **XSS**: React auto-escapes; any `dangerouslySetInnerHTML` reviewed
5. **CSRF**: Django CSRF middleware + SameSite cookies
6. **Rate limiting**: `django-ratelimit` on login, password reset, API endpoints
7. **Encryption**: AES encryption for sensitive fields (bank account, IC number)
8. **JWT security**: short-lived tokens, secure cookie flags
9. **CORS**: strict origin whitelist
10. **Penetration testing**: manual or automated (OWASP ZAP)
