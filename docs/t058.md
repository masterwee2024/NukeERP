# T057 — Opportunity Pipeline

- **Phase**: 5
- **Depends On**: T053
- **Estimated Effort**: 3 days

## What Is Being Built
`Opportunity` with Kanban stages (configurable). Expected value, probability %, expected close date. Associated contacts, activities, quotations. Win/loss reasons. Sales forecast report.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/crm/models.py`):
  - `OpportunityStage`: name, probability_percent, stage_order, color, company FK
  - `Opportunity`: name, customer FK, stage FK, expected_value, probability, expected_close_date, actual_close_date, won_reason, lost_reason, assigned_to FK, company FK, notes
  - `OpportunityActivity`: opportunity FK, activity_type, subject, description, date, user FK
- **Service**: CRUD, stage transition, win/loss, forecast calculation
- **API**: CRUD + stage update + forecast + win/loss endpoints

### Frontend (React)
- `OpportunityPipelinePage` — Kanban board with drag-and-drop stages
- `OpportunityFormPage` — create/edit
- `SalesForecastPage` — forecast report by stage and period
