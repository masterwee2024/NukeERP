# T029 — Tax Codes & SST Engine

- **Phase**: 2
- **Depends On**: T010
- **Estimated Effort**: 3 days

## What Is Being Built
`TaxCode` model with code, rate%, type (Sales/Service/Exempt/Zero-rated/Out-of-scope). `TaxRate` with effective dates for rate changes. Tax calculation on invoice lines. SST-02 return data generation.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `TaxCode`: code (e.g., "SR", "ZR", "ES", "OS"), name, rate_percent, tax_type (sales/service/exempt/zero_rated/out_of_scope), is_active, company FK
  - `TaxRate`: tax_code FK, rate_percent, effective_from, effective_to, is_current
- **Service** (`apps/financial/services/tax_service.py`):
  - `calculate_tax(amount, tax_code, date)` — lookup rate effective on date
  - `get_sst_return(company, period)` — aggregate output tax (sales) and input tax (purchases)
- **API**: CRUD for tax codes, tax rate lookup, SST-02 data endpoint

### Default Tax Codes (seeded)
| Code | Name | Rate | Type |
|---|---|---|---|
| SR | Standard Rate (Sales) | 8% | Sales |
| SR-S | Standard Rate (Service) | 8% | Service |
| ZR | Zero-Rated | 0% | Zero-rated |
| ES | Exempt Supply | 0% | Exempt |
| OS | Out of Scope | 0% | Out-of-scope |
| DX | Deemed Supply (Sales) | 8% | Sales |
| IM | Input Tax (Purchases) | varies | Purchase |
