# T046 — Multi-Warehouse Setup

- **Phase**: 4
- **Depends On**: T010
- **Estimated Effort**: 2 days

## What Is Being Built
`Warehouse` model (code, name, address). Warehouse assignment per inventory transaction. Stock report by warehouse.

## How It Will Be Built

### Backend (Django)
- **Model** (`apps/scm/models.py`):
  - `Warehouse`: code (unique), name, address, city, state, postcode, is_default, is_active, manager FK (optional), company FK
- **Service**: CRUD, default warehouse logic
- **API**: Warehouse CRUD

### Frontend (React)
- `WarehouseListPage` — table with stock summary per warehouse
- `WarehouseFormPage` — create/edit
