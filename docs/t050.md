# T049 — Stock Valuation Report

- **Phase**: 4
- **Depends On**: T045
- **Estimated Effort**: 2 days

## What Is Being Built
Inventory valuation by warehouse, category, item. FIFO layers view. Weighted average cost view. Period-end stock value for balance sheet. Stock aging report.

## How It Will Be Built

### Backend (Django)
- **Service** (`apps/scm/services/valuation_service.py`):
  - `get_valuation_report(company, warehouse, category, as_at_date)` — aggregate stock value
  - `get_fifo_layers(item, warehouse)` — show individual cost layers
  - `get_stock_aging(company, warehouse)` — days since receipt per batch
  - `get_period_end_stock_value(company, period)` — for BS reporting
- **API**: Valuation reports, FIFO layers, aging

### Frontend (React)
- `StockValuationPage` — valuation table with filters, export
- `StockAgingPage` — aging buckets (0-30, 31-60, 61-90, 90+ days)
