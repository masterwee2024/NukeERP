# T048 — Stock Movements & Ledger

- **Phase**: 4
- **Depends On**: T041, T043
- **Estimated Effort**: 5 days

## What Is Being Built
Stock movements: GRN (in), delivery (out), transfer (between warehouse), adjustment, return. `StockLedger` table with running balance, cost, reference. FIFO/weighted average cost calculation. Negative stock prevention (configurable).

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `StockMovement`: item FK, warehouse FK, movement_type (grn/delivery/transfer/adjustment/return), quantity_in, quantity_out, unit_cost, total_cost, reference_document, reference_id, date, company FK, created_by FK
  - `StockLedger`: item FK, warehouse FK, date, quantity_in, quantity_out, balance_qty, unit_cost, total_value, running_balance_value, stock_movement FK
- **Service** (`apps/scm/services/stock_service.py`):
  - `create_stock_movement(data)` — validate stock availability (if negative_stock_prevented), update ledger, calculate cost
  - `get_stock_balance(item, warehouse, date)` — running balance query
  - `get_stock_valuation(item, warehouse)` — FIFO layers or weighted average
  - `transfer_stock(item, from_warehouse, to_warehouse, qty)` — two movements (out + in)
- **API**: Stock movement CRUD, balance query, valuation, transfer
