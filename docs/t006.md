# T006 — Responsive Layout Shell

- **Phase**: 0
- **Depends On**: T001, T005
- **Estimated Effort**: 3 days

## What Is Being Built
The application layout: sidebar + header + main content area. Mobile: hamburger button toggles slide-out overlay sidebar. Desktop: persistent sidebar (240px) with collapsible icon-only mode (64px). Global `overflow-x: hidden` enforced. CSS variable theme tokens for light/dark mode.

## How It Will Be Built

### Frontend (React)
- **Layout Component**: `frontend/src/components/Layout/AppLayout.tsx`
  - Sidebar + Header + Content wrapper
  - CSS: `overflow-x: hidden` on `html`, `body`, and all wrapper divs
  - Tailwind: `w-full max-w-full overflow-x-hidden` on layout container
- **Sidebar Component**: `frontend/src/components/Layout/Sidebar.tsx`
  - Reads menu from `useMenu()` hook (dynamic, not hardcoded)
  - Mobile: overlay with backdrop, slide-in/out animation
  - Desktop: fixed position, collapsible to icon-only mode
  - Expandable menu groups (accordion style)
  - Active route highlighting
- **Header Component**: `frontend/src/components/Layout/Header.tsx`
  - Hamburger button (mobile), breadcrumb, user avatar dropdown
  - Notification bell (links to T016 notifications)
  - Company Switcher dropdown (next to user avatar) — shows current company, lists accessible companies, click to switch active company context
- **Theme**: CSS variables in `frontend/src/styles/theme.css`
  - Light/dark mode toggle
  - Color tokens: primary, secondary, background, surface, text, border
- **Responsive breakpoints tested**: 375px, 768px, 1440px

### Components
- `AppLayout.tsx` — main layout wrapper
- `Sidebar.tsx` — navigation sidebar
- `Header.tsx` — top bar
- `SidebarItem.tsx` — individual menu item with icon
- `SidebarGroup.tsx` — expandable menu group

## Notes
- Theme tokens defined in `index.css` via TailwindCSS 4 `@theme` directive instead of separate `theme.css` — functionally equivalent
- SidebarItem renders active state with `bg-primary-600`, group items show `bg-secondary-700` when child is active
- Company Switcher stores company ID in `localStorage("current_company_id")` — API interceptor reads it for `X-Company-Id` header; backend T013 required for full switching
- Sidebar is a single `aside` element with `-translate-x-full`/`translate-x-0` transform for all viewports (no separate desktop/mobile rendering)
- Hamburger button (`aria-label="Open menu"`) visible on all screen sizes (no `lg:hidden`)
- Loading state shows 8 skeleton placeholders with `animate-pulse`
