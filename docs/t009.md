## What Is Being Built
Django Ninja API configuration with `/api/docs` Swagger UI, base CRUD pattern, error response schema, pagination, sorting, filtering utilities, API versioning (`/api/v1/`), and **concurrency control** (timestamps, optimistic locking, pessimistic locking, 409 handling).

## How It Will Be Built

### Backend (Django Ninja)
- **Main API**: `apps/core/api/api.py` — `NinjaAPI` instance with auth, CORS, versioning
- **Base CRUD mixin**: `apps/core/api/base.py`
  - Generic list/create/update/delete views
  - Consistent pagination: `{ "count": N, "results": [...] }`
  - Sorting: `?sort=-created_at&sort=name`
  - Filtering: `?search=invoice&status=draft&date_from=2024-01-01`
  - **Optimistic locking**: every update validates `updated_at` matches last known → 409 Conflict if mismatch
  - **Pessimistic locking**: `select_for_update()` for financial/inventory operations
- **Error schema**: `apps/core/schemas.py`
  - `{ "detail": "message" }` for single errors
  - `{ "errors": { "field_name": ["error 1", "error 2"] } }` for validation
  - `{ "detail": "Record was modified by another user", "conflict": true }` for 409
- **Versioning**: all endpoints under `/api/v1/`
- **Swagger**: auto-generated at `/api/docs`

### Concurrency Control (`apps/core/mixins/models.py`)

```python
class TimeStampedModel(models.Model):
    """Adds created_at and updated_at to every model."""
    created_at = models.DateTimeField(auto_now_add=True, db_index=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        abstract = True

class ConcurrencyModel(TimeStampedModel):
    """Adds optimistic locking via version field. Every model MUST inherit this."""
    version = models.PositiveIntegerField(default=1)

    class Meta:
        abstract = True

    def save(self, *args, **kwargs):
        if self.pk:
            # Optimistic locking: verify version hasn't changed
            original = self.__class__.objects.get(pk=self.pk)
            if original.version != self.version:
                raise ConcurrencyError(
                    "Record was modified by another user. Please reload and try again."
                )
            self.version += 1
        super().save(*args, **kwargs)

class ConcurrencyError(Exception):
    """Raised when optimistic locking detects a conflict."""
    pass
```

### API Update Pattern (Optimistic Locking)

```python
@router.put("/invoices/{id}/")
def update_invoice(request, id: UUID, data: InvoiceUpdateSchema):
    with transaction.atomic():
        invoice = SupplierInvoice.objects.select_for_update().get(id=id)

        # Validate updated_at matches (optimistic lock check)
        if invoice.updated_at != data.updated_at:
            raise HttpError(
                status_code=409,
                message="Record was modified by another user. Please reload and try again."
            )

        # Update fields
        for field, value in data.dict(exclude_unset=True).items():
            setattr(invoice, field, value)

        invoice.save()  # version auto-increments
        return invoice
```

### API Pessimistic Locking (Financial/Inventory)

```python
@router.post("/invoices/{id}/post/")
def post_invoice(request, id: UUID):
    with transaction.atomic():
        # Lock the row until transaction completes
        invoice = SupplierInvoice.objects.select_for_update().get(id=id)

        # Validate status
        if invoice.status != 'approved':
            raise HttpError(400, "Invoice must be approved before posting")

        # Post to GL (also uses select_for_update on GL entries)
        post_to_gl(invoice)

        invoice.status = 'posted'
        invoice.save()
        return {"detail": "Invoice posted successfully"}
```

### Frontend Concurrency Handling

- **API client**: `frontend/src/lib/api.ts`
  - Axios instance with base URL `/api/v1/`
  - Request interceptor: injects auth token
  - Response interceptor: handles 401 (token refresh), **409 (concurrency conflict)**
  - Typed API functions per module
- **Debounce hook**: `frontend/src/hooks/useDebounce.ts`
  - `useDebounce(value, delay)` — debounce any value (default 300ms)
  - Used on all search inputs to prevent API flooding
  - Pattern: `const debouncedSearch = useDebounce(search, 300)`

```typescript
// Frontend Axios interceptor for 409
api.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 409) {
      // Show conflict toast
      toast.error("This record was modified by another user. Please reload.");
      // Invalidate cache to force refetch
      queryClient.invalidateQueries();

  }
```

```typescript
const handleSave = async (formData) => {

      ...formData,
```
