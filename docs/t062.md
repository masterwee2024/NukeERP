# T061 — Delivery Order

- **Phase**: 5
- **Depends On**: T045, T057
- **Estimated Effort**: 3 days

## What Is Being Built
`DeliveryOrder` from Sales Order. Pick list generation. Partial delivery. Serial/batch assignment. DO print with signature line. Customer acknowledgment.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/crm/models.py`):
  - `DeliveryOrder`: do_number, sales_order FK, customer FK, delivery_date, warehouse FK, status (draft/dispatched/delivered/cancelled), driver_name, vehicle_no, company FK
  - `DeliveryOrderLine`: do FK, so_line FK, item FK, quantity, uom FK, serial_numbers (JSONField), bin_location FK
- **Service**: CRUD from SO, pick list, partial delivery, stock movement creation on dispatch
- **API**: CRUD + dispatch + deliver endpoints
