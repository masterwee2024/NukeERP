# T063c — Product Warranty

- **Phase**: 5
- **Depends On**: T063
- **Estimated Effort**: 2 days

## What Is Being Built
Product warranty tracking — warranty period per product, warranty claims processing, warranty status by serial number. Link to RMA (T064) for resolution. Warranty expiry alerts. Warranty cost provision.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/crm/models.py`):
  - `Warranty`: id, serial_number FK (optional), item FK, customer FK, sales_invoice FK, warranty_start_date, warranty_end_date, warranty_period_months, status (active/expired/claimed), notes, company FK, created_at
  - `WarrantyClaim`: id, warranty FK, claim_date, fault_description, status (submitted/investigating/repairing/resolved/closed), resolution (repair/replace/refund), rma FK (optional), cost_of_repair, company FK, created_at
- **Service** (`apps/crm/services/warranty_service.py`):
  - `register_warranty(data)` — register warranty on sale
  - `check_warranty(serial_number)` — check if item is under warranty
  - `create_claim(warranty_id, data)` — create warranty claim
  - `resolve_claim(claim_id, resolution)` — resolve with RMA or direct
  - `get_expiring_warranties(days)` — warranties expiring soon
  - `get_warranty_cost_provision(company)` — estimated warranty cost
- **API**: Warranty CRUD, claim CRUD, check warranty, expiry alerts

### Frontend (React)
- **Warranty Check Page**: enter serial number, see warranty status
- **Warranty List Page**: all warranties with status and expiry
- **Claim Form**: create and track warranty claims
- **Expiring Warranties Widget**: dashboard widget
