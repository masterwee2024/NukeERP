# T077 — Attendance Management

- **Phase**: 7
- **Depends On**: T072
- **Estimated Effort**: 3 days

## What Is Being Built
`Attendance` record: date, time in/out, status (present/absent/late/half-day). Biometric data import (CSV). Manual attendance entry. Attendance report with overtime hours. Late deduction calculation.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `Attendance`: employee FK, date, time_in, time_out, status, hours_worked, overtime_hours, late_minutes, remarks, source (manual/biometric/system), company FK
  - `AttendanceSummary`: employee FK, month, year, total_present, total_absent, total_late, total_overtime_hours
- **Service**: CRUD, biometric CSV import, calculate hours/overtime/late, summary generation
- **API**: CRUD + import + summary + report

### Frontend (React)
- `AttendanceListPage` — daily/weekly/monthly view
- `AttendanceFormPage` — manual entry
- `AttendanceImportPage` — CSV upload from biometric device
- `AttendanceReportPage` — summary report per employee/department
