# T023 — Journal Entry Approval & Posting

- **Phase**: 2
- **Depends On**: T013, T019
- **Estimated Effort**: 3 days

## What Is Being Built
Multi-level approval via T013 workflow before posting. Posting creates immutable GL entries in `GeneralLedger` table. Posted entries cannot be edited — only reversed. Period validation on posting date.

## How It Will Be Built

### Backend (Django)
- **Model** (`apps/financial/models.py`):
  - `GeneralLedger`: journal_entry FK, journal_entry_line FK, account FK, date, debit, credit, balance (running), period FK, company FK
- **Service** (`apps/financial/services/posting_service.py`):
  - `submit_for_approval(journal_entry_id)` — create ApprovalRequest via T013
  - `post_journal_entry(journal_entry_id)` — validate period open, create GL entries, update running balances, set status=posted
  - `reverse_posted_entry(journal_entry_id)` — create reversal JE, post it
- **API** (`apps/financial/api/journal_api.py`):
  - `POST /api/v1/financial/journal-entries/{id}/submit/` — submit for approval
  - `POST /api/v1/financial/journal-entries/{id}/post/` — post (after approval)
