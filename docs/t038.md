# T037 — Asset Disposal & Transfer

- **Phase**: 3
- **Depends On**: T032, T033
- **Estimated Effort**: 2 days

## What Is Being Built
Asset disposal (sale, scrap, donation) with gain/loss calculation. Asset transfer between locations/departments/custodians with approval workflow.

## How It Will Be Built

### Backend (Django)
- **Service** (`apps/assets/services/disposal_service.py`):
  - `dispose_asset(asset_id, disposal_date, disposal_type, sale_price)` — calculate gain/loss (sale_price - NBV), update asset status, create disposal JE
  - `transfer_asset(asset_id, to_location, to_department, to_custodian)` — create movement record, update asset
- **API**: dispose + transfer endpoints

## Deliverables Checklist
- [ ] Disposal service with gain/loss calculation
- [ ] GL entries for disposal (DR bank/cash, DR accum depr, CR asset, CR/DR gain/loss)
- [ ] Transfer service with movement tracking

## Success Criteria
