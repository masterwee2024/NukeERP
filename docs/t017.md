# T017 — Numbering Series Engine

- **Phase**: 1
- **Depends On**: T009
- **Estimated Effort**: 2 days

## What Is Being Built
Configurable document numbering system. Each document type (invoice, PO, quotation, etc.) has a numbering rule: prefix + date component + running number. Per-year reset. Concurrency-safe via database lock.

## How It Will Be Built

### Backend (Django)
- **Model** (`apps/core/models.py`):
  - `NumberingSeriesPolicy`: Global template — document_type (unique), prefix, date_format, padding, description
  - `CompanyNumberingSeries`: Per-company counter — policy FK, company FK, next_number, reset_period, last_reset_at
  - `unique_together = (policy, company)` — each company gets one counter per policy
- **Service** (`apps/core/services/numbering_service.py`):
  - `get_next_number(document_type, company)` — uses `select_for_update()` to prevent race conditions
  - Format: `{prefix}{date_component}{running_number}` → e.g., "INV-2024000123"
  - Policy CRUD: create, update, delete
  - Assignment CRUD: assign, update, unassign
