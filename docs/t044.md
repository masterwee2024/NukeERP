# T043 — Loan Management

- **Phase**: 3
- **Depends On**: T018
- **Estimated Effort**: 3 days

## What Is Being Built
Loan master (type, lender, principal, interest rate, start date, tenure). Amortization schedule. Interest accrual JE. Repayment tracking. Balance outstanding.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/treasury/models.py`):
  - `Loan`: loan_number, lender, loan_type (term/overdraft/revolving), principal_amount, interest_rate, start_date, tenure_months, GL_account FK, status (active/settled), company FK
  - `LoanRepayment`: loan FK, date, principal_amount, interest_amount, total_amount, balance_after, reference
  - `LoanInterestAccrual`: loan FK, period, interest_amount, journal_entry FK
- **Service**: generate amortization schedule, calculate interest accrual, record repayment, track outstanding balance
- **API**: loan CRUD, repayment recording, schedule view, accrual run

### Frontend (React)
- `LoanListPage` — list of loans with outstanding balances
- `LoanDetailPage` — amortization schedule, repayment history, accrual history
