# T036 — Depreciation Engine

- **Phase**: 3
- **Depends On**: T032
- **Estimated Effort**: 3 days

## What Is Being Built
Depreciation calculation using SLM (Straight Line Method) and RBM (Reducing Balance Method). Depreciation per period (monthly). Accumulated depreciation tracking. GL integration via journal entry per depreciation run.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/assets/models.py`):
  - `DepreciationSchedule`: fixed_asset FK, period, depreciation_amount, accumulated_depreciation, net_book_value, journal_entry FK (optional)
- **Service** (`apps/assets/services/depreciation_service.py`):
  - `calculate_depreciation(asset, period)` — SLM: cost / useful_life / 12; RBM: NBV × rate / 12
  - `run_depreciation(company, period)` — batch calculate for all active assets, create JEs
  - `get_depreciation_forecast(asset, months)` — projected depreciation
- **API**: run depreciation, view schedule, forecast

### Frontend (React)
- `DepreciationRunPage` — select period, preview calculations, confirm run
- `DepreciationSchedulePage` — view schedule per asset
