# T046 — Unit of Measure (UoM)

- **Phase**: 4
- **Depends On**: T045
- **Estimated Effort**: 3 days

## What Is Being Built
Two-layer Unit of Measure system: **Standard Conversion Units** (system-seeded mathematical constants, locked ratios) and **User-Definable Packaging Units** (created by users, per-item conversions). Conversion formula: `Target Qty = Source Qty × (Source Ratio / Target Ratio)`. Category-based grouping (Weight, Length, Volume, Count).

## Architecture

### Layer 1: Standard Conversion Units (System-Seeded)
- Seeded on app init via `seed_standard_uom` management command
- `is_global = True` — ratios are **locked**, user cannot edit
- Used automatically for conversion — no user input needed
- Categories: Weight (kg, g, t, lb, oz), Length (m, cm, mm, in, ft), Volume (ltr, ml, gal), Count (pcs, dz, gr)

### Layer 2: User-Definable Packaging Units
- Created by users for specific business needs
- `is_global = False` — user creates the UoM record AND defines conversion per item
- Conversion factor stored in `ItemPackaging` table (per-item override)
- Examples: Box (12 pcs for beer, 6 pcs for headphones), Carton (24 cans), Pallet (500 units)

### Conversion Logic
```python
def convert_quantity(item, source_uom, target_uom, quantity):
    # Check for item-specific override first
    source_packaging = ItemPackaging.objects.filter(item=item, uom=source_uom).first()
    source_ratio = source_packaging.conversion_factor if source_packaging else source_uom.ratio_to_base

    target_packaging = ItemPackaging.objects.filter(item=item, uom=target_uom).first()
    target_ratio = target_packaging.conversion_factor if target_packaging else target_uom.ratio_to_base

    return quantity * (source_ratio / target_ratio)
```

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `UoMCategory`: name (unique), reference_uom FK (self-referencing after UoM created), description
  - `UoM`: category FK, name, abbreviation (unique), ratio_to_base (decimal), is_global (bool), is_active, created_at
  - `ItemPackaging`: item FK → Item, uom FK → UoM, conversion_factor (decimal), is_default (bool), uom_type (purchase/stock/sales), unique(item, uom)
- **Service** (`apps/scm/services/uom_service.py`):
  - `convert_quantity(item, source_uom, target_uom, qty)` — conversion with item override
  - `get_conversion_ratio(item, uom)` — returns effective ratio (ItemPackaging or global)
  - `get_uoms_by_category(category_name)` — list UoMs in a category
  - `validate_conversion(item, source_uom, target_uom)` — check both UoMs exist and are compatible
- **API** (`apps/scm/api/uom_api.py`):
  - `GET /api/v1/scm/uom-categories/` — list categories with reference unit
  - `GET /api/v1/scm/uoms/` — list all UoMs (filterable by category, is_global)
  - `POST /api/v1/scm/uoms/` — create user-definable UoM (is_global=False only)
  - `PUT /api/v1/scm/uoms/{id}/` — update user-definable UoM
  - `DELETE /api/v1/scm/uoms/{id}/` — deactivate user-definable UoM
  - `GET /api/v1/scm/items/{id}/packaging/` — list item packaging
  - `POST /api/v1/scm/items/{id}/packaging/` — add item packaging
  - `PUT /api/v1/scm/items/{id}/packaging/{id}/` — update item packaging
  - `DELETE /api/v1/scm/items/{id}/packaging/{id}/` — remove item packaging
  - `POST /api/v1/scm/uoms/convert/` — convert quantity between UoMs
- **Seed Data**: `apps/scm/management/commands/seed_standard_uom.py`

### Frontend (React)
- **UoM List Page**: table of all UoMs grouped by category, filter by is_global
- **UoM Form Page**: create/edit user-definable UoMs (is_global units shown as read-only)
- **ItemPackaging Component**: per-item packaging configuration
  - When user selects `is_global=True` UoM → show info message, hide conversion input
  - When user selects `is_global=False` UoM → show conversion factor input
- **Conversion Calculator**: utility page to test conversions between UoMs

### UI Behavior (Dynamic Field)
```typescript
// In any form where user selects UoM:
function handleUoMChange(selectedUom: UoM) {
  if (selectedUom.is_global === true) {
    // Standard unit — show info, no input needed
    showInfo(`Standard conversion: 1 ${selectedUom.abbreviation} = ${selectedUom.ratio_to_base} ${referenceUnit.abbreviation}`);
    hideConversionInput();
  } else {
    // User-definable — prompt for conversion factor
    showConversionInput(`How many ${referenceUnit.abbreviation} fit into 1 ${selectedUom.abbreviation}?`);
  }
}
```
