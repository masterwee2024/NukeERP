# T034 — Bank Reconciliation

- **Phase**: 2
- **Depends On**: T027, T028, T029, T030
- **Estimated Effort**: 4 days

## What Is Being Built
Upload bank statement (CSV/OFX format). Auto-match rules (amount + date tolerance + reference). Manual match/unmatch. Reconciliation report with outstanding items.

## How It Will Be Built

### Backend (Django)
- **Models**:
  - `BankStatement`: bank_account FK, upload_date, statement_date, file, status (draft/reconciled), company FK
  - `BankStatementLine`: statement FK, date, description, debit, credit, reference, status (unmatched/matched/manually_matched), matched_payment FK (optional), matched_invoice FK (optional)
- **Service**: parse CSV/OFX, auto-match algorithm, manual match, reconciliation report
- **API**: upload statement, list lines, match/unmatch, reconciliation report

### Frontend (React)
- `BankReconciliationPage` — upload statement, split view (bank lines vs ERP entries), match interface, reconciliation summary
