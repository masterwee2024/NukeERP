# T207 — Property Management: Reports

- **Phase**: 2
- **Depends On**: T200, T202, T203, T204
- **Estimated Effort**: 3 days

## What Is Being Built
Property management reports — rent roll, occupancy rate, collection rate, arrears aging, property P&L, utility consumption analysis, maintenance cost report.

## How It Will Be Built

### Backend (Django)
- **Service** (`apps/property/services/report_service.py`):
  - `get_rent_roll(property_id, period)` — all units with rental amounts
  - `get_occupancy_rate(property_id, date)` — occupied vs vacant units
  - `get_collection_rate(property_id, period)` — collected vs invoiced
  - `get_arrears_aging(property_id, as_at_date)` — overdue amounts by aging bucket
  - `get_property_pl(property_id, period)` — property-level P&L
  - `get_utility_consumption(property_id, period)` — consumption trends
  - `get_maintenance_cost(property_id, period)` — maintenance cost by category
  - `get_portfolio_summary(company)` — all properties summary
- **API**: all report endpoints with filters

### Frontend (React)
- **Report Gallery**: all available reports
- **Rent Roll Page**: rent roll with filters
- **Occupancy Dashboard**: occupancy trend chart
- **Collection Report**: collection rate and arrears
- **Property P&L**: revenue and expense by property
