- **Phase**: 2
- **Depends On**: T100, T101, T102

## What Is Being Built
Project profitability reporting. P&L per project, budget vs actual, margin analysis, cash flow by project. Multi-project comparison. Project ranking by profitability.

## How It Will Be Built

### Backend (Django)
- **Service** (`apps/financial/services/project_reporting_service.py`):
  - `get_project_pl(project_id, period)` — P&L for a specific project
  - `get_all_projects_pl(company, period)` — P&L summary for all projects
  - `get_project_budget_vs_actual(project_id)` — budget comparison
  - `get_project_cash_flow(project_id, period)` — cash flow by project
  - `get_profitability_ranking(company)` — projects ranked by margin
  - `get_project_performance_metrics(project_id)` — CPI, SPI, EAC, ETC
- **API** (`apps/financial/api/project_reporting_api.py`):
  - Project P&L, budget vs actual, cash flow, profitability ranking

### Project Performance Metrics
```
Cost Performance Index (CPI) = Earned Value / Actual Cost
  CPI > 1 = under budget (good)
  CPI < 1 = over budget (bad)

Schedule Performance Index (SPI) = Earned Value / Planned Value
  SPI > 1 = ahead of schedule (good)
  SPI < 1 = behind schedule (bad)

Estimate at Completion (EAC) = Budget at Completion / CPI
Estimate to Complete (ETC) = EAC - Actual Cost
Variance at Completion (VAC) = BAC - EAC
```

- **Multi-Project Comparison**: side-by-side P&L
- **Profitability Ranking**: table sorted by margin
- **Project Performance Dashboard**: CPI, SPI, EAC gauges
