# T076 — Organization Structure

- **Phase**: 7
- **Depends On**: T072
- **Estimated Effort**: 2 days

## What Is Being Built
`Department`, `Designation`, `Grade` models. Reporting hierarchy (reports-to tree). Org chart visualization (React). Position control (budgeted vs filled).

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `Department`: code, name, parent FK (self), head FK (employee), cost_center, company FK
  - `Designation`: name, grade FK, department FK, is_active, company FK
  - `Grade`: code, name, min_salary, max_salary, epf_rate, socso_category, company FK
- **Service**: org tree building, position control (count of employees per designation vs budgeted)
- **API**: department/designation/grade CRUD + org tree + position report

### Frontend (React)
- `OrgChartPage` — interactive org chart (tree visualization)
- `DepartmentListPage` — department hierarchy
- `PositionControlPage` — budgeted vs filled positions
