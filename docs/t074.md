# T073 — Quality Control Plans

- **Phase**: 6
- **Depends On**: T065
- **Estimated Effort**: 3 days

## What Is Being Built
QC plan per item/routing: inspection points, test specs, sample size, AQL. QC results recording. Non-conformance (NC) tracking with root cause + corrective action. Certificate of Analysis (COA) generation.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/mrp/models.py`):
  - `QCPlan`: item FK, routing FK (optional), inspection_point (incoming/in_process/final), sample_size, aql_level, is_active, company FK
  - `QCTest`: qc_plan FK, test_name, test_method, expected_value, min_value, max_value, unit, is_critical
  - `QCResult`: work_order FK (optional), grn FK (optional), qc_plan FK, inspector FK, inspection_date, result (pass/fail/conditional), notes
  - `QCResultLine`: qc_result FK, test FK, actual_value, is_pass
  - `NonConformance`: nc_number, source (internal/customer/supplier), item FK, description, severity (minor/major/critical), root_cause, corrective_action, status (open/investigating/resolved/closed), company FK
- **Service**: CRUD, NC tracking, COA generation
- **API**: QC plan CRUD, result recording, NC CRUD, COA endpoint

## Deliverables Checklist
