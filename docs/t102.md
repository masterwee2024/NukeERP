# T102 — Progress Billing

- **Phase**: 2
- **Depends On**: T100, T032
- **Estimated Effort**: 4 days

## What Is Being Built
Progress billing for project-based companies. Bill based on % completion or milestones. Revenue recognition using percentage of completion method. Interim progress certificates. Retention deduction on progress claims.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `ProgressClaim`: id, project FK, claim_number, claim_date, period FK, certified_amount, retention_percent, retention_amount, net_amount, status (draft/submitted/certified/paid), customer_invoice FK (optional), company FK, created_at
  - `ProgressClaimLine`: claim FK, description, quantity, unit_price, amount, sort_order
  - `Milestone`: id, project FK, name, description, target_date, completion_percent, status (pending/in_progress/completed), sort_order
  - `RevenueRecognition`: id, project FK, period FK, recognition_method (percentage_of_completion/milestone/finished), recognized_amount, cumulative_amount, journal_entry FK, company FK
- **Service** (`apps/financial/services/progress_billing_service.py`):
  - `create_progress_claim(project_id, data)` — create claim with retention calculation
  - `certify_claim(claim_id, certified_amount)` — certify claim amount
  - `generate_invoice(claim_id)` — create customer invoice from certified claim
  - `recognize_revenue(project_id, period)` — calculate and post revenue recognition
  - `get_billing_summary(project_id)` — total certified, billed, received, retention held
- **API** (`apps/financial/api/progress_billing_api.py`):
  - Claim CRUD, certification, invoice generation, revenue recognition, billing summary

### Revenue Recognition (% Completion)
```
Contract Value: RM5,000,000
Costs Incurred to Date: RM2,800,000
Total Estimated Cost: RM4,200,000

% Complete = 2,800,000 / 4,200,000 = 66.67%
Revenue to Recognize = 5,000,000 × 66.67% = RM3,333,333
Less: Revenue Previously Recognized = RM2,500,000
Current Period Revenue = RM833,333
```

### GL Entries (Revenue Recognition)
```
DR Revenue Receivable (AR)          833,333.00
CR Revenue Recognized (P&L)        833,333.00
```

- **Milestone Tracker**: visual timeline with completion status
- **Revenue Recognition Page**: run recognition for period
- **Billing Summary Dashboard**: certified, billed, received, retention
