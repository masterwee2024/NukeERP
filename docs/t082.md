# T081 — Payroll: EPF Calculation

- **Phase**: 7
- **Depends On**: T077
- **Estimated Effort**: 2 days

## What Is Being Built
EPF contribution calculation per LHDN/EPF rates: employee 11%, employer 12% (salary < RM5,000) or 13% (salary ≥ RM5,000). EPF Form A (monthly contribution statement). EPF payment file generation.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `EPFContribution`: employee FK, payroll_period FK, employee_contribution, employer_contribution, total_contribution, wage_for_epf
- **Service** (`apps/hrm/services/epf_service.py`):
  - `calculate_epf(basic_salary, allowances)` — lookup rate table, calculate employee + employer share
  - `generate_epf_form_a(company, period)` — Form A data
  - `generate_epf_file(company, period)` — payment file
- **API**: EPF calculation, Form A, file generation

### EPF Rate Table
| Salary Range (RM) | Employee Rate | Employer Rate |
|---|---|---|
| 0 – 5,000 | 11% | 13% |
| 5,001+ | 11% | 12% |
