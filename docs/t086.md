# T085 — Payroll: Tabung Haji & Zakat

- **Phase**: 7
- **Depends On**: T077
- **Estimated Effort**: 1 day

## What Is Being Built
Tabung Haji deduction (employee-elected fixed amount). Zakat deduction (employee-elected or income-based). Integration into payslip.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `TabungHajiDeduction`: employee FK, payroll_period FK, amount
  - `ZakatDeduction`: employee FK, payroll_period FK, amount, calculation_method (fixed/income_based)
- **Service**: deduction calculation, payslip integration
- **API**: deduction setup, calculation

## Deliverables Checklist
- [ ] `TabungHajiDeduction` and `ZakatDeduction` models
- [ ] TH deduction (fixed amount)
- [ ] Zakat deduction (fixed or income-based)
- [ ] Integration into payslip calculation

## Success Criteria
- [ ] TH deduction reduces net pay
- [ ] Zakat calculation methods work correctly
- [ ] Both appear on payslip
