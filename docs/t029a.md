# T029a — Withholding Tax

- **Phase**: 2
- **Depends On**: T029, T030
- **Estimated Effort**: 2 days

## What Is Being Built
Withholding tax (WHT) deduction on payments to contractors, non-residents, and specific transaction types (royalty, interest, services). WHT rates per LHDN schedule. Auto-calculate on payment. WHT certificate generation. Monthly WHT remittance (CP37/CP39).

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `WithholdingTaxCode`: id, code, description, rate_percent, payment_type (contractor/royalty/interest/service/rental), is_active, company FK
  - `WithholdingTaxEntry`: id, payment FK → Payment, wht_code FK, gross_amount, wht_rate, wht_amount, net_payment, wht_certificate_no, status (pending/remitted), remittance_period FK, company FK
- **Service** (`apps/financial/services/wht_service.py`):
  - `calculate_wht(payment_id)` — auto-calculate WHT based on payment type
  - `post_wht(wht_entry_id)` — create GL entry (DR AP, CR WHT payable)
  - `remittance(period_id)` — aggregate WHT for period, generate remittance data
  - `generate_certificate(wht_entry_id)` — WHT certificate PDF
- **API** (`apps/financial/api/wht_api.py`):
  - `POST /api/v1/financial/wht/calculate/` — calculate WHT for payment
  - `POST /api/v1/financial/wht/{id}/post/` — post WHT entry
  - `GET /api/v1/financial/wht/remittance/{period_id}/` — remittance data
  - `GET /api/v1/financial/wht/{id}/certificate/` — download certificate

### WHT Rates (Malaysian LHDN)
| Payment Type | Rate |
|---|---|
| Contractor (professional fee) | 10% |
| Royalty | 10% |
| Interest (to non-resident) | 15% |
| Service (to non-resident) | 10% |
| Rental | 10% |
| Commission | 10% |

### GL Entries
```
Payment with WHT:
  Gross Payment: RM10,000
  WHT (10%): RM1,000
  Net Payment: RM9,000

DR AP Control                    10,000.00
CR Bank (net payment)             9,000.00
CR WHT Payable                    1,000.00
```
