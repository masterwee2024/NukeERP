# T041a — Bank Feed Integration

- **Phase**: 3
- **Depends On**: T041
- **Estimated Effort**: 3 days

## What Is Being Built
Bank feed integration for automatic bank statement import. Support multiple bank formats (CSV, OFX, MT940, CAMT.053). Scheduled auto-import via Celery. Matching rules for auto-reconciliation. Manual upload fallback.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/treasury/models.py`):
  - `BankFeedConfig`: id, bank_account FK, bank_name, feed_type (csv/ofx/mt940/camt053), frequency (daily/weekly/manual), api_credentials (encrypted JSON), last_import_date, is_active, company FK
  - `BankFeedLog`: id, feed_config FK, import_date, file_name, records_imported, records_matched, records_unmatched, status (success/partial/failed), error_message
- **Service** (`apps/treasury/services/bank_feed_service.py`):
  - `import_bank_feed(bank_account_id, file, format)` — parse file and create BankStatementLine records
  - `auto_match(statement_lines)` — match against ERP entries using amount, date, reference
  - `schedule_import(feed_config_id)` — Celery task for scheduled import
  - `get_unmatched_lines(bank_account_id)` — lines awaiting manual matching
- **Parsers** (`apps/treasury/parsers/`):
  - `csv_parser.py` — generic CSV parser with configurable column mapping
  - `ofx_parser.py` — OFX/QFX format parser
  - `mt940_parser.py` — SWIFT MT940 format parser
  - `camt053_parser.py` — ISO 20022 CAMT.053 parser
- **API** (`apps/treasury/api/bank_feed_api.py`):
  - `POST /api/v1/treasury/bank-feeds/{id}/import/` — manual import
  - `POST /api/v1/treasury/bank-feeds/{id}/auto-import/` — trigger scheduled import
  - `GET /api/v1/treasury/bank-feeds/{id}/logs/` — import history
  - `GET /api/v1/treasury/bank-feeds/{id}/unmatched/` — unmatched lines

### Frontend (React)
- **Bank Feed Config Page**: set up feed per bank account
- **Import Page**: upload file, select format, preview, confirm
- **Import History**: log of past imports with status
- **Unmatched Lines**: list of lines awaiting manual matching
