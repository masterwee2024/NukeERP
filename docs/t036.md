# T035 — Fixed Asset Register

- **Phase**: 3
- **Depends On**: T010
- **Estimated Effort**: 3 days

## What Is Being Built
`FixedAsset` model with name, category, purchase date, cost, location, custodian, serial number. Asset categories with default depreciation method and useful life. Barcode/label print.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/assets/models.py`):
  - `FixedAssetCategory`: name, code, default_depreciation_method (SLM/RBM), default_useful_life_years, GL_account_purchase, GL_account_depreciation, GL_account_accum_depreciation, company FK
  - `FixedAsset`: asset_code, name, category FK, purchase_date, purchase_cost, accumulated_depreciation, net_book_value, location, department FK, custodian FK, serial_number, warranty_expiry, status (active/disposed/transferred), company FK, notes
  - `AssetMovement`: asset FK, movement_type (transfer/disposal), from_location, to_location, date, reference, approved_by FK
- **Service**: CRUD, search, barcode generation
- **API**: Asset CRUD + list with filters + barcode endpoint

### Frontend (React)
- `AssetRegisterPage` — table with filters (category, status, location)
- `AssetFormPage` — create/edit asset
- `AssetDetailPage` — full asset info, movement history, depreciation schedule link
