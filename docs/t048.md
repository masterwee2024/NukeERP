# T047 — Bin Location Management

- **Phase**: 4
- **Depends On**: T043
- **Estimated Effort**: 2 days

## What Is Being Built
`BinLocation` within warehouse (aisle, rack, shelf, bin). Item-bin assignment. Basic pick path optimization.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `BinLocation`: warehouse FK, code, name, aisle, rack, shelf, bin, capacity, is_active
  - `ItemBinLocation`: item FK, bin FK, quantity, min_qty, max_qty
- **Service**: CRUD, item-bin assignment, pick path generation (aisle → rack → shelf order)
- **API**: Bin CRUD, item-bin assignment
