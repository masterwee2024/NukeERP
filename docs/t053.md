# T052 — Purchase Order

- **Phase**: 4
- **Depends On**: T013, T014, T041, T042, T048
- **Estimated Effort**: 5 days

## What Is Being Built
`PurchaseOrder` CRUD with multi-line items. Copy from PR/RFQ. Delivery schedule per line. Tax calculation. Approval workflow. PO amendment (versioning). PO print/email.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `PurchaseOrder`: po_number, vendor FK, order_date, expected_delivery_date, status (draft/submitted/approved/partially_received/received/cancelled), total, tax_total, grand_total, currency, terms_conditions, company FK, approval_request FK
  - `PurchaseOrderLine`: po FK, line_number, item FK, description, quantity, received_quantity, uom FK, unit_price, discount_percent, amount, tax_code FK, tax_amount, expected_delivery_date
- **Service**: CRUD, copy from PR/RFQ, tax calculation, submit/approve, print/email
- **API**: Full CRUD + submit + approve + copy + print endpoints
