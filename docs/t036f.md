# T036f — Maintenance Contracts & Vendor Management

- **Phase**: 3
- **Depends On**: T036d
- **Estimated Effort**: 3 days

## What Is Being Built
Maintenance contract management with vendors. Contract types (full service, parts only, labour only). SLA definitions (response time, resolution time, uptime guarantee). SLA tracking and breach alerts. Vendor performance scoring. Contract renewal alerts. Cost comparison between internal vs outsourced maintenance.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/assets/models.py`):
  - `MaintenanceContract`: id, contract_number, vendor FK, contract_type (full_service/parts_only/labour_only/inspection), asset FK (optional — specific asset), facility FK (optional — facility-wide), scope_description, start_date, end_date, renewal_date, sla_response_hours, sla_resolution_hours, uptime_guarantee_percent, monthly_cost, annual_cost, payment_terms, status (active/expired/cancelled/renewed), auto_renew, company FK, created_at
  - `MaintenanceContractAsset`: contract FK, asset FK (assets covered by contract)
  - `SLATracking`: id, contract FK, wo FK, reported_date,响应_date (response_date), resolved_date, response_time_hours, resolution_time_hours, is_breach, breach_type (response/resolution/uptime), company FK
  - `VendorMaintenanceScore`: id, vendor FK, period, total_wos, on_time_count, avg_response_hours, avg_resolution_hours, avg_rating, cost_accuracy, company FK
- **Service** (`apps/assets/services/contract_service.py`):
  - `create_contract(data)` — create with asset linking
  - `track_sla(wo_id)` — record response/resolution times, check breach
  - `calculate_vendor_score(vendor_id, period)` — aggregate performance metrics
  - `get_expiring_contracts(company, days)` — contracts expiring soon
  - `get_breach_report(company, period)` — all SLA breaches
  - `compare_internal_vs_outsourced(company, period)` — cost comparison
- **API** (`apps/assets/api/contract_api.py`):
  - Contract CRUD, SLA tracking, vendor scores, expiry alerts, breach report

### Frontend (React)
- **Contract List Page**: all contracts with status, vendor, expiry
- **Contract Form Page**: create/edit with asset selection, SLA fields
- **SLA Dashboard**: response/resolution times, breach count
- **Vendor Performance Page**: scores, trends, comparison
- **Contract Expiry Widget**: dashboard widget for expiring contracts
- **Internal vs Outsourced Report**: cost comparison chart

### SLA Tracking Flow
```
Maintenance Work Order created:
├── Contract: ACME Maintenance (SLA: 4hr response, 24hr resolution)
├── Reported: 15 Jan 2026, 09:00
├── Vendor Response: 15 Jan 2026, 11:30 (2.5 hours) ✓ Within SLA
├── Resolved: 15 Jan 2026, 18:00 (9 hours) ✓ Within SLA
└── No breach

SLA Breach:
├── Reported: 15 Jan 2026, 09:00
├── Vendor Response: 16 Jan 2026, 14:00 (29 hours) ✗ Breach (>4hr)
└── Alert sent to facility manager
```
