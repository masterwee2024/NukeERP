# T050 — Purchase Requisition

- **Phase**: 4
- **Depends On**: T013, T041
- **Estimated Effort**: 3 days

## What Is Being Built
`PurchaseRequisition` CRUD. Request items with suggested vendor. Approval workflow. Budget check (optional). Auto-convert to RFQ/PO.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `PurchaseRequisition`: requisition_number, request_date, requester FK, department FK, status (draft/submitted/approved/converted), priority (low/medium/high/urgent), notes, company FK
  - `PurchaseRequisitionLine`: requisition FK, line_number, item FK, description, quantity, uom FK, suggested_vendor FK, required_date, notes
- **Service**: CRUD, submit for approval, convert to RFQ or PO
- **API**: CRUD + submit + convert endpoints

### Frontend (React)
- `PurchaseRequisitionListPage` — table with filters
- `PurchaseRequisitionFormPage` — create/edit with line items

## Deliverables Checklist
