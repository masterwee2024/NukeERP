# T087 — Payroll: EA Form & Form E

- **Phase**: 7
- **Depends On**: T083
- **Estimated Effort**: 2 days

## What Is Being Built
EA Form: annual employee earnings statement (gross, EPF, PCB, allowances, benefits in kind). PDF generation per employee. Form E / CP8D: employer annual return data file per LHDN specification.

## How It Will Be Built

### Backend (Django)
- **Service** (`apps/hrm/services/ea_form_service.py`):
  - `generate_ea_form(employee_id, year)` — aggregate payroll data for the year, generate PDF
  - `generate_form_e(company, year)` — CP8D data file per LHDN format
- **API**: EA form PDF download, Form E data download

## Deliverables Checklist
- [ ] EA Form PDF generation per employee
- [ ] Form E / CP8D data file generation
- [ ] LHDN-compliant format
- [ ] React EA form view page

## Success Criteria
- [ ] EA form shows correct annual totals
- [ ] EPF, PCB, allowances match payroll records
- [ ] Form E file is LHDN-compliant
- [ ] All tests pass
