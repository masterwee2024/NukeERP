# T009d — Data Migration Framework

- **Phase**: 0
- **Depends On**: T009
- **Estimated Effort**: 5 days

## What Is Being Built
Data migration framework for importing master data and configuration via CSV. CSV import engine with column mapping, data validation (required, unique, type, FK, business rules), transformation, bulk insert with error handling, import history, rollback capability, downloadable CSV templates for all entity types.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/core/models.py`):
  - `ImportTemplate`: id, name, entity_type (unique), description, column_definitions (JSON — [{name, label, type, required, max_length, fk_model, format_example}]), csv_template_file, is_active, created_at
  - `ImportJob`: id, template FK, file_name, uploaded_by FK, status (uploaded/validating/importing/completed/failed/rolled_back), total_rows, success_count, error_count, warning_count, started_at, completed_at, company FK, created_at
  - `ImportRow`: id, job FK, row_number, raw_data (JSON), mapped_data (JSON), status (pending/valid/success/error), errors (JSON), warnings (JSON), imported_record_id (UUID)
  - `ImportHistory`: id, job FK, entity_type, action (import/rollback), record_count, performed_by FK, performed_at, notes

- **Service** (`apps/core/services/import_service.py`):
  - `upload_file(file, template_id)` — parse CSV, create import job, map columns
  - `validate_job(job_id)` — validate all rows, mark valid/error/warning
  - `import_job(job_id)` — bulk import valid rows, create records
  - `rollback_job(job_id)` — delete imported records, mark job as rolled back
  - `get_template(entity_type)` — get import template with column definitions
  - `generate_csv_template(entity_type)` — generate downloadable CSV with headers
  - `get_import_history(company)` — list past imports

- **Validation Engine** (`apps/core/services/validation_engine.py`):
  - `validate_required(row, rules)` — check required fields
  - `validate_type(row, rules)` — check data types (string, number, date, email)
  - `validate_unique(row, rules, model)` — check unique constraints
  - `validate_fk(row, rules, model)` — check foreign key references
  - `validate_business_rules(row, rules)` — custom business validation
  - `validate_format(row, rules)` — check formats (date: DD/MM/YYYY, amount: numeric)
  - `detect_duplicates(rows)` — warn about potential duplicates

- **Column Mapping** (`apps/core/services/column_mapper.py`):
  - `auto_detect_columns(csv_headers, template)` — match CSV headers to template columns
  - `manual_map(user_mapping)` — user provides column mapping
  - `transform_value(value, column_type)` — format data (date, amount, code)

- **API** (`apps/core/api/import_api.py`):
  - `GET /api/v1/import/templates/` — list available templates
  - `GET /api/v1/import/templates/{entity_type}/` — template detail with column definitions
  - `GET /api/v1/import/templates/{entity_type}/csv/` — download CSV template
  - `POST /api/v1/import/upload/` — upload CSV file
  - `POST /api/v1/import/jobs/{id}/validate/` — validate job
  - `POST /api/v1/import/jobs/{id}/import/` — execute import
  - `POST /api/v1/import/jobs/{id}/rollback/` — rollback import
  - `GET /api/v1/import/jobs/{id}/` — job status and errors
  - `GET /api/v1/import/history/` — import history

### Frontend (React)
- **ImportWizard** (`frontend/src/components/import/ImportWizard.tsx`):
  - Step 1: Select template (entity type)
  - Step 2: Upload CSV file
  - Step 3: Column mapping (auto-detected or manual)
  - Step 4: Validation preview (errors, warnings, valid rows)
  - Step 5: Import execution
  - Step 6: Results summary

- **ImportTemplateList** (`frontend/src/components/import/ImportTemplateList.tsx`):
  - List of available import templates
  - Download CSV template button
  - Description and column count

- **ImportJobStatus** (`frontend/src/components/import/ImportJobStatus.tsx`):
  - Progress bar during import
  - Error/warning counts
  - Link to view errors

- **ImportHistoryPage** (`frontend/src/components/import/ImportHistoryPage.tsx`):
  - List of past imports with status
  - Rollback button for recent imports
