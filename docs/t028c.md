# T028c — Standard Costing

- **Phase**: 2
- **Depends On**: T028b, T075
- **Estimated Effort**: 3 days

## What Is Being Built
Standard cost management for manufactured items. Set standard costs per item (material + labour + overhead). Standard cost roll-up from BOM + routing. Standard cost revision with version control. Compare actual vs standard.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `StandardCost`: id, item FK, material_cost, labour_cost, overhead_cost, total_cost, effective_date, status (draft/active/obsolete), revision (int), company FK, created_at
- **Service** (`apps/financial/services/standard_cost_service.py`):
  - `roll_up_standard_cost(item_id)` — calculate from BOM material cost + routing labour/overhead
  - `set_standard_cost(item_id, material, labour, overhead)` — manual override
  - `activate_standard_cost(item_id, effective_date)` — set as active, obsolete previous
  - `get_standard_cost(item_id, date)` — get active standard cost for date
  - `compare_actual_vs_standard(item_id, period)` — variance calculation
- **API** (`apps/financial/api/standard_cost_api.py`):
  - `POST /api/v1/financial/standard-costs/{item_id}/rollup/` — auto roll-up from BOM+routing
  - `PUT /api/v1/financial/standard-costs/{item_id}/` — manual set
  - `POST /api/v1/financial/standard-costs/{item_id}/activate/` — activate
  - `GET /api/v1/financial/standard-costs/{item_id}/compare/` — actual vs standard
