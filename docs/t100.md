# T100 — Project Master

- **Phase**: 2
- **Depends On**: T013, T021
- **Estimated Effort**: 3 days

## What Is Being Built
Project master data for project-based companies. Project setup with types (fixed price, time & material, cost-plus), project budget, project team assignment, project status tracking. Link projects to GL accounts for project accounting.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `Project`: id, project_code (unique), name, description, project_type (fixed_price/tm/cost_plus), client FK (optional), start_date, expected_end_date, actual_end_date, status (planning/active/on_hold/completed/cancelled), budget_amount, contract_amount, currency, gl_account_revenue FK, gl_account_cost FK, company FK, project_manager FK, created_by FK, created_at, updated_at
  - `ProjectTeam`: project FK, employee FK, role (project_manager/lead/member), allocation_percent, start_date, end_date
  - `ProjectBudget`: id, project FK, category (material/labour/subcontractor/equipment/overhead), budgeted_amount, spent_amount, notes
- **Service** (`apps/financial/services/project_service.py`):
  - `create_project(data)` — create project with budget lines
  - `get_project_summary(project_id)` — budget, spent, remaining, % complete
  - `get_project_dashboard(company)` — all projects with status and key metrics
  - `get_project_cost_breakdown(project_id)` — costs by category
- **API** (`apps/financial/api/project_api.py`):
  - Project CRUD, team management, budget, dashboard

### Frontend (React)
- **Project List Page**: all projects with status, budget, progress
- **Project Detail Page**: summary, team, budget breakdown, timeline
- **Project Form Page**: create/edit project
- **Project Dashboard**: overview of all projects with KPIs
