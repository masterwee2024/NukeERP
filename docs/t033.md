# T033 — Accounts Receivable: Credit Notes & Collections

- **Phase**: 2
- **Depends On**: T029
- **Estimated Effort**: 3 days

## What Is Being Built
Credit note creation linked to original invoice. Debit note. Dunning letter generation for overdue accounts. Bad debt provision. Payment allocation from bank receipt.

## How It Will Be Built

### Backend (Django)
- **Models**:
  - `CreditNote`: customer FK, credit_note_number, date, original_invoice FK, total, tax_total, reason, status, company FK
  - `CreditNoteLine`: credit_note FK, line details, amounts
  - `DebitNote`: similar to credit note but increases amount owed
- **Service**: create credit note, post (GL: DR revenue, CR AR), dunning letter generation, bad debt provision, forex gain/loss on credit notes with foreign currency
- **API**: Credit/debit note CRUD + post, dunning endpoint
