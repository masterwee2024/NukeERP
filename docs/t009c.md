# T009c — Industry Template Engine

- **Phase**: 0
- **Depends On**: T009b
- **Estimated Effort**: 2 days

## What Is Being Built
Industry template system — JSON-based configurations that pre-configure the platform for a specific industry. Templates define: menu items, page configs, workflows, GL accounts, report templates, seed data. Install a template → platform configured for that industry.

## How It Will Be Built

### Backend (Django)
- **Model** (`apps/core/models.py`):
  - `IndustryTemplate`: id, name, code (unique), description, version, module_dependencies (JSON), menu_config (JSON), page_config (JSON), workflow_config (JSON), gl_account_config (JSON), report_config (JSON), seed_data (JSON), is_active, created_at
  - `IndustryTemplateInstallation`: id, template FK, company FK, installed_by FK, installed_at, status (active/uninstalled), configuration_overrides (JSON)

- **Service** (`apps/core/services/template_service.py`):
  - `install_template(template_id, company_id)` — install template for company:
    1. Validate module dependencies are installed
    2. Create menu items from menu_config
    3. Create page configs from page_config
    4. Create workflows from workflow_config
    5. Create GL account mappings from gl_account_config
    6. Run seed data from seed_data
    7. Create installation record
  - `uninstall_template(template_id, company_id)` — remove template configuration
  - `get_template_preview(template_id)` — show what will be configured
  - `export_template(template_id)` — export as JSON
  - `import_template(json_data)` — import from JSON
  - `get_installed_templates(company_id)` — list installed templates

- **API** (`apps/core/api/template_api.py`):
  - `GET /api/v1/platform/templates/` — list all templates
  - `GET /api/v1/platform/templates/{code}/` — template detail
  - `POST /api/v1/platform/templates/{code}/install/` — install for company
  - `POST /api/v1/platform/templates/{code}/uninstall/` — uninstall
  - `GET /api/v1/platform/templates/{code}/preview/` — preview installation
  - `POST /api/v1/platform/templates/import/` — import template
  - `GET /api/v1/platform/templates/{code}/export/` — export template

### Template Structure (JSON)
```json
{
  "name": "Property Management",
  "code": "property",
  "version": "1.0.0",
  "description": "Complete property management setup",
  "module_dependencies": ["finance", "asset_management", "facility_management", "hrm", "property_management"],
  "menu_items": [
    {"name": "Properties", "icon": "building", "sort_order": 1, "children": [
      {"name": "Property Register", "url": "/property/register", "icon": "list", "sort_order": 1},
      {"name": "Units", "url": "/property/units", "icon": "grid", "sort_order": 2}
    ]}
  ],
  "page_configs": [...],
  "workflow_config": [
    {"name": "Lease Approval", "document_type": "lease", "steps": [...]}
  ],
  "gl_account_config": [
    {"code": "1300", "name": "Rental Receivable", "type": "asset"},
    {"code": "4100", "name": "Rental Revenue", "type": "revenue"}
  ],
  "report_config": [
    {"name": "Rent Roll", "type": "list", "entity": "lease"}
  ],
  "seed_data": {
    "lease_types": ["tenancy", "license", "lease_to_own"],
    "maintenance_categories": ["plumbing", "electrical", "hvac", "structural"]
  }
}
```

### Frontend (React)
- **Template Gallery**: browse available industry templates
- **Template Detail**: preview what will be configured
- **Install Button**: install template for current company (with confirm dialog)
- **Installed Templates**: list installed templates per company
