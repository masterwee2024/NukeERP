# T205 — Property Management: Maintenance Requests

- **Phase**: 2
- **Depends On**: T200, T036d
- **Estimated Effort**: 3 days

## What Is Being Built
Tenant maintenance request system — tenants submit requests, property manager assigns to internal team or outsourced vendor, tracking, SLA, completion confirmation, tenant satisfaction rating.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/property/models.py`):
  - `MaintenanceRequest`: id, request_number, tenant FK, property FK, unit FK, category (plumbing/electrical/hvac/structural/pest/other), priority (low/medium/high/urgent), description, photos (JSON), status (submitted/acknowledged/in_progress/completed/closed), assigned_to FK (internal) OR vendor FK (outsourced), estimated_cost, actual_cost, reported_date, acknowledged_date, completed_date, tenant_satisfaction_rating, company FK, created_at
- **Service**: create request, assign, track, complete, rate
- **API**: CRUD, assign, complete, rate

### Frontend (React)
- **Tenant Request Page**: submit maintenance request (tenant portal)
- **Request List Page**: all requests with status and filters
- **Request Detail Page**: timeline, cost, assignment
- **Assignment Form**: assign to team or vendor
