# T062a — Logistics (Picking, Sorting, Loading, Delivery, QR)

- **Phase**: 5
- **Depends On**: T062
- **Estimated Effort**: 4 days

## What Is Being Built
Logistics workflow for delivery orders: order picking (pick list generation), sorting (zone-based), loading (vehicle assignment), delivery (route tracking), and customer acceptance with QR code scanning for efficient data capture. Mobile-optimized for warehouse/delivery staff.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/crm/models.py`):
  - `PickList`: id, pick_list_number, warehouse FK, status (pending/picking/completed), assigned_to FK, created_at
  - `PickListLine`: pick_list FK, delivery_order FK, item FK, quantity, bin_location FK, picked_quantity, status (pending/picked/short_picked), picked_at
  - `LoadingPlan`: id, loading_number, vehicle_no, driver_name, departure_date, status (planning/loaded/in_transit/delivered), company FK, created_at
  - `LoadingPlanLine`: loading_plan FK, delivery_order FK, pick_list FK, items_count, weight, volume, status
  - `DeliveryConfirmation`: id, delivery_order FK, confirmed_by_customer FK, confirmed_at, latitude, longitude, proof_of_delivery (file), qr_code_data, notes
- **Service** (`apps/crm/services/logistics_service.py`):
  - `generate_pick_list(warehouse_id, delivery_orders)` — create pick list from DOs
  - `record_pick(pick_list_line_id, picked_qty)` — record picked quantity
  - `complete_pick_list(pick_list_id)` — mark complete, create stock movements
  - `create_loading_plan(data)` — assign DOs to vehicle
  - `confirm_delivery(do_id, qr_data, location)` — customer acceptance via QR scan
  - `generate_qr_code(delivery_order_id)` — QR code for DO with deep link
- **QR Code**: Each DO gets a unique QR code. Customer scans QR on delivery → opens confirmation page → confirms receipt → system records delivery with timestamp and GPS.

### Frontend (React)
- **Pick List Page**: list of items to pick with bin locations
- **Pick List Mobile**: touch-optimized for warehouse scanner
- **Loading Plan Page**: assign DOs to vehicle, capacity visualization
- **Delivery Confirmation Page**: QR scan result, confirm button
- **QR Code Generator**: print QR labels for DOs
- **Route Map**: delivery route visualization (future: Google Maps integration)

### QR Code Scanning Flow
```
1. Warehouse generates pick list from DOs
2. Picker picks items, scans bin location QR, records picked qty
3. Loader scans DO QR when loading onto vehicle
4. Driver delivers to customer
5. Customer scans DO QR on their phone (or driver scans on their behalf)
6. Confirmation page shows: DO number, items, quantities
7. Customer taps "Confirm Receipt"
8. System records: timestamp, GPS location, proof of delivery photo
9. Delivery status updated to "delivered"
```
