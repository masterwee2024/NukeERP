# T090 — Performance Appraisal (Basic)

- **Phase**: 7
- **Depends On**: T072
- **Estimated Effort**: 2 days

## What Is Being Built
Appraisal cycle setup (period, reviewer assignment). KPI template per designation. Self-appraisal + manager appraisal. Overall rating calculation. Appraisal status tracking.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `AppraisalCycle`: name, period_start, period_end, status (draft/active/closed), company FK
  - `KPITemplate`: designation FK, cycle FK, kpi_name, weight_percent, max_score, company FK
  - `Appraisal`: employee FK, cycle FK, reviewer FK, self_score, manager_score, overall_score, status (pending_self/pending_manager/completed), comments, company FK
  - `AppraisalItem`: appraisal FK, kpi_template FK, self_rating, manager_rating, self_comment, manager_comment
- **Service**: CRUD, rating calculation (weighted average), cycle management
- **API**: Cycle CRUD, appraisal CRUD + submit + complete
