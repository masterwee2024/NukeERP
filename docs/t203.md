# T203 — Property Management: Rent Invoicing

- **Phase**: 2
- **Depends On**: T202, T032
- **Estimated Effort**: 3 days

## What Is Being Built
Monthly rent invoicing — generate rent invoices from active leases, late fee calculation, payment allocation, rent roll report. Integration with Finance module for GL posting.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/property/models.py`):
  - `RentInvoice`: id, invoice_number, lease FK, tenant FK, property FK, unit FK, invoice_date, period_start, period_end, base_rent, late_fee, utility_charges, other_charges, discount, total, tax_amount, grand_total, status (draft/sent/paid/partially_paid/overdue), due_date, company FK, created_at
  - `RentPayment`: id, payment_number, invoice FK, tenant FK, payment_date, amount, payment_method, reference, allocated_rent, allocated_late_fee, allocated_other, unallocated_amount, company FK
- **Service**: generate invoices (batch from leases), late fee calculation, payment allocation, rent roll
- **API**: invoice generation, payment recording, rent roll

### GL Entries
```
Rent Invoice:
DR Rental Receivable               5,000.00
CR Rental Revenue                  5,000.00
CR SST Payable (if applicable)       300.00

Payment Received:
DR Bank                            5,300.00
CR Rental Receivable               5,000.00
CR SST Payable                      300.00
```
