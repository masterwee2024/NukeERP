# T018a — Advanced Audit Trail

- **Phase**: 1
- **Depends On**: T018, T009a, T016, T009d
- **Estimated Effort**: 8 days

## What Is Being Built
Comprehensive audit trail extending T018 with: bulk operation audit, login/logout tracking, data export tracking, report generation tracking, configuration change audit, file attachment audit, approval audit linkage, configurable retention per company, audit log export, and audit dashboard.

## How It Will Be Built

### Backend (Django)
- **Extended Models** (`apps/core/models.py`):
  - `AuditLog`: (existing — add fields)
    - `category` (string — crud/login/export/config/file/approval/bulk)
    - `bulk_operation_id` FK (optional — links bulk entries to parent operation)
    - `metadata` (JSON — additional context like export format, file name, etc.)

  - `AuditLogBulk`: id, operation_type (bulk_update/bulk_delete/bulk_import), description, record_count, affected_models (JSON), user FK, timestamp, ip_address, company FK

  - `AuditRetention`: id, company FK, retention_years (int, default 7), auto_archive (bool, default true), last_archive_date, is_active

  - `AuditExport`: id, export_type (csv/excel), filters (JSON), record_count, user FK, timestamp, file_path, company FK

- **Extended Mixin** (`apps/core/mixins/audit_mixin.py`):
  - `AuditModelMixin` — existing (auto-track CRUD)
  - `AuditBulkMixin` — auto-track bulk operations
  - `AuditConfigMixin` — auto-track configuration changes (workflow, tax code, numbering, page config, menu)

- **Integration Points**:
  ```
  T018 (existing):
  ├── CRUD audit on all models via AuditModelMixin
  └── Audit log page, record-level history

  T018a (new):
  ├── Bulk operation audit (bulk_update, bulk_delete, bulk_import)
  ├── Login/logout tracking (integrate with T015 login history)
  ├── Data export tracking (CSV/Excel/PDF export logging)
  ├── Report generation tracking (which report, filters, when)
  ├── Configuration change audit (workflows, tax codes, numbering, page config, menus)
  ├── File attachment audit (upload/download/delete from T009a)
  ├── Approval audit link (approve/reject/return from T016)
  ├── Configurable retention policy per company
  ├── Audit log export (CSV/Excel for compliance)
  └── Audit dashboard (summary by user, model, date)
  ```

- **Service** (`apps/core/services/advanced_audit_service.py`):
  - `log_bulk_operation(operation_type, description, records, user, company)` — create bulk audit entry
  - `log_export(export_type, filters, count, user, company)` — log data export
  - `log_config_change(model, record_id, changes, user, company)` — log config change
  - `log_file_action(action, file_name, user, company)` — log file upload/download/delete
  - `log_approval_action(execution_id, action, user, company)` — log approval action
  - `get_audit_dashboard(company, period)` — summary statistics
  - `export_audit_logs(filters, format, company)` — export logs
  - `archive_old_logs(company)` — archive logs older than retention period
  - `get_retention_policy(company)` — get company retention settings

- **Celery Task**: `archive_audit_logs` — runs monthly, archives logs older than retention period

- **API** (`apps/core/api/advanced_audit_api.py`):
  - `GET /api/v1/admin/audit-logs/export/` — export audit logs as CSV/Excel
  - `GET /api/v1/admin/audit-logs/dashboard/` — summary by user, model, date
  - `GET /api/v1/admin/audit-retention/` — get retention policy
  - `PUT /api/v1/admin/audit-retention/` — update retention policy
  - `POST /api/v1/admin/audit-logs/archive/` — trigger manual archive

### Audit Categories

| Category | What's Logged | Integration |
|---|---|---|
| **crud** | Create, update, delete on any model | AuditModelMixin (existing T018) |
| **login** | Login, logout, failed login, password reset | T015 login history |
| **export** | Data export (CSV/Excel), report export (PDF) | Export endpoints |
| **config** | Workflow changes, tax codes, numbering, page config, menus | Config CRUD endpoints |
| **file** | File upload, download, delete | T009a attachment service |
| **approval** | Approve, reject, return actions | T016 approval service |
| **bulk** | Bulk update, bulk delete, bulk import | T009d import service |
