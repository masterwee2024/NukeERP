# T009b — Module Plugin Interface

- **Phase**: 0
- **Depends On**: T009
- **Estimated Effort**: 3 days

## What Is Being Built
Module plugin system that allows industry-specific modules to register with the platform. Each module declares its configuration (menu items, page configs, workflows, GL accounts, signals). Inter-module communication via signal bus. Module dependency management.

## How It Will Be Built

### Backend (Django)
- **Registry** (`apps/core/platform/module_registry.py`):
  - `ModuleRegistry` class — singleton that tracks all registered modules
  - `register_module(config)` — register a module with its configuration
  - `get_module(code)` — get module by code
  - `get_all_modules()` — list all registered modules
  - `get_module_dependencies(code)` — get dependency chain

- **Signal Bus** (`apps/core/platform/signals.py`):
  - `signal.send(event_name, data)` — emit event
  - `signal.subscribe(event_name, handler)` — subscribe to event
  - Events: `invoice.posted`, `payment.received`, `asset.registered`, `employee.hired`, `stock.received`, `facility.reading`

- **Module Config Schema** (`apps/core/platform/schemas.py`):
  ```python
  class ModuleConfig(BaseModel):
      name: str                    # "Property Management"
      code: str                    # "property"
      version: str                 # "1.0.0"
      description: str
      dependencies: list[str]      # ["finance", "asset_management", "hrm"]
      menu_items: list[dict]       # Dynamic menu items
      page_configs: list[dict]     # Page config records
      workflows: list[dict]        # Approval workflows
      gl_accounts: list[dict]      # GL account mappings
      signals_emitted: list[str]   # Events this module emits
      signals_handled: list[str]   # Events this module subscribes to
  ```

- **API** (`apps/core/api/module_api.py`):
  - `GET /api/v1/platform/modules/` — list registered modules
  - `GET /api/v1/platform/modules/{code}/` — module detail
  - `GET /api/v1/platform/modules/{code}/dependencies/` — dependency chain
  - `POST /api/v1/platform/modules/{code}/activate/` — activate module
  - `POST /api/v1/platform/modules/{code}/deactivate/` — deactivate module

### Module Registration Pattern
```python
# apps/property_management/__init__.py

from apps.core.platform.module_registry import registry

MODULE_CONFIG = {
    "name": "Property Management",
    "code": "property",
    "version": "1.0.0",
    "description": "Lease management, tenant management, utility billing",
    "dependencies": ["finance", "asset_management", "facility_management", "hrm"],
    "menu_items": [
        {"name": "Properties", "icon": "building", "children": [
            {"name": "Property Register", "url": "/property/register"},
            {"name": "Units", "url": "/property/units"},
        ]},
    ],
    "signals_emitted": ["tenant.registered", "lease.signed", "rent.invoice.created"],
    "signals_handled": ["invoice.posted", "payment.received", "maintenance.completed"],
}

registry.register_module(MODULE_CONFIG)
```

- **Module Detail Page**: configuration, dependencies, status
