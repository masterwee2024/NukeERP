## What Is Being Built
GitHub Actions CI pipeline that runs on every PR: Python lint (Ruff), format check (Black), typecheck (mypy), backend tests (Pytest), frontend lint + typecheck + tests (ESLint + tsc + Vitest), and E2E tests (Playwright). PRs cannot merge if any check fails.

## How It Will Be Built

### GitHub Actions Workflows
- `.github/workflows/ci.yml`: triggered on PR to `main`
- Jobs: lint, typecheck, test-backend, test-frontend, test-e2e (matrix)
- PostgreSQL service container for test DB
- Redis service container for Celery tests
- Caching: pip/poetry, npm

### CI Steps
1. **Lint**: `ruff check .` (Python), `eslint .` (TypeScript)
2. **Format check**: `black --check .` (Python), `prettier --check .` (TypeScript)
3. **Typecheck**: `mypy .` (Python), `tsc --noEmit` (TypeScript)
4. **Backend tests**: `pytest --tb=short -q`
5. **Frontend tests**: `npm run test -- --run`
6. **E2E tests**: `npx playwright test` (requires backend + DB)

## Notes
- E2E job starts Django dev server in background, installs Chromium via Playwright
- Backend test job runs migrations + Django system check before pytest
- Concurrency group cancels in-progress runs when new pushes arrive
- Workflow also triggers on push to `main` (not just PRs)

## Success Criteria
- [x] Push to PR triggers all CI jobs (workflow configured on `pull_request`)
- [x] Lint errors fail the build (Ruff + ESLint error on non-zero exit)

- [x] Failing tests fail the build (pytest + vitest exit codes propagate)
- [ ] All checks pass on clean codebase — requires running CI on GitHub
