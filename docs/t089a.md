# T089a — Report Writer Engine

- **Phase**: 2
- **Depends On**: T009, T021
- **Estimated Effort**: 5 days

## What Is Being Built
Report writer engine — the backend for user-definable reports. Report definition (JSON), data source registry, query builder (generates SQL from config), pivot/cross-tab engine, data aggregation (sum, count, avg, min, max), drill-down support, scheduled report generation via Celery.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/core/models.py`):
  - `ReportDefinition`: id, name, description, data_source, config (JSON — fields, filters, groups, sort, aggregates, pivot, charts), created_by FK, is_public, company FK, created_at, updated_at, version
  - `ReportSchedule`: id, report FK, frequency (daily/weekly/monthly/quarterly), day_of_week, day_of_month, time_of_day, recipients (JSON — email addresses), last_run, next_run, is_active, company FK
  - `ReportExecution`: id, report FK, schedule FK (optional), executed_at, executed_by FK, status (running/completed/failed), result_file, error_message, row_count, execution_time_ms
  - `DataSource`: id, name, code (unique), description, base_model (Django model name), available_fields (JSON), is_active

- **Service** (`apps/core/services/report_engine.py`):
  - `register_data_source(name, code, model, fields)` — register available data source
  - `build_query(report_config)` — generate SQL from report definition JSON
  - `execute_report(report_id, params)` — run report, return results
  - `execute_pivot(report_config, data)` — perform cross-tab aggregation
  - `aggregate(data, field, function)` — sum, count, avg, min, max
  - `drill_down(report_id, row_id, field)` — get detail for specific row
  - `export_to_excel(data, config)` — generate Excel file
  - `export_to_pdf(data, config)` — generate PDF via WeasyPrint
  - `export_to_csv(data)` — generate CSV
  - `run_scheduled_reports()` — Celery task: run all due scheduled reports

- **Query Builder** (`apps/core/services/query_builder.py`):
  - `build_select(fields, aggregates)` — SELECT clause
  - `build_from(data_source)` — FROM clause with joins
  - `build_where(filters)` — WHERE clause with operators (=, !=, >, <, >=, <=, in, not_in, like, between, is_null)
  - `build_group_by(groups)` — GROUP BY clause
  - `build_order_by(sort)` — ORDER BY clause
  - `build_having(aggregates)` — HAVING clause for aggregate filters
  - `build_limit(offset, limit)` — LIMIT/OFFSET for pagination

- **Pivot Engine** (`apps/core/services/pivot_engine.py`):
  - `pivot(data, row_fields, column_fields, value_field, aggregation)` — cross-tab calculation
  - `unpivot(pivoted_data)` — reverse pivot
  - `calculate_totals(pivoted_data)` — row and column totals

- **Data Source Registry** (`apps/core/services/data_source_registry.py`):
  - Pre-registered sources:
    - `general_ledger`: Account, period, debit, credit, balance, department, cost_centre
    - `accounts_payable`: Supplier, invoice, amount, due_date, status, aging_bucket
    - `accounts_receivable`: Customer, invoice, amount, due_date, status, aging_bucket
    - `inventory`: Item, warehouse, quantity, value, movement_type, date
    - `sales`: Customer, item, quantity, amount, date, salesperson
    - `purchases`: Supplier, item, quantity, amount, date
    - `payroll`: Employee, department, gross, deductions, net_pay, epf, socso
    - `fixed_assets`: Asset, category, cost, depreciation, nbv, location
    - `projects`: Project, cost_category, revenue, profit, percent_complete

- **API** (`apps/core/api/report_api.py`):
  - `GET /api/v1/reports/data-sources/` — list available data sources
  - `GET /api/v1/reports/data-sources/{code}/fields/` — list fields for data source
  - `POST /api/v1/reports/` — create report definition
  - `PUT /api/v1/reports/{id}/` — update report
  - `GET /api/v1/reports/{id}/` — get report definition
  - `POST /api/v1/reports/{id}/execute/` — run report with params
  - `POST /api/v1/reports/{id}/pivot/` — run pivot analysis
  - `GET /api/v1/reports/{id}/export/{format}/` — export (pdf/excel/csv)
  - `POST /api/v1/reports/{id}/schedule/` — schedule report
  - `GET /api/v1/reports/scheduled/` — list scheduled reports
  - `GET /api/v1/reports/history/` — report execution history

### Report Definition JSON Schema
```json
{
  "data_source": "accounts_payable",
  "fields": ["supplier.name", "invoice.number", "invoice.amount", "invoice.due_date"],
  "filters": [
    {"field": "invoice.status", "operator": "in", "value": ["open", "overdue"]},
    {"field": "invoice.due_date", "operator": "<=", "value": "today"}
  ],
  "groups": ["supplier.name"],
  "sort": [{"field": "supplier.name", "direction": "asc"}],
  "aggregates": [
    {"field": "invoice.amount", "function": "sum", "label": "Total Amount"},
    {"field": "invoice.amount", "function": "count", "label": "Count"}
  ],
  "pivot": {
    "enabled": true,
    "row_fields": ["supplier.name"],
    "column_fields": ["aging_bucket"],
    "value_field": "invoice.amount",
    "aggregation": "sum"
  },
  "charts": [
    {"type": "bar", "x": "supplier.name", "y": "invoice.amount", "title": "AP by Supplier"}
  ]
}
```
