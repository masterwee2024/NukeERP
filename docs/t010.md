# T010 — Page Config Engine

- **Phase**: 1
- **Depends On**: T009
- **Estimated Effort**: 5 days
- **Status**: Completed

## What Is Being Built
Database-driven page configuration system. Two models: `PageConfig` (page-level settings) and `PageConfigField` (field-level definitions). A single CRUD API manages all page configs. Seed data defines every form, list, detail, and dashboard page in the system.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/core/models.py`):
  - `PageConfig`: page_key (unique slug), page_title, page_type (form/list/detail/dashboard), module (financial/scm/crm/mrp/hrm/admin), entity_model (Django model name), api_endpoint, is_active, layout (single/two_column/tabs/wizard), desktop_layout (single/two_column/tabs/wizard — default: same as layout), mobile_layout (single/tabs — default: single), list_mobile_view (table/card — default: card), mobile_group_by (field_name for card grouping on mobile), actions (JSON — [{label, endpoint, method, confirm, variant, icon}]), breadcrumbs (JSON), page_size, sort_default, sort_direction
  - `PageConfigField`: page_config FK, field_name, label, placeholder, help_text, field_type, data_type, required, readonly, hidden, disabled, default_value, sort_order, group_name (header/details/totals/notes), col_span (1–12), width (full/half/third/quarter), show_on_desktop (bool, default true), show_on_mobile (bool, default true), desktop_col_span (1–12, default: same as col_span), mobile_col_span (1–12, default: 12 — full width on mobile), mobile_render_as (text/badge/card/compact — how field renders on mobile cards), min_length, max_length, min_value, max_value, pattern, custom_validator, options_source (static/api/enum/model), options (JSON), options_api, options_label_field, options_value_field, option_group_by, related_entity, related_display, related_search (JSON), related_fields (JSON), show_when (JSON), depends_on (JSON), is_column, column_order, column_width, column_align, sortable, filterable, searchable, aggregate, render_as, parent_field (FK self), line_entity, line_fields (JSON), permission_read, permission_write, icon, prefix, suffix, format, badge_color (JSON), css_class
- **Service** (`apps/core/services/page_config_service.py`):
  - `get_page_config(page_key)` — returns config with all fields sorted by sort_order
  - `create_page_config(data)`, `update_page_config(page_key, data)`, `delete_page_config(page_key)`
  - `add_field(page_key, field_data)`, `update_field(page_key, field_id, field_data)`, `remove_field(page_key, field_id)`
  - `clone_config(page_key, new_page_key)` — deep clone with all fields
  - `export_config(page_key)` — JSON export
  - `import_config(json_data)` — JSON import with validation
- **API** (`apps/core/api/page_config_api.py`):
  - `GET /api/v1/page-configs/` — list all page configs
  - `POST /api/v1/page-configs/` — create page config
  - `GET /api/v1/page-configs/{page_key}/` — get config with all fields
  - `PUT /api/v1/page-configs/{page_key}/` — update config
  - `DELETE /api/v1/page-configs/{page_key}/` — delete config
  - `POST /api/v1/page-configs/{page_key}/fields/` — add field
  - `PUT /api/v1/page-configs/{page_key}/fields/{field_id}/` — update field
  - `DELETE /api/v1/page-configs/{page_key}/fields/{field_id}/` — delete field
  - `POST /api/v1/page-configs/{page_key}/clone/` — clone config
  - `GET /api/v1/page-configs/{page_key}/export/` — export as JSON
  - `POST /api/v1/page-configs/import/` — import from JSON

### Seed Data
- Management command: `apps/core/management/commands/seed_page_configs.py`
- Creates page configs for every module:
  - Financial: chart-of-accounts (list), journal-entry (form+list), trial-balance (list), supplier-invoice (form+list), customer-invoice (form+list), payment (form+list)
  - SCM: item-master (form+list), warehouse (form+list), purchase-order (form+list), grn (form+list), stock-movement (list)
  - CRM: lead (form+list), opportunity (form+list+kanban), customer (form+list), quotation (form+list), sales-order (form+list), delivery-order (form+list)
  - MRP: bom (form+list), work-center (form+list), work-order (form+list)
  - HRM: employee (form+list), attendance (form+list), leave (form+list), payroll-run (form), payslip (list)
  - Admin: user-management (form+list), role-management (form+list), menu-access (form)

### Frontend (React)
- **Hooks**:
  - `usePageConfig(pageKey)` — fetches config, caches with TanStack Query
  - `usePageConfigMutations()` — create/update/delete operations
