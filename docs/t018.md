# T018 — Audit Log System

- **Phase**: 1
- **Depends On**: T009
- **Estimated Effort**: 2 days

## What Is Being Built
Immutable audit trail tracking every create, update, and delete across all models. Records: model name, record ID, action, changed fields with old/new values (JSON diff), user, timestamp, IP address.

## How It Will Be Built

### Backend (Django)
- **Model** (`apps/core/models.py`):
  - `AuditLog`: model_name, record_id (UUID), action (create/update/delete), changes (JSONField — `{ field: { old: X, new: Y } }`, user FK, timestamp, ip_address, company FK
- **Mixin**: `apps/core/mixins/audit_mixin.py`
  - `AuditModelMixin` — override `save()` and `delete()` to auto-create AuditLog entries
  - Exclude fields: `updated_at`, `modified_by` (metadata, not business data)
- **API** (`apps/core/api/audit_api.py`):
  - `GET /api/v1/admin/audit-logs/` — list with filters (model, action, user, date range, record_id)
  - `GET /api/v1/admin/audit-logs/{id}/` — detail with full change diff

### Frontend (React)
- **Audit Log Page**: filterable table showing all changes
- **Record Audit Trail**: linked from any record's detail page — shows that record's history
