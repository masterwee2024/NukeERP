# T028a — Budgeting

- **Phase**: 2
- **Depends On**: T021, T024
- **Estimated Effort**: 3 days

## What Is Being Built
Budget management: create departmental and account-level budgets per period. Budget vs actual comparison reports. Variance analysis. Budget alerts when approaching limits. Budget approval workflow.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `Budget`: id, name, financial_year FK, department FK (optional), company FK, status (draft/submitted/approved/closed), total_amount, approval_request FK, created_by FK, created_at
  - `BudgetLine`: budget FK, account FK, period FK (optional — for monthly budget), budgeted_amount, notes
  - `BudgetActual`: (view/materialized) budget FK, account FK, period FK, budgeted_amount, actual_amount, variance, variance_percent
- **Service** (`apps/financial/services/budget_service.py`):
  - `create_budget(data)` — create budget with line items
  - `get_budget_vs_actual(budget_id)` — calculate actual from GL, compare to budget
  - `get_variance_report(company, year, department)` — all accounts with budget vs actual
  - `check_budget_limit(account_id, amount, period)` — check if posting would exceed budget (warning, not blocking)
  - `get_budget_utilization(account_id, period)` — percentage used
- **API** (`apps/financial/api/budget_api.py`):
  - `GET /api/v1/financial/budgets/` — list budgets
  - `POST /api/v1/financial/budgets/` — create budget
  - `PUT /api/v1/financial/budgets/{id}/` — update budget
  - `GET /api/v1/financial/budgets/{id}/actual/` — budget vs actual
  - `GET /api/v1/financial/budgets/variance-report/` — variance report
  - `POST /api/v1/financial/budgets/{id}/submit/` — submit for approval
  - `GET /api/v1/financial/budgets/{id}/utilization/` — utilization percentages
- **Integration**: On journal entry posting, check budget limits (warning only, not blocking)

### Frontend (React)
- **Budget List Page**: all budgets by year, department, status
- **Budget Form Page**: create/edit with line items (account × period matrix)
- **Budget vs Actual Report**: table with budgeted, actual, variance, variance %, bar chart
- **Budget Utilization Dashboard**: gauge charts showing % used per account
- **Budget Alert Config**: set thresholds (80%, 90%, 100%) for warnings
