# T019b — Internal Messaging System: UI

- **Phase**: 1
- **Depends On**: T019a
- **Estimated Effort**: 5 days

## What Is Being Built
Chat interface for internal messaging — Slack-like UI with channel list, message list, thread panel, file upload, link preview cards, @mentions autocomplete, emoji picker, search, notification badge. Mobile-responsive with touch-optimized interactions.

## How It Will Be Built

### Frontend (React)
- **MessagingLayout** (`frontend/src/components/messaging/MessagingLayout.tsx`):
  - Three-panel layout: channel list (left, 240px), message list (center, flex), thread/detail panel (right, 320px, toggleable)
  - Mobile: channel list as drawer, messages full-width, thread as overlay

- **ChannelList** (`frontend/src/components/messaging/ChannelList.tsx`):
  - Channels grouped by type: Starred, Channels, Direct Messages
  - Unread badge per channel
  - Active channel highlighting
  - Create channel button
  - Search channels

- **MessageList** (`frontend/src/components/messaging/MessageList.tsx`):
  - Messages with sender avatar, name, timestamp
  - Grouped by date (Today, Yesterday, Date)
  - Thread indicator (reply count)
  - Link preview cards (invoice, PO, etc.)
  - System messages (different styling)
  - Infinite scroll (load older messages)
  - Typing indicator

- **MessageInput** (`frontend/src/components/messaging/MessageInput.tsx`):
  - Rich text input (bold, italic, code, links)
  - @mention autocomplete (search users)
  - Emoji picker
  - File upload (drag-and-drop or button)
  - Send button (Enter to send, Shift+Enter for newline)
  - Typing indicator broadcast

- **ThreadPanel** (`frontend/src/components/messaging/ThreadPanel.tsx`):
  - Shows parent message
  - Thread replies
  - Reply input
  - Close button

- **LinkPreviewCard** (`frontend/src/components/messaging/LinkPreviewCard.tsx`):
  - Auto-detects ERP links (invoice, PO, SO, etc.)
  - Fetches preview data (number, party, amount, status)
  - Renders card with icon, title, details, "View" button
  - Click → opens document in ERP

- **FileAttachment** (`frontend/src/components/messaging/FileAttachment.tsx`):
  - File icon based on type
  - File name, size
  - Download button
  - Preview for images/PDFs

- **EmojiPicker** (`frontend/src/components/messaging/EmojiPicker.tsx`):
  - Common emojis grid
  - Frequently used section
  - Search emojis

- **MentionAutocomplete** (`frontend/src/components/messaging/MentionAutocomplete.tsx`):
  - Triggered by @ character
  - Searches users by name
  - Shows avatar, name, department
  - Select to insert mention

- **SearchPanel** (`frontend/src/components/messaging/SearchPanel.tsx`):
  - Full-text search across messages
  - Filter by channel, sender, date range
  - Search results with context

- **NotificationBadge** (`frontend/src/components/messaging/NotificationBadge.tsx`):
  - Unread count badge on messaging icon in header
  - Badge on individual channels

### Library
- `@tiptap/react` — rich text input (reuse from T089e)
- `emoji-picker-react` — emoji picker
- No heavy chat libraries (build custom for full control)
