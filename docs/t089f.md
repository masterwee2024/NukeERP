# T089f — Document Template Management

- **Phase**: 2
- **Depends On**: T089d, T089e
- **Estimated Effort**: 3 days

## What Is Being Built
Template management — CRUD, versioning, per-company templates, cloning, default templates per document type, BM/English template sets, template activation/deactivation, template import/export.

## How It Will Be Built

### Backend (Django)
- **Service** (`apps/core/services/template_management.py`):
  - `create_template(data)` — create with initial version
  - `update_template(template_id, content)` — save changes, create new version
  - `clone_template(template_id, target_company)` — clone to company
  - `set_default(template_id)` — set as default for document type + company
  - `get_default_template(document_type, company)` — get active default
  - `activate_template(template_id)` — activate
  - `deactivate_template(template_id)` — deactivate
  - `export_template(template_id)` — export as JSON
  - `import_template(json_data, company)` — import from JSON
  - `get_template_history(template_id)` — version history

- **Default Templates** (seeded):
  - Invoice (EN), Invoice (BM)
  - Quotation (EN), Quotation (BM)
  - Purchase Order (EN), Purchase Order (BM)
  - Delivery Order (EN), Delivery Order (BM)
  - Credit Note (EN), Credit Note (BM)
  - Official Receipt (EN), Official Receipt (BM)
  - Payslip (EN), Payslip (BM)
  - Statement of Account (EN), Statement of Account (BM)

- **API** (`apps/core/api/template_management_api.py`):
  - Template CRUD
  - Clone, activate, deactivate
  - Default template management
  - Export/Import
  - Version history

### Frontend (React)
- **Template Management Page**: list all templates, filter by type/company/language
- **Default Template Selector**: set default per document type per company
- **Template History**: version list with compare
- **Import/Export**: upload/download template JSON
