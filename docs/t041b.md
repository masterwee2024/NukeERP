# T041b — Bank Guarantee / Fixed Deposit Management

- **Phase**: 3
- **Depends On**: T041
- **Estimated Effort**: 2 days

## What Is Being Built
Bank guarantee and fixed deposit tracking. Record BG/FD details (amount, bank, purpose, issue date, expiry date). Interest accrual for FDs. BG expiry alerts. Renewal tracking.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/treasury/models.py`):
  - `BankGuarantee`: id, reference_number, bank FK, amount, purpose, beneficiary, issue_date, expiry_date, status (active/expired/claimed/cancelled), related_project FK (optional), company FK, created_at
  - `FixedDeposit`: id, reference_number, bank FK, principal_amount, interest_rate, tenure_months, issue_date, maturity_date, interest_accrual_method (simple/compound), status (active/matured/early_withdrawn), gl_account FK, company FK, created_at
  - `FDInterestAccrual`: fd FK, period, interest_amount, journal_entry FK
- **Service** (`apps/treasury/services/bank_guarantee_service.py`):
  - `create_guarantee(data)` — create BG record
  - `create_fd(data)` — create FD record
  - `calculate_fd_interest(fd_id)` — calculate interest accrual
  - `get_expiring_guarantees(days)` — BGs expiring within N days
  - `get_maturing_fds(days)` — FDs maturing within N days
- **API**: BG/FD CRUD, interest calculation, expiry alerts
