# T015 — User Management UI

- **Phase**: 1
- **Depends On**: T011
- **Estimated Effort**: 2 days

## What Is Being Built
Admin-facing user management: user list with search/filter, create/edit user form, role assignment, activate/deactivate, admin password reset, login history view.

## How It Will Be Built

### Backend (Django)
- **API** (`apps/core/api/user_api.py`):
  - `GET /api/v1/admin/users/` — list with search, role filter, status filter
  - `POST /api/v1/admin/users/` — create user
  - `PUT /api/v1/admin/users/{id}/` — update user
  - `POST /api/v1/admin/users/{id}/deactivate/` — soft delete
  - `POST /api/v1/admin/users/{id}/reset-password/` — admin password reset
  - `GET /api/v1/admin/users/{id}/login-history/` — login audit trail

### Frontend (React)
- **Pages**:
  - `UserListPage` — table with search, role filter, status filter, quick actions
  - `UserFormPage` — create/edit: name, email, password, roles (multi-select), company, status
  - `UserDetailPage` — profile, roles, login history, audit log

## Deliverables Checklist
- [ ] User list API with search, filter, pagination
- [ ] User create/edit API
- [ ] Deactivate API (soft delete, not hard delete)
- [ ] Admin password reset API
- [ ] Login history API
- [ ] React user list page
- [ ] React user form page with role assignment
- [ ] React user detail page with login history
- [ ] All CRUD actions use `useConfirm()` dialog
- [ ] Permission-gated: only users with `admin_create` can access

## Success Criteria
- [ ] Admin can create, edit, deactivate users
- [ ] Admin can assign multiple roles to a user
- [ ] Deactivated user cannot log in
- [ ] Password reset sends email notification
- [ ] Login history shows timestamp, IP, device
- [ ] All destructive actions show confirmation dialog
- [ ] All tests pass
