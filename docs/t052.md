# T051 — Request for Quotation (RFQ)

- **Phase**: 4
- **Depends On**: T047
- **Estimated Effort**: 3 days

## What Is Being Built
Create RFQ from PR. Send to multiple vendors. Vendor response recording (price, delivery terms). Comparison matrix. Select winning quote → auto-create PO.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `RFQ`: rfq_number, requisition FK, status (draft/sent/response_received/closed), issue_date, closing_date, company FK
  - `RFQLine`: rfq FK, item FK, quantity, uom FK
  - `RFQResponse`: rfq FK, vendor FK, response_date, total_amount, notes, status
  - `RFQResponseLine`: response FK, rfq_line FK, unit_price, lead_time_days, notes
- **Service**: CRUD, send to vendors, record responses, comparison matrix, select winner → create PO
- **API**: RFQ CRUD + response recording + comparison + select winner
