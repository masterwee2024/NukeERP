# T088 — Claims & Reimbursement

- **Phase**: 7
- **Depends On**: T013, T072
- **Estimated Effort**: 3 days

## What Is Being Built
`Claim` model: type (mileage, travel, medical, overtime meal, other). Line items with receipt attachment. Rate per km (mileage). Approval workflow. Claim limit per type per period. Reimbursement via payroll or separate payment.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `ClaimType`: name, code, max_amount_per_claim, max_amount_per_month, requires_receipt, rate_per_km, is_active, company FK
  - `Claim`: claim_number, employee FK, claim_type FK, claim_date, total_amount, status (draft/submitted/approved/paid/rejected), approval_request FK, company FK
  - `ClaimLine`: claim FK, date, description, amount, receipt_attachment, mileage_km (for mileage claims)
- **Service**: CRUD, validation against limits, approval, reimbursement (add to payroll or separate payment)
- **API**: Claim type CRUD, claim CRUD + submit + approve + reject + pay
