# T202 — Property Management: Lease Management

- **Phase**: 2
- **Depends On**: T200, T201
- **Estimated Effort**: 4 days

## What Is Being Built
Lease creation and management — lease types (tenancy/license/lease-to-own), lease terms, rent escalation (fixed/percentage/CPI), security deposit, stamp duty, renewal, termination. Lease addendum tracking.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/property/models.py`):
  - `Lease`: id, lease_number, property FK, unit FK, tenant FK, lease_type (tenancy/license/lease_to_own), start_date, end_date, lease_term_months, monthly_rental, security_deposit, stamp_duty, rent_escalation_type (fixed/percentage/cpi), rent_escalation_percent, escalation_frequency (yearly/bi_yearly), payment_terms (due_day, late_fee_percent, grace_days), status (draft/active/expired/terminated/renewed), renewal_of FK → Lease, approval_request FK, company FK, created_at, updated_at, version
  - `LeaseAddendum`: id, lease FK, effective_date, changes (JSON), reason, approved_by FK, created_at
- **Service**: CRUD, renewal, termination, rent escalation calculation, stamp duty calculation
- **API**: Lease CRUD, renew, terminate, addendum, escalation preview

### Frontend (React)
- **Lease List Page**: all leases with status, expiry, tenant
- **Lease Form Page**: create/edit with all terms
- **Lease Detail Page**: summary, payment history, addendums
- **Renewal Wizard**: step-by-step lease renewal
