# T066 — BOM Revisions & Versioning

- **Phase**: 6
- **Depends On**: T062
- **Estimated Effort**: 2 days

## What Is Being Built
BOM revision control (v1, v2, ...). Effective date range. Approval workflow on new revision. Compare revisions diff. Default revision marking.

## How It Will Be Built

### Backend (Django)
- **Model Extension** (`apps/mrp/models.py`):
  - `BOM.version` field (auto-increment per item)
  - `BOM.effective_date` and `BOM.expiry_date`
  - `BOM.is_default` (only one default per item)
- **Service**: create new revision (clone existing), compare revisions (added/removed/changed lines), set default
- **API**: create revision, compare, set default

## Deliverables Checklist
- [ ] BOM version auto-increment
- [ ] Effective/expiry date range
- [ ] Create new revision (clone from existing)
- [ ] Compare revisions (diff view)
- [ ] Set default BOM per item
- [ ] Approval workflow on new revision
- [ ] React revision comparison page

## Success Criteria
- [ ] New revision clones existing BOM lines
- [ ] Compare shows added/removed/changed lines
- [ ] Only one default BOM per item
- [ ] Effective date controls which BOM is active
- [ ] All tests pass
