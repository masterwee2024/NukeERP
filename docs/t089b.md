# T089b — Report Designer UI

- **Phase**: 2
- **Depends On**: T089a
- **Estimated Effort**: 5 days

## What Is Being Built
Drag-and-drop report designer interface. Users select data source, pick fields, build filters, configure grouping/sorting, set up pivot/cross-tab, add charts, preview results live. No code required — users build reports visually.

## How It Will Be Built

### Frontend (React)
- **ReportDesigner** (`frontend/src/components/reporting/ReportDesigner.tsx`):
  - Three-panel layout: data source/fields (left), canvas (center), properties (right)
  - Save/Load/Export buttons in toolbar
  - Live preview toggle

- **DataSourceSelector** (`frontend/src/components/reporting/DataSourceSelector.tsx`):
  - Dropdown of available data sources from T089a
  - Shows description and field count
  - On select: loads field list

- **FieldPicker** (`frontend/src/components/reporting/FieldPicker.tsx`):
  - Categorized field list (dimensions, measures, dates)
  - Drag to columns/rows/measures area
  - Field type indicators (text, number, date)

- **FilterBuilder** (`frontend/src/components/reporting/FilterBuilder.tsx`):
  - Add/remove filter conditions
  - Field selector, operator dropdown (=, !=, >, <, >=, <=, in, not_in, like, between, is_null)
  - Value input (dynamic: text, date picker, multi-select)
  - AND/OR logic between conditions

- **GroupConfig** (`frontend/src/components/reporting/GroupConfig.tsx`):
  - Drag fields to group by
  - Subtotal options (per group, grand total)
  - Group expansion/collapse in preview

- **PivotConfig** (`frontend/src/components/reporting/PivotConfig.tsx`):
  - Row fields (drag here)
  - Column fields (drag here)
  - Value field (drag here)
  - Aggregation selector (sum, count, avg, min, max)
  - Grand total toggle

- **ChartConfig** (`frontend/src/components/reporting/ChartConfig.tsx`):
  - Chart type selector (bar, line, pie, scatter, area)
  - X axis field, Y axis field
  - Series field (for grouped charts)
  - Title, colors, legend

- **PreviewPanel** (`frontend/src/components/reporting/PreviewPanel.tsx`):
  - Live preview of report results
  - Table view with sorting
  - Chart preview
  - Pivot table preview
  - Loading state while executing

- **ReportListPage** (`frontend/src/components/reporting/ReportListPage.tsx`):
  - List of saved reports
  - Search, filter by data source
  - Quick actions: run, edit, clone, delete, schedule

### Library
- `@dnd-kit/core` — drag and drop
- `recharts` — chart rendering (already in project)
- No heavy BI dependencies
