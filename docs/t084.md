# T083 — Payroll: EIS Calculation

- **Phase**: 7
- **Depends On**: T077
- **Estimated Effort**: 1 day

## What Is Being Built
EIS: 0.2% employer + 0.2% employee, capped at monthly wage ceiling. Contribution calculation. Return data.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `EISContribution`: employee FK, payroll_period FK, employee_contribution, employer_contribution, total_contribution, wage_for_eis
- **Service**: calculation (0.2% each, capped at ceiling), return data generation
- **API**: EIS calculation, return data

### EIS Rate
- Rate: 0.2% employee + 0.2% employer
- Ceiling: RM5,000 per month (as of 2024)
