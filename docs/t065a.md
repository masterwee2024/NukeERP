# T065a — Client Portal (Full)

- **Phase**: 5
- **Depends On**: T065c, T032, T063, T062, T019a
- **Estimated Effort**: 5 days

## What Is Being Built
Full client portal for customers to self-service: view quotations, orders, invoices, statements, delivery tracking, make payments, submit support tickets, collaborate with internal team via dedicated messaging channel. Desktop and mobile responsive. PWA installable.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/core/models.py`):
  - `PortalUser`: id, user FK → User, entity_type (customer/supplier), entity_id (UUID — links to Customer or Vendor), portal_role (admin/user), is_active, last_login, created_at
  - `SupportTicket`: id, ticket_number, portal_user FK, subject, description, category (billing/delivery/product/other), priority (low/medium/high), status (open/in_progress/resolved/closed), assigned_to FK (internal), created_at, updated_at
  - `SupportTicketMessage`: id, ticket FK, sender FK → User, sender_type (internal/external), content, created_at
  - `PaymentRecord`: id, portal_user FK, invoice FK, amount, payment_method (online_banking/credit_card/transfer), reference, status (pending/completed/failed), processed_at

- **Service** (`apps/portal/services/client_portal_service.py`):
  - `get_customer_documents(customer_id)` — quotations, orders, invoices, statements
  - `get_delivery_tracking(customer_id)` — DO status, delivery dates
  - `get_account_balance(customer_id)` — outstanding, aging, payment history
  - `submit_support_ticket(portal_user_id, data)` — create ticket
  - `reply_ticket(ticket_id, content, sender_type)` — reply to ticket
  - `process_payment(payment_data)` — process online payment
  - `get_messaging_channel(portal_user_id)` — get or create dedicated channel

- **API** (`apps/portal/api/client_api.py`):
  - `GET /api/v1/portal/client/quotations/` — customer's quotations
  - `GET /api/v1/portal/client/orders/` — customer's orders
  - `GET /api/v1/portal/client/invoices/` — customer's invoices
  - `GET /api/v1/portal/client/invoices/{id}/pdf/` — download invoice PDF
  - `GET /api/v1/portal/client/statements/` — account statement
  - `GET /api/v1/portal/client/deliveries/` — delivery tracking
  - `GET /api/v1/portal/client/balance/` — account balance
  - `POST /api/v1/portal/client/tickets/` — create support ticket
  - `GET /api/v1/portal/client/tickets/` — list tickets
  - `POST /api/v1/portal/client/tickets/{id}/reply/` — reply to ticket
  - `POST /api/v1/portal/client/payments/` — make payment
  - `GET /api/v1/portal/client/messaging/` — get messaging channel

- **Security**: All queries scoped to portal_user's customer_id. No cross-customer data leakage.

### Frontend (React)
- **ClientPortalLayout** (`frontend/src/components/portal/ClientPortalLayout.tsx`):
  - Portal-specific layout (simpler than internal)
  - Header: logo, notifications, messaging, profile
  - Sidebar: navigation (Dashboard, Documents, Payments, Support, Messaging)
  - Mobile: hamburger menu, full-width content

- **ClientDashboard** (`frontend/src/components/portal/ClientDashboard.tsx`):
  - KPI cards: outstanding balance, pending deliveries, open tickets
  - Recent activity list
  - Quick actions (view invoices, make payment, submit ticket)

- **ClientDocumentsPage** (`frontend/src/components/portal/ClientDocumentsPage.tsx`):
  - Tabs: Quotations, Orders, Invoices, Statements
  - List with filters (date, status)
  - Click to view detail
  - PDF download button

- **ClientPaymentsPage** (`frontend/src/components/portal/ClientPaymentsPage.tsx`):
  - Outstanding invoices list
  - Make payment button (online banking integration)
  - Payment history
  - Account balance

- **ClientDeliveryPage** (`frontend/src/components/portal/ClientDeliveryPage.tsx`):
  - Delivery tracking list
  - Status timeline (ordered → dispatched → delivered)
  - DO detail with items
  - Confirm receipt button

- **ClientSupportPage** (`frontend/src/components/portal/ClientSupportPage.tsx`):
  - Ticket list with status
  - Create ticket form
  - Ticket detail with message thread
  - Reply input

- **ClientMessagingPage** (`frontend/src/components/portal/ClientMessagingPage.tsx`):
  - Dedicated channel with internal team
  - Same messaging UI as internal (T019b)
  - Cannot see other clients' channels
