# T009a — Document Attachments

- **Phase**: 0
- **Depends On**: T009
- **Estimated Effort**: 2 days

## What Is Being Built
Global document attachment service. Any record in the system can have file attachments (PDF, images, documents). Upload, download, preview, delete. Used by invoices (supplier receipts), employees (contracts, IC), items (product images), quotations (termsheets), etc.

## How It Will Be Built

### Backend (Django)
- **Model** (`apps/core/models.py`):
  - `Attachment`: id, content_type (generic FK — links to any model), object_id (UUID), file (FileField), file_name, file_size, mime_type, uploaded_by FK → User, description, is_active, created_at
- **Service** (`apps/core/services/attachment_service.py`):
  - `upload_attachment(content_type, object_id, file, user)` — upload and link to any record
  - `get_attachments(content_type, object_id)` — list attachments for a record
  - `delete_attachment(attachment_id)` — soft delete
  - `download_attachment(attachment_id)` — serve file
- **API** (`apps/core/api/attachment_api.py`):
  - `POST /api/v1/attachments/upload/` — upload file (multipart form data)
  - `GET /api/v1/attachments/{content_type}/{object_id}/` — list attachments for record
  - `GET /api/v1/attachments/{id}/download/` — download file
  - `DELETE /api/v1/attachments/{id}/` — delete attachment
- **Storage**: MinIO (S3-compatible) or local filesystem (configurable)
- **Limits**: max file size 10MB, allowed types: pdf, jpg, jpeg, png, gif, doc, docx, xls, xlsx

### Frontend (React)
- **AttachmentUpload** (`frontend/src/components/ui/AttachmentUpload.tsx`):
  - Drag-and-drop upload zone
  - File type validation
  - Upload progress bar
  - Multiple file upload support
- **AttachmentList** (`frontend/src/components/ui/AttachmentList.tsx`):
  - List of attachments with file icon, name, size, uploaded by, date
  - Download button per attachment
  - Delete button (with confirm dialog)
  - Preview for images and PDFs
- **useAttachments** hook: fetch, upload, delete attachments for any record

### Integration Pattern
```typescript
// Any component can add attachments:
const { attachments, upload, remove } = useAttachments('supplier_invoice', invoiceId);

// Upload:
await upload(file, 'Receipt from supplier');

// List:
attachments.map(a => <a href={a.downloadUrl}>{a.fileName}</a>)
```
