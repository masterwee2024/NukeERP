# T012 — Visual Page Builder UI

- **Phase**: 1
- **Depends On**: T011
- **Estimated Effort**: 6 days

## What Is Being Built
Drag-and-drop admin interface for managing page configs visually. Component palette, live canvas preview, property editor panel. Non-technical users can create and modify page layouts without touching code.

## How It Will Be Built

### Frontend (React)
- **PageBuilderLayout.tsx** (`frontend/src/components/page-builder/`) — three-panel layout:
  - Left: ComponentPalette (240px, collapsible)
  - Center: Canvas (flex, live preview)
  - Right: PropertyEditor (320px, collapsible)

- **ComponentPalette.tsx** — categorized draggable components:
  - Input Fields: text, number, email, password, textarea
  - Selection: select, multi-select, autocomplete, radio, checkbox, toggle
  - Date/Time: date, datetime, time
  - Display: heading, separator, readonly_text, badge
  - Upload: file, image
  - Layout: group, tabs, spacer
  - Data: inline table, related table

- **Canvas.tsx** — drop zone with live preview:
  - Drag from palette to add field
  - Drag to reorder fields within and between groups
  - Click to select → opens PropertyEditor for that field
  - Group into sections (by group_name) or tabs
  - 12-column grid layout with col_span visualization
  - Preview mode toggle (switches between builder view and actual form rendering)
  - Empty state with prompt to drag first field

- **PropertyEditor.tsx** — all PageConfigField properties organized in tabs:
  - General: field_name, label, placeholder, help_text, default_value
  - Type & Data: field_type (dropdown), data_type (dropdown), width
  - Validation: required, readonly, disabled, min_length, max_length, min_value, max_value, pattern, custom_validator
  - Options: options_source (dropdown), options (JSON editor), options_api, options_label_field, options_value_field, option_group_by
  - Relationship: related_entity, related_display, related_search (tag input), related_fields (JSON editor)
  - Conditional: show_when (visual condition builder), depends_on (multi-select)
  - Table Columns: is_column, column_order, column_width, column_align, sortable, filterable, searchable, aggregate, render_as
  - Inline Table: line_entity, line_fields (sub-builder for line item fields)
  - Permissions: permission_read, permission_write
  - UI: icon (icon picker), prefix, suffix, format, badge_color (color picker), css_class
  - Responsive: show_on_desktop, show_on_mobile, desktop_col_span, mobile_col_span, mobile_render_as, desktop_layout, mobile_layout, list_mobile_view, mobile_group_by

- **ConfigActions.tsx** — top bar:
  - Page selector dropdown (create new / edit existing / search)
  - Save button (persists to database)
  - Publish button (marks config as active)
  - Preview mode toggle
  - Export as JSON / Import from JSON
  - Clone page config

- **PageList.tsx** — admin page listing all page configs with:
  - Search by page_key or page_title
  - Filter by module
  - Quick actions: edit, clone, delete, export

### Library
- `@dnd-kit/core` + `@dnd-kit/sortable` — drag and drop (lightweight, accessible, maintained)
- No heavy UI framework dependencies

### Routes
- `/admin/page-builder` — page list
- `/admin/page-builder/{page_key}` — edit specific page config
- `/admin/page-builder/new` — create new page config
