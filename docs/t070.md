# T069 — Master Production Schedule (MPS)

- **Phase**: 6
- **Depends On**: T041, T064
- **Estimated Effort**: 3 days

## What Is Being Built
MPS grid: item × time bucket (weekly). Demand forecast + sales orders + safety stock. Manual MPS entry. Rough-cut capacity check against work center capacity.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/mrp/models.py`):
  - `MPSPlan`: item FK, period_start_date, period_end_date, forecast_qty, sales_order_qty, safety_stock, mps_qty, projected_available, company FK
- **Service**: calculate projected available balance, rough-cut capacity check, generate planned orders
- **API**: MPS CRUD + calculate + capacity check

### Frontend (React)
- `MPSPage` — editable grid (item × week), inline editing, capacity indicator
