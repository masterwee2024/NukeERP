# T054 — Stock Take & Cycle Count

- **Phase**: 4
- **Depends On**: T045
- **Estimated Effort**: 3 days

## What Is Being Built
Stock take sheet generation (by warehouse/zone). Count entry (first count → second count/recount). Variance report. Stock adjustment approval. Cycle count scheduling (ABC analysis).

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `StockTake`: stocktake_number, warehouse FK, status (in_progress/completed/adjusted), start_date, end_date, company FK
  - `StockTakeLine`: stocktake FK, item FK, bin_location FK, system_qty, first_count_qty, recount_qty, final_qty, variance, variance_value, notes
- **Service**: generate sheet, record counts, calculate variance, post adjustment
- **API**: CRUD + count entry + complete + adjust

## Deliverables Checklist
- [ ] `StockTake` and `StockTakeLine` models
