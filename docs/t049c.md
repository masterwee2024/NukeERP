# T049c — Stock Issue (Non-Trading Items)

- **Phase**: 4
- **Depends On**: T049
- **Estimated Effort**: 2 days

## What Is Being Built
Stock issue for non-trading items — issuing inventory for internal use (maintenance supplies, packaging consumables, office supplies, cleaning materials). Items are not for resale but still tracked in inventory. GL entry debits expense account, not COGS.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `StockIssue`: id, issue_number, issue_date, department FK, requested_by FK, approved_by FK, purpose (maintenance/packaging/office/cleaning/other), status (draft/approved/issued/cancelled), gl_account FK (expense account), company FK, created_at
  - `StockIssueLine`: issue FK, item FK, quantity, uom FK, unit_cost, total_cost, warehouse FK, bin_location FK
- **Service** (`apps/scm/services/stock_issue_service.py`):
  - `create_stock_issue(data)` — create issue request
  - `approve_issue(issue_id)` — approve with confirmation
  - `issue_stock(issue_id)` — reduce stock, create stock movement, create GL entry
  - `get_issue_history(filters)` — past issues
- **GL Entries**:
  ```
  Issue 100 units of packing material at RM5/unit:
  DR Packing Expense                500.00
  CR Raw Material Inventory         500.00
  ```
- **Stock Movement**: type = "issue", quantity_out = issued qty

### Frontend (React)
- **Stock Issue Form**: select items, quantities, purpose, department
- **Issue List Page**: all issues with status and filters
- **Approval Workflow**: approve before issuing
