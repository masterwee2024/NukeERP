# T041d — Multi-Currency Bank Accounts

- **Phase**: 3
- **Depends On**: T041, T034a
- **Estimated Effort**: 2 days

## What Is Being Built
Enhanced bank account management for multi-currency operations. Bank accounts can hold foreign currencies. Realized forex gain/loss on bank transfers between currency accounts. Bank balance reporting in base currency (MYR) using closing rate.

## How It Will Be Built

### Backend (Django)
- **Model Updates** (`apps/treasury/models.py`):
  - `BankAccount`: add fields — `opening_balance_foreign`, `current_balance_foreign`, `last_revaluation_date`
- **Service** (`apps/treasury/services/multi_currency_bank_service.py`):
  - `get_bank_balance_in_baseCurrency(bank_account_id, as_at_date)` — convert foreign balance to MYR using closing rate
  - `transfer_between_currency_accounts(from_account, to_account, amount, date)` — create FX conversion entry
  - `revalue_bank_balances(company, period)` — revalue foreign currency bank balances at closing rate
  - `get_bank_balance_report(company)` — all accounts with balances in base currency
- **GL Entries** (transfer between USD and MYR accounts):
  ```
  Transfer USD 10,000 from USD account to MYR account:
  USD Account: USD 10,000 @ 4.72 = MYR 47,200

  DR Bank (MYR account)              47,200.00
  CR Bank (USD account)              47,200.00
  ```

### Frontend (React)
- **Bank Balance Report**: all accounts with balances in both foreign and base currency
- **Transfer Form**: select source/destination accounts, handle currency conversion
