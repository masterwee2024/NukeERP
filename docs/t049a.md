# T049a — Landed Cost Adjustments

- **Phase**: 4
- **Depends On**: T049, T054
- **Estimated Effort**: 3 days

## What Is Being Built
Landed cost calculation — adding freight, insurance, customs duty, and other costs to the purchase cost of inventory. Distribute landed costs across GRN lines (by value, quantity, or weight). Update stock cost with landed cost. GL entries for landed cost.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `LandedCostHeader`: id, grn FK, total_landed_cost, currency, exchange_rate, status (draft/posted), company FK, created_at
  - `LandedCostLine`: header FK, cost_type (freight/insurance/customs/handling/other), description, amount, account FK
  - `LandedCostAllocation`: id, header FK, grn_line FK, allocated_amount, allocation_method (value/quantity/weight)
- **Service** (`apps/scm/services/landed_cost_service.py`):
  - `create_landed_cost(grn_id, data)` — create landed cost header and lines
  - `allocate_costs(header_id, method)` — distribute costs across GRN lines
  - `post_landed_cost(header_id)` — update stock cost, create GL entries
  - `calculate_unit_cost(item, grn_line)` — purchase price + allocated landed cost
- **Allocation Methods**:
  - By Value: proportional to line value (default)
  - By Quantity: proportional to quantity received
  - By Weight: proportional to line weight

### GL Entries
```
Freight Charge: RM5,000 allocated to 3 GRN lines

DR Inventory (GRN Line 1)           2,000.00
DR Inventory (GRN Line 2)           1,500.00
DR Inventory (GRN Line 3)           1,500.00
CR Accrued Freight Payable          5,000.00
```

### Frontend (React)
- **Landed Cost Form**: enter costs, select allocation method, preview allocation
- **Allocation Preview**: show how costs distribute across GRN lines
- **Post Button**: confirm and post (with useConfirm dialog)
