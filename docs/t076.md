# T076 — Employee Master

- **Phase**: 7
- **Depends On**: T010
- **Estimated Effort**: 3 days

## What Is Being Built
`Employee` model: employee no, name, IC no, joining date, confirmation date, designation, department, grade, employment type (permanent/contract/probation). Emergency contacts. Bank details for payroll. Document vault (IC, contracts, certs).

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `Employee`: employee_no (unique globally), name, ic_no, email, phone, date_of_birth, gender, race, religion, marital_status, photo, joining_date, confirmation_date, designation FK, grade FK, employment_type, reporting_to FK, status (active/resigned/terminated), bank_name, bank_account_no, bank_branch
  - `EmployeeCompany`: employee FK, company FK, department FK, is_primary (bool), effective_date, unique(employee, company)
  - `EmergencyContact`: employee FK, name, relationship, phone, address
  - `EmployeeDocument`: employee FK, document_type (ic/contract/certificate/other), title, file, uploaded_at
- **Service**: CRUD, search, document management
- **API**: Employee CRUD + documents + search

### Frontend (React)
- `EmployeeListPage` — table with department/status filter
- `EmployeeFormPage` — create/edit with tabs (personal, employment, bank, documents)
- `EmployeeDetailPage` — profile with all tabs
