# T078 — Shift & Roster Management

- **Phase**: 7
- **Depends On**: T074
- **Estimated Effort**: 2 days

## What Is Being Built
`Shift` model (name, start time, end time, break duration, grace period). Roster assignment (employee × date × shift). Shift swap request/approval. Overtime rate per shift type (normal/rest day/public holiday).

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `Shift`: name, start_time, end_time, break_minutes, grace_period_minutes, is_active, company FK
  - `Roster`: employee FK, date, shift FK, status (scheduled/confirmed/absent)
  - `ShiftSwapRequest`: employee FK, original_date, requested_date, swap_with FK, status (pending/approved/rejected), approved_by FK
  - `OvertimeRate`: shift_type (normal/rest_day/public holiday), rate_multiplier
- **Service**: CRUD, roster generation, swap request/approval, overtime rate lookup
- **API**: Shift/roster CRUD + swap request + approve
