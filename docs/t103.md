# T103 — Retention Money

- **Phase**: 2
- **Depends On**: T102
- **Estimated Effort**: 2 days

## What Is Being Built
Retention money management for project-based companies. Track retention held from progress claims (5-10%). Retention release after defects liability period (DLP). Retention aging. GL entries for retention receivable/payable.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `RetentionRecord`: id, project FK, claim FK, retention_amount, retention_date, dlp_end_date (defects liability period end), release_date, status (held/released/partially_released), released_amount, company FK, created_at
- **Service** (`apps/financial/services/retention_service.py`):
  - `create_retention(claim_id)` — create retention record from progress claim
  - `release_retention(retention_id, amount)` — release retention (partial or full)
  - `get_retention_summary(company)` — total held, total released, aging
  - `get_released_retention_report(company, period)` — released retention for period
  - `get_expiring_retention(company, days)` — retention expiring within N days
- **GL Entries**
  ```
  On Progress Claim (retention deducted):
  DR Retention Receivable             25,000.00
  CR Accounts Receivable              25,000.00

  On Retention Release:
  DR Bank                            25,000.00
  CR Retention Receivable             25,000.00
  ```

### Frontend (React)
- **Retention Summary Page**: all retention records with status
- **Retention Release Form**: release retention with amount
- **Retention Aging**: aging report by DLP end date
- **Expiring Retention Widget**: dashboard widget
