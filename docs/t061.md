# T060 — Sales Order Management

- **Phase**: 5
- **Depends On**: T056
- **Estimated Effort**: 4 days

## What Is Being Built
`SalesOrder` CRUD. Copy from quotation. Order status (draft/confirmed/partially_delivered/delivered/cancelled). Backorder tracking. Credit limit check. Delivery schedule.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/crm/models.py`):
  - `SalesOrder`: order_number, quotation FK (optional), customer FK, order_date, status, delivery_date, total, tax_total, grand_total, company FK
  - `SalesOrderLine`: order FK, line_number, item FK, description, quantity, delivered_quantity, uom FK, unit_price, discount_percent, amount, tax_code FK, tax_amount
- **Service**: CRUD, copy from quotation, credit limit check, backorder calculation, status tracking
- **API**: Full CRUD + confirm + status endpoints
