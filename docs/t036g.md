# T036g — Equipment Allocation & Usage (Project Equipment)

- **Phase**: 3
- **Depends On**: T036, T100
- **Estimated Effort**: 3 days

## What Is Being Built
Equipment allocation to projects, usage logging (hours or meter reading), cost per hour of usage charged to project. Rental vs owned equipment tracking. Equipment transfer between projects/sites. Integration with T101 Project Cost Tracking. For construction machinery, delivery trucks, and other mobile equipment used across projects.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/assets/models.py`):
  - `EquipmentAllocation`: id, asset FK, project FK, allocation_date, return_date, purpose, allocated_by FK, status (active/returned), company FK, created_at
  - `EquipmentUsageLog`: id, allocation FK, asset FK, log_date, hours_used, meter_reading_start, meter_reading_end, operator FK, fuel_cost, other_cost, notes, created_by FK, company FK
  - `EquipmentRate`: id, asset FK, rate_per_hour (depreciation + fuel + maintenance provision), effective_date, is_active, company FK
  - `RentalAgreement`: id, agreement_number, vendor FK, asset_description, rental_type (short_term/long_term/wet_rent/dry_rent), start_date, end_date, monthly_rental_cost, daily_rate, deposit_amount, status (active/terminated/completed), related_project FK (optional), company FK, created_at
- **Service** (`apps/assets/services/equipment_service.py`):
  - `allocate_equipment(asset_id, project_id, purpose)` — assign equipment to project
  - `return_equipment(allocation_id)` — return equipment, calculate final cost
  - `log_usage(allocation_id, data)` — record hours/meter, calculate cost
  - `calculate_usage_cost(allocation_id)` — sum of hours × rate + fuel + other
  - `get_equipment_utilization(company, period)` — usage % across all equipment
  - `get_project_equipment_cost(project_id)` — total equipment cost for project
  - `get_available_equipment(company, date)` — equipment not currently allocated
  - `create_rental_agreement(data)` — track rental equipment
  - `compare_rental_vs_owned(company)` — cost comparison
- **API** (`apps/assets/api/equipment_api.py`):
  - Allocation CRUD, usage logging, cost calculation, utilization, rental agreements

### Cost Flow to Project (T101)
```
Equipment: Excavator (owned)
├── Rate per hour: RM200 (depreciation RM80 + fuel RM100 + maintenance provision RM20)
├── Allocated to Project A
├── Usage: 8 hours on 15 Jan, 6 hours on 16 Jan = 14 hours
├── Usage cost: 14 × RM200 = RM2,800
├── Fuel cost: RM1,500
├── Total: RM4,300
└── Project Cost Entry (T101):
    DR Project Equipment Cost        4,300.00
    CR Equipment Cost Provision      4,300.00
```

### Rental vs Owned Comparison
```
Owned Excavator:
├── Monthly cost: RM16,000 (depreciation RM8,000 + maintenance RM3,000 + fuel RM5,000)
├── Usage: 200 hours/month
├── Cost per hour: RM80

Rental Excavator:
├── Monthly rental: RM12,000
├── Fuel: RM5,000
├── Total: RM17,000
├── Usage: 200 hours/month
├── Cost per hour: RM85

Decision: Own (lower cost per hour)
```
