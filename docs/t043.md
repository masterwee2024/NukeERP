# T042 — Cash Flow Forecasting

- **Phase**: 3
- **Depends On**: T036, T037
- **Estimated Effort**: 3 days

## What Is Being Built
Projected cash inflows from AR due dates and outflows from AP due dates. Manual adjustments. Weekly/monthly view. Scenario analysis (best/worst/base case).

## How It Will Be Built

### Backend (Django)
- **Service** (`apps/treasury/services/forecast_service.py`):
  - `get_cash_forecast(company, start_date, end_date, granularity)` — aggregate AR inflows + AP outflows + manual entries by period
  - `create_manual_forecast_entry()` — manual adjustment
  - `get_scenario(company, scenario_type)` — best/worst/base case with probability weighting
- **API**: forecast data, manual entries, scenario analysis

### Frontend (React)
- `CashForecastPage` — forecast table with chart, period selector, scenario toggle
