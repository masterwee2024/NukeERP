# T086 — Payroll: Payslip Generation

- **Phase**: 7
- **Depends On**: T077, T078, T079, T080, T081, T082
- **Estimated Effort**: 4 days

## What Is Being Built
Monthly payroll run: select employees → calculate gross → deductions (EPF, SOCSO, EIS, PCB, TH, Zakat, advances) → net pay. Payslip PDF generation (BM template). Email payslip to employee. Bank payment file (EFT/IBG format). GL journal entry for payroll.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `PayrollPeriod`: name, start_date, end_date, status (draft/processing/completed/closed), company FK
  - `PayrollRun`: period FK, run_date, total_employees, total_gross, total_deductions, total_net_pay, status, company FK
  - `PayRunDetail`: payroll_run FK, employee FK, basic_salary, allowances, gross_pay, epf_employee, socso_employee, eis_employee, pcb, th_amount, zakat_amount, advances, other_deductions, total_deductions, net_pay
  - `Payslip`: pay_run_detail FK, payslip_number, generated_pdf, email_sent, email_sent_at
- **Service** (`apps/hrm/services/payroll_service.py`):
  - `run_payroll(period_id, employee_ids)` — calculate for all selected employees
  - `generate_payslip_pdf(pay_run_detail_id)` — WeasyPrint BM template
  - `email_payslip(payslip_id)` — send via Celery
  - `generate_bank_file(payroll_run_id)` — EFT/IBG format
  - `post_payroll_to_gl(payroll_run_id)` — GL: DR salaries expense, DR EPF employer, CR EPF payable, CR SOCSO payable, CR EIS payable, CR PCB payable, CR TH payable, CR Zakat payable, CR bank
- **API**: run payroll, view payslips, generate PDF, email, bank file, post GL

### Frontend (React)
- `PayrollRunPage` — select period, select employees, run payroll, review totals
- `PayslipListPage` — list of generated payslips
- `PayslipDetailPage` — individual payslip view
