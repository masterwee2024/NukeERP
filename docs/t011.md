# T011 — Dynamic Page Renderer

- **Phase**: 1
- **Depends On**: T010
- **Estimated Effort**: 7 days
- **Status**: Completed

## What Is Being Built
Generic React components that render any page from `PageConfig`. Four page types: form, list, detail, dashboard. One component per field type. Validation driven by config. Conditional display. Inline tables for line items.

## How It Will Be Built

### Frontend (React)
- **Page Components** (`frontend/src/components/dynamic/`):
  - `DynamicPageRenderer.tsx` — top-level dispatcher (reads page_type, renders correct page)
  - `DynamicFormPage.tsx` — reads config, renders field groups as sections/tabs
  - `DynamicListPage.tsx` — reads config, renders table with columns/filters/search/pagination
  - `DynamicDetailPage.tsx` — reads config, renders read-only view with linked records
  - `DynamicDashboardPage.tsx` — reads config, renders KPI cards + charts + tables
  - `ResponsiveRenderer.tsx` — detects viewport (mobile/tablet/desktop), renders correct layout based on PageConfig desktop_layout vs mobile_layout
  - `CardView.tsx` — mobile card view for list pages (replaces table when viewport < 768px), renders each record as a card with fields from config

- **Field Components** (`frontend/src/components/dynamic/fields/`):
  - `DynamicField.tsx` — master switch (dispatches to specific field component based on field_type)
  - `TextField.tsx`, `NumberField.tsx`, `DecimalField.tsx`, `TextareaField.tsx`
  - `SelectField.tsx`, `MultiSelectField.tsx`, `AutocompleteField.tsx`
  - `DateField.tsx`, `DateTimeField.tsx`, `TimeField.tsx`
  - `ToggleField.tsx`, `CheckboxField.tsx`, `RadioField.tsx`
  - `FileField.tsx`, `ImageField.tsx`
  - `CurrencyField.tsx` (with prefix), `PercentageField.tsx` (with suffix)
  - `HeadingField.tsx`, `SeparatorField.tsx`, `SpacerField.tsx`
  - `InlineTableField.tsx` (parent-detail line items with add/remove/edit rows)
  - `ReadonlyTextField.tsx`, `BadgeField.tsx` (with badge_color mapping)

- **Engine Components**:
  - `ValidationEngine.tsx` — reads min_length, max_length, min_value, max_value, pattern, required. Custom validator registry. Real-time validation on blur + on submit.
  - `ConditionalEngine.tsx` — evaluates show_when JSON conditions. Re-evaluates when depends_on fields change. Hides/shows fields dynamically.
  - `OptionsResolver.tsx` — resolves options from static JSON, API endpoint, enum, or model.

- **Hooks**:
  - `usePageConfig(pageKey)` — from T010
  - `useFieldValidation(field)` — validates per config rules, returns error messages
  - `useConditionalDisplay(fields)` — evaluates all show_when conditions, returns visibility map
  - `useOptionsResolver(field)` — fetches/caches options from api or static
  - `useCompanyContext()` — returns active company, filters all data by company_id or company assignment
  - `useViewport()` — returns { isMobile: <768px, isTablet: 768-1024px, isDesktop: >1024px }, used by ResponsiveRenderer

### Layout System
- `FieldGroup.tsx` — groups fields by group_name into collapsible sections
- `TabGroup.tsx` — renders groups as tabs when layout=tabs
- `GridLayout.tsx` — 12-column Tailwind grid, fields positioned by desktop_col_span (desktop) or mobile_col_span (mobile), auto-switches based on viewport
- `ResponsiveFieldFilter.tsx` — filters fields based on show_on_desktop/show_on_mobile flags before rendering
