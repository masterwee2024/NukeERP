# T082 — Payroll: SOCSO Calculation

- **Phase**: 7
- **Depends On**: T077
- **Estimated Effort**: 2 days

## What Is Being Built
SOCSO contribution by wage bracket (First Category: Employment Injury + Invalidity). Employer + employee share. SOCSO monthly return data.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/hrm/models.py`):
  - `SOCSOContribution`: employee FK, payroll_period FK, employee_contribution, employer_contribution, total_contribution, wage_for_socso
- **Service** (`apps/hrm/services/socso_service.py`):
  - `calculate_socso(basic_salary + allowances)` — lookup wage bracket table
  - `generate_socso_return(company, period)` — monthly return data
- **API**: SOCSO calculation, return data

### SOCSO Rate Table (wage brackets)
| Monthly Wage (RM) | Employee (First Cat.) | Employer (First Cat.) |
|---|---|---|
| ≤ 1,000 | 0.10 | 0.40 |
| 1,001 – 2,000 | 0.20 | 0.70 |
| 2,001 – 3,000 | 0.30 | 1.10 |
| 3,001 – 4,000 | 0.40 | 1.50 |
| 4,001 – 5,000 | 0.55 | 1.90 |
| 5,001+ | 0.65 | 2.30 |
