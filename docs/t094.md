# T093 — Mobile PWA Optimization

- **Phase**: 8
- **Depends On**: T006
- **Estimated Effort**: 3 days

## What Is Being Built
Service worker for offline caching. Install prompt (Add to Home Screen). Touch-optimized interactions (larger tap targets, swipe actions). Responsive data tables: card view on mobile, table view on desktop. Offline data entry queue (sync when online).

## How It Will Be Built

### Frontend (React)
- **PWA Config**: `frontend/public/manifest.json` — app name, icons, theme color, display: standalone
- **Service Worker**: workbox configuration for caching static assets + API responses
- **Touch Optimization**: min 44px tap targets, swipe-to-delete on list items
- **Responsive Tables**: `DataTable` component switches between table (desktop) and card (mobile) layout
- **Offline Queue**: `useOfflineQueue()` hook — stores pending writes in IndexedDB, syncs when online
- **Install Prompt**: custom install banner component
