# T041 — Petty Cash

- **Phase**: 3
- **Depends On**: T036
- **Estimated Effort**: 2 days

## What Is Being Built
Petty cash fund management: fund setup, reimbursement requests, top-up, cash count reconciliation.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/treasury/models.py`):
  - `PettyCashFund`: name, GL_account FK, fund_amount, current_balance, company FK, custodian FK
  - `PettyCashTransaction`: fund FK, date, type (disbursement/topup/reimbursement), amount, description, receipt_attachment, approved_by FK, status
- **Service**: disbursement, top-up, reimbursement, cash count reconciliation
- **API**: CRUD + approve + reconcile

## Deliverables Checklist
- [ ] `PettyCashFund` and `PettyCashTransaction` models
- [ ] Disbursement, top-up, reimbursement services
- [ ] Cash count reconciliation
- [ ] React petty cash pages
- [ ] All actions use `useConfirm()` dialog

## Success Criteria
- [ ] Disbursement reduces fund balance
- [ ] Top-up increases fund balance
- [ ] Cash count reconciliation shows variance
