# T089c — Report Viewer & Export

- **Phase**: 2
- **Depends On**: T089a, T089b
- **Estimated Effort**: 3 days

## What Is Being Built
Report viewer with rendering, drill-down, export (PDF/Excel/CSV), scheduled report email delivery, saved report management. Users can run saved reports, export results, and subscribe to scheduled reports.

## How It Will Be Built

### Backend (Django)
- **Export Service** (`apps/core/services/export_service.py`):
  - `export_to_pdf(data, config, template)` — generate PDF via WeasyPrint
  - `export_to_excel(data, config)` — generate Excel via openpyxl
  - `export_to_csv(data)` — generate CSV
  - `email_report(report_id, recipients, format)` — send report via email

- **Celery Tasks** (`apps/core/tasks.py`):
  - `execute_scheduled_report(schedule_id)` — run scheduled report
  - `email_scheduled_report(schedule_id, execution_id)` — email report to recipients

### Frontend (React)
- **ReportViewer** (`frontend/src/components/reporting/ReportViewer.tsx`):
  - Render report results (table, chart, or pivot)
  - Sort columns
  - Filter bar (quick filters)
  - Drill-down: click row to see detail
  - Export buttons (PDF, Excel, CSV)
  - Print button

- **DrillDownModal** (`frontend/src/components/reporting/DrillDownModal.tsx`):
  - Shows detail records for a specific row
  - Table with all fields for that row
  - Back button to return to summary

- **ReportHistoryPage** (`frontend/src/components/reporting/ReportHistoryPage.tsx`):
  - List of past report executions
  - Status, execution time, row count
  - Download result file
  - Re-run report

- **ScheduledReportsPage** (`frontend/src/components/reporting/ScheduledReportsPage.tsx`):
  - List of scheduled reports
  - Next run date, frequency, recipients
  - Enable/disable schedule
