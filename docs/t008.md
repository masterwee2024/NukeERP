# T008 — Authentication System

- **Phase**: 0
- **Depends On**: T006
- **Estimated Effort**: 3 days

## What Is Being Built
Custom `User` model with email-based login (not username), JWT authentication via `djangorestframework-simplejwt`, and React pages for login, register, forgot password, and reset password. Token storage in httpOnly cookies for XSS protection.

## How It Will Be Built

### Backend (Django)
- **Custom User Model** (`apps/core/models.py`):
  - `email` as the login field (not `username`)
  - `company FK` for multi-tenant filtering
  - `is_active`, `is_staff`, `is_superuser` flags
  - `last_login`, `date_joined`
- **Auth API** (`apps/core/api/auth_api.py`):
  - `POST /api/v1/auth/login/` — returns access + refresh tokens
  - `POST /api/v1/auth/logout/` — invalidates refresh token
  - `POST /api/v1/auth/token/refresh/` — refresh access token
  - `POST /api/v1/auth/register/` — create new user (if enabled)
  - `POST /api/v1/auth/forgot-password/` — send reset email via Celery
  - `POST /api/v1/auth/reset-password/` — validate token, update password
  - `GET /api/v1/auth/me/` — current user profile
- **JWT Settings**: access token TTL 15 min, refresh token TTL 7 days

### Frontend (React)
- **Pages**:
  - `LoginPage` — email + password form, "Forgot Password?" link
  - `RegisterPage` — name + email + password + confirm password
  - `ForgotPasswordPage` — email input, submit sends reset link
  - `ResetPasswordPage` — new password + confirm, validates token from URL
- **Auth Context**: `frontend/src/contexts/AuthContext.tsx`
  - `user`, `login()`, `logout()`, `isAuthenticated`
- **API Interceptor**: `frontend/src/lib/api.ts`
  - Axios instance with Bearer token injection
  - 401 response → silent refresh → retry request
  - Refresh failed → redirect to `/login`
