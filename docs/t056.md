# T056 — Vendor Management

- **Phase**: 4
- **Depends On**: T041
- **Estimated Effort**: 2 days

## What Is Being Built
Vendor master (extends supplier from T027) with procurement fields. Vendor category, payment terms, lead time, performance score (on-time delivery, quality), blacklist flag. Purchase history view.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `VendorCategory`: name, description
  - `VendorCompany`: vendor FK, company FK, payment_terms (override), gl_payable_account FK, is_active (per company), unique(vendor, company)
  - `VendorPerformance`: vendor FK, period, on_time_delivery_rate, quality_score, avg_lead_time, total_orders, total_value
- **Service**: CRUD, company assignment, performance scoring (auto-calculate from PO/GRN data), blacklist management
- **API**: Vendor CRUD + performance + history

### Frontend (React)
- `VendorListPage` — table with category filter, performance score
- `VendorDetailPage` — profile, performance metrics, purchase history
