# T045 — Item Master

- **Phase**: 4
- **Depends On**: T010
- **Estimated Effort**: 3 days

## What Is Being Built
`Item` model: code, name, description, category, UOM, tax code, cost method (FIFO/weighted average), selling price, reorder level, min/max stock, barcode. Item image. Active/inactive flag. Global record — no company_id FK. Assigned to companies via ItemCompany junction with per-company price overrides.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/scm/models.py`):
  - `ItemCategory`: name, code, parent FK (self), GL_account_inventory, GL_account_cogs, GL_account_revenue
  - `Item`: code (unique globally), name, description, category FK, base_uom FK → UoM (from T046), tax_code FK, cost_method (fifo/weighted_avg), selling_price (global default), purchase_price (global default), reorder_level (global default), min_stock, max_stock, barcode, image, is_active, notes
  - `ItemCompany`: item FK, company FK, selling_price (override, null = use global), purchase_price (override, null = use global), reorder_level (override, null = use global), is_active (per company), unique(item, company)
  - `ItemPackaging`: (from T046) item FK, uom FK, conversion_factor, is_default, uom_type — stores per-item custom packaging conversions
- **Service**: CRUD, search by code/name/barcode, validate unique code globally, manage company assignments, manage packaging (ItemPackaging)
- **API**: Item CRUD + search + list with filters

### Frontend (React)
- `ItemListPage` — table with search, category filter, status filter
- `ItemFormPage` — create/edit with image upload, UOM selection (from T046 two-layer UoM), tax code assignment, packaging configuration (ItemPackaging)
