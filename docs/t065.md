# T064 — Customer Portal (Basic)

- **Phase**: 5
- **Depends On**: T055, T056, T057, T059
- **Estimated Effort**: 3 days

## What Is Being Built
Customer login. View own quotations, orders, invoices, statements. Download PDFs. Submit support ticket. Read-only phase 5; full portal in phase 8.

## How It Will Be Built

### Backend (Django)
- **API** (`apps/crm/api/portal_api.py`):
  - `GET /api/v1/portal/quotations/` — customer's own quotations
  - `GET /api/v1/portal/orders/` — customer's own orders
  - `GET /api/v1/portal/invoices/` — customer's own invoices
  - `GET /api/v1/portal/statement/` — account statement
  - `GET /api/v1/portal/invoices/{id}/pdf/` — download invoice PDF
  - `POST /api/v1/portal/tickets/` — submit support ticket
- **Auth**: customer-specific JWT (separate user type or linked to customer record)

### Frontend (React)
- `CustomerPortalLayout` — separate layout for customer portal
- `PortalDashboardPage` — summary of quotes, orders, invoices
- `PortalInvoicesPage` — list with PDF download
- `PortalSubmitTicketPage` — support ticket form
