# T021 — Chart of Accounts

- **Phase**: 2
- **Depends On**: T010
- **Estimated Effort**: 3 days

## What Is Being Built
Hierarchical Chart of Accounts with MFRS-compliant categories. Account types: Asset, Liability, Equity, Revenue, Expense with subtypes. Tree structure via parent FK. Import from CSV template. Cannot delete accounts with transactions.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `Account`: code (unique globally), name, account_type (asset/liability/equity/revenue/expense), subtype (current_asset/non_current_asset/current_liability/long_term_liability/equity/revenue/cost_of_sales/operating_expense/non_operating), parent FK (self), level, is_group (has children), is_active, mfrs_code, notes
  - `AccountCompany`: account FK, company FK, is_active (per company), unique(account, company)
- **Service** (`apps/financial/services/account_service.py`):
  - `create_account()`, `update_account()`, `delete_account()` — validate no children before delete, no transactions before delete
  - `get_account_tree(company)` — build nested tree, filtered by company assignment
  - `assign_account_to_company(account_id, company_id)` — assign account to company
  - `import_accounts_from_csv(file)` — bulk import
- **API** (`apps/financial/api/account_api.py`):
  - `GET /api/v1/financial/accounts/` — list with tree structure
  - `POST /api/v1/financial/accounts/` — create
  - `PUT /api/v1/financial/accounts/{id}/` — update
  - `DELETE /api/v1/financial/accounts/{id}/` — delete (if no transactions)
  - `POST /api/v1/financial/accounts/import/` — CSV import
  - `GET /api/v1/financial/accounts/template/` — download CSV template
  - `POST /api/v1/financial/accounts/{id}/assign/` — assign account to company
  - `DELETE /api/v1/financial/accounts/{id}/assign/{company_id}/` — unassign
