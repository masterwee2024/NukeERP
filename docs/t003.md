# T003 — Git Repository & Graphify Setup

- **Phase**: 0
- **Depends On**: T001

## What Is Being Built
Git repository initialization with `.gitattributes`, `.gitignore`, pre-commit hooks (Ruff, Black, mypy), and initial Graphify knowledge graph integration for AI agent navigation.

## How It Will Be Built

### Git Setup
- `git init` in project root
- `.gitignore`: Python, Node.js, Django, IDE, .env, __pycache__, node_modules, dist, .vite
- `.gitattributes`: LF line endings, linguist-detectable languages

### Pre-commit Hooks
- Install `pre-commit` package
- `.pre-commit-config.yaml`: Ruff (lint+format), Black, mypy, trailing-whitespace, end-of-file-fixer

### Graphify Integration
- Create Graphify skill reference in project docs
- Generate initial knowledge graph JSON + HTML from codebase structure
- Link knowledge graph in `AGENTS.md`
