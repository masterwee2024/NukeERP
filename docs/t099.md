# T099 — Graphify Knowledge Graph — Final

- **Phase**: 8
- **Depends On**: T092, T093
- **Estimated Effort**: 1 day

## What Is Being Built
Full Graphify scan on entire codebase. Generate knowledge graph JSON + HTML. Cluster communities by module. Audit report for orphaned nodes. Link to AGENTS.md as primary reference for AI agents.

## How It Will Be Built

### Graphify Integration
1. Read Graphify skill from `~/.claude/skills/graphify/SKILL.md` or `~/.config/opencode/skills/graphify/SKILL.md`
2. Run Graphify on full pyERP codebase
3. Generate:
   - `docs/graphify/graph.json` — machine-readable knowledge graph
   - `docs/graphify/graph.html` — visual HTML graph
   - `docs/graphify/audit-report.md` — orphaned nodes, module boundaries, community detection
4. Update `AGENTS.md` to reference the knowledge graph

### Graphify Output
- **Communities**: detected modules (financial, scm, crm, mrp, hrm, core)
- **Nodes**: files, classes, functions
- **Edges**: imports, references, dependencies
- **Orphaned nodes**: files not connected to main graph (review for cleanup)
