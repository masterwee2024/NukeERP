# T029c — GL Account Mapping

- **Phase**: 2
- **Depends On**: T021
- **Estimated Effort**: 2 days

## What Is Being Built
Configurable GL account mapping per company. Instead of hardcoding which GL accounts are used for AP control, AR control, revenue, expense, etc., each company configures its own account mappings. This allows different companies in the same group to use different account structures while sharing the same codebase.

## How It Will Be Built

### Backend (Django)
- **Model** (`apps/financial/models.py`):
  - `GLAccountMapping`: id, company FK, mapping_type (string — unique per company), account FK → Account, description, is_active, created_at
  - `mapping_type` choices:
    - `ap_control` — Accounts Payable control account
    - `ar_control` — Accounts Receivable control account
    - `revenue_default` — Default revenue account
    - `expense_default` — Default expense account
    - `inventory_asset` — Inventory asset account
    - `cogs_default` — Default cost of goods sold
    - `tax_output` — SST output tax payable
    - `tax_input` — SST input tax receivable
    - `bank_default` — Default bank account
    - `cash_default` — Default cash account
    - `forex_realised_gain` — Realised forex gain
    - `forex_realised_loss` — Realised forex loss
    - `forex_unrealised_gain` — Unrealised forex gain
    - `forex_unrealised_loss` — Unrealised forex loss
    - `inter_company_receivable` — Inter-company receivable
    - `inter_company_payable` — Inter-company payable
    - `wht_payable` — Withholding tax payable
    - `epf_payable` — EPF payable
    - `socso_payable` — SOCSO payable
    - `eis_payable` — EIS payable
    - `pcb_payable` — PCB payable
    - `retained_arnings` — Retained earnings
- **Service** (`apps/financial/services/gl_mapping_service.py`):
  - `get_account(company, mapping_type)` — get GL account for mapping
  - `get_all_mappings(company)` — get all mappings for company
  - `set_mapping(company, mapping_type, account_id)` — set/update mapping
  - `validate_mappings(company)` — check all required mappings are set
- **API** (`apps/core/api/gl_mapping_api.py`):
  - `GET /api/v1/financial/gl-mappings/` — list all mappings for company
  - `PUT /api/v1/financial/gl-mappings/{mapping_type}/` — set/update mapping
  - `GET /api/v1/financial/gl-mappings/validate/` — check all required mappings set
- **Seed Data**: Default mappings seeded on company creation using standard COA

### Integration Points
```python
# Instead of hardcoding accounts:
# OLD: account = Account.objects.get(code="2110")  # AP Control
# NEW:
account = gl_mapping_service.get_account(company, "ap_control")

# Used in:
# - Invoice posting (AP/AR control accounts)
# - Payment posting (bank account)
# - Tax posting (SST payable/receivable)
# - Forex posting (gain/loss accounts)
# - Inter-company posting (receivable/payable)
# - Payroll posting (EPF/SOCSO/EIS payable)
```

### Frontend (React)
- **GL Mapping Configuration Page**: dropdown to select account for each mapping type
- **Validation Warnings**: show which mappings are missing when creating transactions
- **Setup Wizard**: on first company setup, guide user through mapping configuration
