# T026 — Profit & Loss Statement

- **Phase**: 2
- **Depends On**: T022
- **Estimated Effort**: 3 days

## What Is Being Built
Configurable P&L statement template with account mapping. Multi-period comparison (current month vs YTD vs budget). Departmental P&L. Export to PDF/Excel.

## How It Will Be Built

### Backend (Django)
- **Model** (`apps/financial/models.py`):
  - `ReportTemplate`: name, report_type (pl/bs/cf), company FK, template_config (JSON — account mappings, line items)
- **Service**: `get_profit_and_loss(company, period_from, period_to, template_id)` — aggregate revenue and expense accounts per template
- **API**: `GET /api/v1/financial/reports/profit-and-loss/` — with period and template params

### Frontend (React)
- `ProfitAndLossPage` — period selector, comparison toggle (month/YTD/budget), template selector, PDF/Excel export
