# T022a — Recurring Journals

- **Phase**: 2
- **Depends On**: T022, T024
- **Estimated Effort**: 2 days

## What Is Being Built
Recurring journal entry templates for automated monthly postings. Define a journal template (accounts, amounts, description) and schedule (monthly, quarterly). System auto-creates journal entries on schedule or user can generate manually. Used for prepayments, accruals, depreciation (T037 handles assets separately), insurance, rent, etc.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `RecurringJournal`: id, name, description, frequency (monthly/quarterly/yearly), next_run_date, last_run_date, is_active, company FK, created_by FK, created_at
  - `RecurringJournalLine`: recurring_journal FK, account FK, debit (formula or fixed), credit (formula or fixed), description
- **Service** (`apps/financial/services/recurring_journal_service.py`):
  - `create_recurring_journal(data)` — create template with lines
  - `generate_entries(recurring_journal_id)` — create actual JE from template for current period
  - `generate_all_due()` — Celery task: find all due recurring journals and generate entries
  - `preview(recurring_journal_id)` — show what entries would be created
- **API** (`apps/financial/api/recurring_journal_api.py`):
  - `GET /api/v1/financial/recurring-journals/` — list all
  - `POST /api/v1/financial/recurring-journals/` — create template
  - `PUT /api/v1/financial/recurring-journals/{id}/` — update template
  - `POST /api/v1/financial/recurring-journals/{id}/generate/` — manually generate entries
  - `POST /api/v1/financial/recurring-journals/{id}/preview/` — preview entries
  - `GET /api/v1/financial/recurring-journals/{id}/history/` — past generated entries
- **Celery Task**: `generate_recurring_journals` — runs daily, generates entries for due journals

### Frontend (React)
- **Recurring Journal List Page**: all templates with next run date, status
- **Recurring Journal Form Page**: create/edit template with line items
- **Generate Button**: manually trigger entry generation (with confirm dialog)
- **History View**: show past entries generated from this template

### Example Use Cases
```
Monthly Prepayment:
  DR Prepaid Insurance (asset)    RM1,200
  CR Insurance Expense            RM1,200
  Frequency: Monthly, 12 months

Monthly Accrual:
  DR Utilities Expense            RM5,000
  CR Accrued Expenses (liability) RM5,000
  Frequency: Monthly
```
