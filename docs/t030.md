# T030 — Accounts Payable: Supplier Invoice

- **Phase**: 2
- **Depends On**: T013, T014, T018, T026, T041
- **Estimated Effort**: 8 days

## What Is Being Built
Supplier invoice recording with line items, tax codes, GL accounts. 3-way match with PO and GRN. Due date and payment terms. Aging analysis. GL posting on approval.

## How It Will Be Built

### Backend (Django)
- **Models** (`apps/financial/models.py`):
  - `Supplier`: (shared with SCM) name, code, contact, address, payment_terms, credit_limit, GL_account FK, tax_code FK, SST_no, company FK, is_active
  - `SupplierInvoice`: supplier FK, invoice_number, date, due_date, PO FK (optional), currency, exchange_rate, status (draft/submitted/approved/posted/void), foreign_amount (amount in foreign currency), base_amount (amount in MYR = foreign_amount × exchange_rate), total, tax_total, grand_total, reference, notes, company FK, approval_request FK
  - `SupplierInvoiceLine`: invoice FK, line_number, item FK, description, quantity, unit_price, discount_percent, amount, tax_code FK, tax_amount, GL_account FK, PO_line FK
- **Service** (`apps/financial/services/ap_service.py`):
  - `create_invoice()`, `validate_invoice()`, `submit_for_approval()`, `post_invoice()` (create GL: DR expense/asset, CR AP control), `void_invoice()` (reverse GL)
- **API**: Full CRUD + submit + post + void endpoints

### Frontend (React)
- `SupplierInvoiceListPage` — table with filters (supplier, date, status)
- `SupplierInvoiceFormPage` — create/edit with line items, item lookup, auto-calculation
- `SupplierInvoiceDetailPage` — read-only detail, approval history, GL entries

## Deliverables Checklist
- [ ] `Supplier`, `SupplierInvoice`, `SupplierInvoiceLine` models
- [ ] Invoice service (create, validate, submit, post, void)
- [ ] GL posting: DR expense/asset, CR AP control
- [ ] GL reversal on void
- [ ] 3-way match validation (PO-GRN-Invoice)
- [ ] Tax calculation per line
- [ ] Aging analysis
- [ ] React list, form, and detail pages
- [ ] All CRUD actions use `useConfirm()` dialog

## Success Criteria
- [ ] Invoice creates correct GL entries on post
- [ ] Void posts reversing entries
- [ ] Line total = qty × price × (1 - discount%)
- [ ] Tax amount = line total × tax rate
- [ ] Grand total = sum of all line totals + tax
- [ ] Cannot post to closed period
- [ ] Foreign currency invoice stores both foreign_amount and base_amount
- [ ] base_amount = foreign_amount × exchange_rate
- [ ] All tests pass
