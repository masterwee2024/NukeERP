# T034a — Exchange Rate Management

- **Phase**: 2
- **Depends On**: T013, T021
- **Estimated Effort**: 2 days

## What Is Being Built
`ExchangeRate` model for storing daily exchange rates. CRUD API. Rate history view. Rates used for foreign currency transactions (invoices, payments). Company base currency configuration.

## How It Will Be Built

### Backend (Django)
- **Model** (`apps/financial/models.py`):
  - `ExchangeRate`: id, source_currency (string, e.g., "USD"), target_currency (string, e.g., "MYR"), rate (decimal — 1 source = X target), rate_date (date), rate_type (spot/average/closing), source (manual/api), created_by FK → User, created_at, unique(source_currency, target_currency, rate_date, rate_type)
- **Service** (`apps/financial/services/exchange_rate_service.py`):
  - `get_rate(source_currency, target_currency, date, rate_type)` — get rate for specific date, fallback to nearest available
  - `get_rate_for_transaction(source_currency, target_currency, transaction_date)` — get spot rate for transaction
  - `get_closing_rate(source_currency, target_currency, period_end_date)` — get closing rate for revaluation
  - `get_average_rate(source_currency, target_currency, period_start, period_end)` — average rate for period
  - `create_rate(data)` — create new rate entry
  - `bulk_create_rates(rates)` — bulk import rates
  - `get_rate_history(source_currency, target_currency, start_date, end_date)` — rate trend data
- **API** (`apps/financial/api/exchange_rate_api.py`):
  - `GET /api/v1/financial/exchange-rates/` — list rates (filter by currency, date range)
  - `POST /api/v1/financial/exchange-rates/` — create rate
  - `POST /api/v1/financial/exchange-rates/bulk/` — bulk import
  - `GET /api/v1/financial/exchange-rates/latest/` — get latest rates for all currencies
  - `GET /api/v1/financial/exchange-rates/history/` — rate history chart data
  - `GET /api/v1/financial/exchange-rates/{id}/` — rate detail
  - `DELETE /api/v1/financial/exchange-rates/{id}/` — delete rate (admin only)
- **Seed Data**: Common currencies (USD, EUR, GBP, SGD, JPY, AUD, HKD) with sample rates

### Frontend (React)
- **Exchange Rate List Page**: table with currency pair, rate, date, type, source
- **Exchange Rate Form Page**: create/edit rates, bulk import
- **Rate History Chart**: line chart showing rate trend over time
- **Latest Rates Dashboard**: widget showing current rates for all active currencies
